## 逐次現場

### 中立性的五次下降

**2026-08-06：數字第一次真的下降**（`specs/053-declare-noop-execute`）。在此之前交付的四個功能全部是量測，沒有一個讓數字動過。

| | 前 | 後 |
|---|---|---|
| 中立性違規 | 216 筆 | **174 筆**（`interpreter.ts` 61 → 33） |
| 完備性殼 | 92 | **76**（其中 ✅ 778→782、📄 已宣告 0→12） |
| 執行器重複註冊 | （沒人看過） | **0**（原本 14） |

**2026-08-06 稍晚：第二次下降，性質不同**（`specs/054-execute-into-capsules`）。中立性 **174 → 116 筆**、違規檔案 **20 → 16 個**。

這次**全部是同一種下降：位置改變，行為一字未動**。58 個執行器搬進它們的模組——語言套件的模組本來就有 concepts／blocks／generators／lifters 四路，執行那一路住在核心層，**膠囊缺一面牆**。補上之後 8 個標準函式庫模組的五面牆才齊。

> ⚠️ **這一段的兩個字後來都變了，見 [history/047](../history/047-模組是搬家的中途站不是終點.md)（2026-08-11）**：
>
> - 「**五面牆才齊**」讀起來像終點，而 `<cmath>` 的五面牆在五個月後**全空**了
>   ——三顆概念都進了元件膠囊。**模組是搬家的中途站，不是終點**：
>   它把耦合從「核心 ↔ 語言」降一級，膠囊再降一級到「元件自己」。
> - 「**膠囊**」在這裡指的是**模組**。今天這個詞指
>   `src/components/<scope>/<name>/`——**元件**的資料夾。
>   兩次都是對的（那時候模組確實是最小的自足單位），而讀到這裡的人
>   若用今天的意思去讀，會得到一個錯的結論（「模組本來就該是膠囊」）。

零行為改動有證據不是宣稱：執行器清冊（166 個概念）搬移前後完全相同、完備性 782/12/76/5 一字未動、重複註冊仍是 0。

**剩下的 116 筆**：8 個混住的執行器檔（通用與語言專屬同檔）＋ `interpreter.ts` 的 33 筆。

**2026-08-06 第三次下降**（`specs/055-finish-executor-move`）。中立性 **116 → 55 筆、20 → 8 檔**；`src/interpreter/` 從 76 降到 **15**（只剩已知缺口清單），八個執行器檔**全部歸零**。

「混住」原本被當成判斷題，**實測是查表題**——概念定義裡就有層級欄位。

同一輪還補了兩個護欄看不到的東西：
- **有實作卻沒宣告**（第八條護欄）：3 個概念有執行器卻從來沒有定義，補上後**攤開了 8 個藏著的缺口**（殼 76→78、缺 5→11）。那是揭露不是退步。
- **P9 原文寫的 import 檢查**：中立性數的一直是元件身分**字串**，而 P9 說的是「無 `languages/cpp/` import」。加上之後立刻抓到一處。**那條原則自己寫下的檢查，兩個月來沒被做過。**

**2026-08-06 第四次下降**（`specs/056-abstract-concept-integrity`）。中立性 **55 → 31 筆**（自階段 6.5 起 216 → 31，**-85%**）。

這次修的是**抽象層**：131 個概念宣告了語言中立的父概念，**98 個（75%）指向根本不存在的概念**，而查詢函式對它們靜默回傳「沒有」——與「沒宣告」產出一樣。30 個改指向真實存在的父概念，68 個移除宣告（那些概念真的沒有通用對應物）。

**明確拒絕**把 98 個目標名都建成概念：那會產生一批五路皆空的殼，用一個病換另一個病。

抽象層修好之後，介面層兩份寫死清單才能由宣告導出——`sync-controller` 16→1、`block-registrar` 12→3。**它們之所以要寫死，正是因為抽象層指不到東西。**

---

054 的代價記著：`array_access` 從 13 檔變 14 檔——拆分 `io.ts` 之後，留下的 `print`／`input` 與搬走的 `printf`／`scanf` 都要辨識它。**中立性 -61 換就近性 +1。**

---

**053 的下降則是兩種成分混在一起。只有 4 個是真的修好。** 四個轉型概念（`static_cast` 等）的實作一直都在，被一份「無執行行為」清單覆蓋掉——`static_cast<int>(3.9)` 原本輸出 `void`。其餘的下降是**說清楚**，不是變好：12 個概念的「刻意不執行」從核心層的清單改成概念自己宣告。

完備性報表因此**改成三欄**（✅實作／📄已宣告不提供／🈳殼）。混在同一個數字裡的話，用宣告刷數字看起來會像進步。

**檔案數仍是 20**——每個檔都還剩至少一筆。要降到檔案層級得等 P2 把執行器搬進語言套件。`interpreter.ts` 剩的 33 筆是 15 條已知缺口 + 18 個 inline 執行器，兩者都要等 P2。

### 完備性換線打

**2026-08-06 換線打完備性**：🈳 **92（起始）→ 37**。組成第一次是誠實的：

| | |
|---|---|
| 量測造成的 | **20 個**——合成樣本產生錯的程式碼（`compare` 產生 `1 + 1`）或語法孤立的片段（`case 1:` 沒有 switch）。已修合成器並加「❔ 判不出來」這一類 |
| 真的沒有可觀察效果 | **7 個**——實測後宣告（`srand`／`free`／`delete`／`typedef` 等） |
| **真的壞掉、已修** | **9 個**——`sort`／`reverse`／`fill`／`iota`／`partial_sum` 全是空操作；`strcpy` 一族印出 `[array]` |

修的過程挖到更根本的三個：
- **陣列初始值從來沒進到執行期**。050 修好了辨識那半，執行那半沒接上——`int a[3]={3,1,2}; cout << a[0];` 輸出 0，而語義樹裡看得見值。**半條路修好比沒修更難察覺。**
- **字元陣列印出來是 `[array]`**。這一個讓五個 cstring 函式「看起來」都是壞的——隔離的做法是改印 `s[0] << s[1]`，`strcpy` 立刻顯示 `hi`，**那時才知道要修的不是它**。
- **`char s[4]="ab"` 把整串塞進 `s[0]`**，沒有拆成字元。

**2026-08-06 續清**：🈳 **92（起始）→ 27**、❌ **5 → 1**。

這一輪修掉的四類：
- **`print` 的身分丟失是量測假象**——測試傳了假的風格物件（`{ id: 'default' }`），產生器因此走了非預期的分支。050 用 `it.fails` 釘住的「已知缺陷」**不存在**，釘子已拔。
- **條件編譯真的會跑了**——`#ifdef` 的 body 原本在 lifter 就被整段丟掉。
- **辨識不出來的程式碼不再被靜靜略過**——改為出聲。
- **十幾條路徑依證據宣告為「由父概念消費」**，各自附實測依據。

**剩下的 27 個裡有 24 個是物件導向**——那是一個未實作的功能，不是 24 個問題。其餘 3 個：`cpp_string_clear`／`cpp_string_push_back` 的 lift（`x.clear()` 被辨識成方法呼叫，屬 051 的歧義題）、`if_else` 的 lift（死概念，移除它要動存檔格式）。

### 收盤與雙重真相

**2026-08-06 收盤**：中立性 **216 → 0 筆、20 → 0 檔**。護欄從四條增至**十七條**（新增語法耦合、宣告的子節點名、標註採用率）：就近性／中立性／完備性／缺陷帳／辨識歧義／存檔完整性／執行器重複註冊／孤兒實作／抽象層完整性／雙重真相／元件身分／欄位寫入／指標概念。

**但那個數字的意義在同一天被改小了**：它只量得到**元件身分**這一維的耦合。核心層寫死語法符號（`//`、`/* */`）的六個地方它一個字都看不到，而那六處同樣違反 P9。見 [history/021](../history/021-中立性的數字只量身分那一維.md)——**「中立性歸零」不等於「語言獨立性成立」**，下一步要補的是其他維度的護欄。

**而完備性的 🈳 27 個殼一個都沒動**——這一輪全部是「搬」不是「宣告」，那 10 個物件導向概念仍然是殼，等 OOP 真的實作了再處理。

**P4「殺雙重真相」的基線第一次量出來**（第十條護欄）：43 顆積木動態註冊，**其中 33 顆在 JSON 裡也有 `blockDef`**，29 顆的 input 名稱有分歧。那個坑的咬人方式是——PatternRenderer 從 JSON 推導 input 名，**JSON 錯了只在切換積木風格時才炸**，平常測試全綠。

**分歧不等於錯**：可變參數積木的執行期 input 本來就比靜態宣告多。

**2026-08-06 已清償**（`specs/057-single-source-input-names`）：真正的雙重真相面是「插槽名在 JSON 有對應卻仍寫死」，實測 13 處，**已全部遷移為唯一真相**（採用率 9% → **100%**）。

量法換了三次才對——三次錯都是**把不該算的算進來**（mutator 容器、執行期插槽、純排版輸入沒有 JSON 對應物是設計如此）。
