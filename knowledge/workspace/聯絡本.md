# 聯絡本（semorphe）

只放**角色與職責**。session 的位址會變，不寫在這裡（要的話放 `local/`）；找人用 ListAgents 依名字找。

| 名字 | 角色 | 管什麼 |
|---|---|---|
| 使用者 | 決定者 | 方向、對外不可逆的事（發布、DNS、推到公開處）、改原則或規則 |
| semorphe-main | semorphe 的窗口 | 對使用者彙整、回報、代問；更新工人看板；不改程式碼 |
| semorphe | semorphe 的工人 | 規劃、實作、測試、合併推 main、寫 history；照 [開場指示](開場指示.md)「工人這邊的承諾」通知窗口 |
| cella-main ／ cella | Cella 的窗口／工人 | 判決引擎（`cella-lang`）；semorphe 需要的語義在那邊做 |
| cos-mos-main ／ cos-mos-72 | cos-mos 的窗口／工人 | 三個專案共用的機制（長測試排隊、看板）；使用者常在 cos-mos-main 做跨專案的決定 |
| board-main | 看板的維護者 | 使用者在看板上送出的決定／問題由它帶原話轉來 |
| knowie-06 | knowie 的擁有者 | 知識庫協定（principles／vision／experience、draft、workspace） |

轉達規則：別的窗口轉來的使用者決定，附了原話、寫明經誰轉達，就算數；改原則、改規則、對外不可逆的事，仍要使用者直接說（11-10）。
