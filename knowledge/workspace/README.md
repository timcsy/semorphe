# 工作空間（workspace）

**現在正在做的事**放這裡——誰在做、卡在誰、等誰、待決幾件。接手（換 session、壓縮之後、換電腦、換一個 AI）的人先讀這裡。

名字借自「全域工作空間」（認知科學：當下被廣播給所有處理者的那一小塊內容）。它和 `draft/` 不同：`draft/` 是**還沒定的想法**，這裡是**正在進行的狀態**。

## 讀的順序

1. [開場指示](開場指示.md)——窗口（使用者對這個專案的對話入口）的規則。
2. [進行中](進行中.md)——一件一行：誰在做、卡在誰、先後、預估完成、做到什麼算完。**接手最重要的一份。**
3. [聯絡本](聯絡本.md)——有哪些角色、各管什麼。

## `local/` 不進版控

`local/` 被 `.gitignore` 擋著，放**只對這台機器有意義**的東西：窗口的流水帳筆記、session 的位址。
規則：版控裡的檔案**不得**把 `local/` 當必讀（換一台電腦就不在了）；接續狀態一律寫進 `進行中.md`。

由來：2026-11-13 使用者定（經 cos-mos-main → semorphe-main 轉達），見 [開場指示](開場指示.md) 的「決定」行。
