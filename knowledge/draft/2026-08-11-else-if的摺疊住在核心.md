# else-if 的摺疊住在核心——而性狀只把身分搬走了，行為沒有

> 日期：2026-08-11
> 怎麼冒出來的：把 23 條性狀逐條問「換一個語言，會不會有另一顆元件宣告它」，
> 分出真／C 家族／假三堆。**23 條裡 21 條放對了**，兩條錯的都在最內層。
> 其中 `plainDeclaration` 當天下沉修好了；**這一條下沉修不好**。
> 判準的來源見 [concepts/性狀](../concepts/性狀.md)「真抽象還是假抽象」那一節。

## 事實

```ts
// src/core/lift/pattern-lifter.ts —— 最內層
&& liftedChildren.length === 1 && isElseIfChainable(liftedChildren[0].conceptId)
```

它做的事：把 `else { if … }` **摺成** `else if …`。

性狀讓這個檔不再認得 `cpp:if` 這個**名字**，就近性護欄與中立性護欄都乾淨了。

**而「else 裡面只有一個 if 就把它摺起來」這個行為，仍然住在核心裡。**

> **依賴方向反轉了，而抽象沒有被抽乾淨時，反轉只是把耦合藏得更深一層。**

## 為什麼護欄看不到

| 護欄 | 找什麼 | 為什麼漏掉 |
|---|---|---|
| 中立性（身分掃描） | 元件身分字串 | 這裡一個都沒有 |
| 中立性（import 檢查） | `from '…languages/…'` | 這裡 import 的是 `../component/traits`（核心內部）|
| 就近性 | 膠囊身分出現在膠囊外 | 同上 |

**三條護欄全部合格，而 P9 的精神被違反了**——「拔掉 C++ 核心仍能運作」，
而一個沒有 else-if 鏈的語言拿到這個核心，那段摺疊邏輯是死的。

這與 vision 早就記著的那條同族：「中立性只量得到耦合的**一種形式**」。
`history/021` 講的是**語法符號**那一維，這裡是第三維：**範疇名**。

## 三個候選處置（都還沒選）

### A. 把摺疊搬進語言套件

`pattern-lifter` 提供一個「後處理鉤子」，C++ 套件註冊自己的摺疊規則。

- ✅ 核心真的不知道 else-if 這回事了
- ❌ 鉤子是一個**新的擴充點**，而這個專案對「機制有了沒人接上」已經有八個實例
- ❓ 要先確認：除了 else-if，還有沒有別的「摺疊」需求？只有一個的話，
  鉤子就是為一個消費者發明的抽象——**同一個假抽象病，換一層**

### B. 讓摺疊變成一條可宣告的規則

不是鉤子（程式碼），是**資料**：

```json
{ "fold": { "when": "else 只有一個子節點且它宣告 elseIfChainable", "into": "…" } }
```

- ✅ 與性狀同一個形狀（宣告得出來的才留下）
- ❌ **「摺疊」比「我是什麼」複雜得多**——它要描述樹的形狀變換，
  而那很快會變成一個小語言。`concepts/元件.md` 對這種東西有前例：
  資訊軸（C2）就是因為「今天沒有消費者」而被顯式延後的
- ❓ 判準應該是：**這個規則除了 else-if 還能描述什麼？** 答不出來就是 A 的變形

### C. 承認它、標註它、等第二個語言

留在核心，加一條顯式註解說明「這是 C 家族的知識暫住核心」，
並**在中立性護欄加一欄「範疇名」**把它數出來（今天 1 筆）。

- ✅ 誠實，而且**把不可見變成可見**——這正是這個專案處理殼的一貫方式
- ✅ 成本最低，不預先發明抽象
- ❌ 它會一直在那裡，直到有人來收

## 我的傾向（未定）

**C，而且立刻做「數出來」那半。**

理由是這個專案自己的教訓：`concepts/執行機構.md` 說**一條規範沒有機械化的檢查
就是殼**；而現在的狀況是**規範（P9）有檢查，檢查漏掉一整個維度**。

在不知道 A 還是 B 對之前，先讓那個維度**有數字**——第二個語言進來時，
那個數字會自己告訴我們該怎麼收（1 筆 → A 就夠；10 筆 → 需要 B）。

⚠️ 而「加一欄」本身要小心：**這個維度量得出來嗎？**
`isBinaryOperator` 算不算範疇名？二元運算子幾乎每個語言都有。
判準大概是「這個範疇名，換個語言還存在嗎」——也就是**性狀的判準本身**。
那表示這一欄其實是「核心引用了幾條 🟡/🔴 性狀」，而那個分類今天是**人判的**。

→ **所以真正的第一步可能是：把三堆分類寫進 `component.json` 或性狀宣告裡，
讓它從人判變成可查。** 那樣護欄才有輸入。

## 出口條件

這份 draft 的三個出口：

- **找到答案** → 選 A/B/C 其中一個，寫進 `history/`，這裡刪掉
- **第二個語言進來** → 屆時數字會說話，回來重讀這一份
- **放手** → 如果 Python 之後發現 else-if 摺疊在 Python 也需要（`elif` 也要
  從 `else: if` 摺），那它就是真通用的，這份作廢
