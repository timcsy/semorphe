## 〇、跨規則的共同需求（Cella 的型別表今天缺的）

semorphe 為了補下面這幾個缺口，自己造了平行的型別記錄。Cella 寫明之後，這些可以先刪：

1. **指定目標沒有型別**。`varTypeOf`（462）、`elementTypeOf`／`noteElementType`（450、459）、`Target.type`（465）全都是為了這個。`var_assign/to-python.ts:9-10`、`:27-28` 的註解寫著「目標的型別 Cella 不給時問宣告那一顆記下的」。量到四次失真：450 的 map 值、459 的陣列元素、462 的 bool／int、478 的 char。→ **每個左值節點都要帶它的宣告型別**。
2. **比較與邏輯回報 `int`**（219 R8：「C++ 標準是 `bool`，`int` 是 C 的規則」）。→ 改成 `bool`，或者直接標出轉換（見規則 9）。
3. **`cin >> s` 那一格報的是呼叫的型別 `std::istream`，不是 s 的型別**（`input/to-python.ts:25`）。
4. **型別不分參考**（`struct_at_member/to-python.ts:7`：「型別都問宣告那一顆記下的（不問 Cella——它不分參考）」）。→ 要區分 `T&` 與 `T`。
5. **`max({a,b,c})` 的大括號串列沒有型別**（456，已回報）。
6. **名字沒有綁定身分**：同名換名（473）、全域與區域（451）、遮蔽檢查都是 semorphe 自己推作用域。→ **每次提到名字都要帶它指到的宣告 id**（見規則 38、39）。

## Ⅰ、轉換（隱式型別轉換）

### 1. 浮點 → 整數的隱式轉換（向零截斷）
1. **規則**：浮點值放進整數物件時，捨去小數部分、向零截斷（[conv.fpint]）。複合指定 `E1 op= E2` 等同 `E1 = E1 op E2`，結果再轉回 E1 的型別（`var_assign_compound` 的註解引了 [expr.ass]p7）。
2. **在哪個檔**：`contract.ts:110` 的 `intValue`（`/^(int|long|long long|short)$/` 目標而值是 double／float／long double ⟹ `int(e)`）。呼叫的地方有：`var_assign/to-python.ts:33`、`var_assign_compound/to-python.ts:47`（`x = int(x + 2.5)`）、`var_declare/to-python.ts:25`、`var_declare_const:13`、`array_assign/to-python.ts:17`、`array_2d_assign:18`、`array_declare:29`、`map_assign:12`、`vector_declare:37`、`vector_make:13`、`pairDeclLine`（`contract.ts:390`）、`elementValue`（`contract.ts:411`）、`return/to-python.ts:16`、`func_call:13`。目標型別不知道而值是浮點 ⟹ 保留（`var_assign:32`、`array_assign:13`、`array_2d_assign:16`、`map_assign:11`）。
3. **量到過的失真**：450（history 409）`int x = 1; x += 2.5;` C++ 印 4、Python 印 5.25；`map<string,int>` 的 `ii["a"] = 2.7`。459（history 411 後續）`int a[3]; a[1] = 7.9;` C++ 印 7、Python 印 7.9。462 `int k; k = 2.5 * n` 存成 7.5。465 `vector<int>` 的 `push_back(2.5)`、`stack<int>` 的 `push(4.5)`、`set<int>` 的 `insert(6.2)`、`vector<int> v(n, 2.5)`。473 `ll DFS(){ return 1e9; }` 印成 `1000000000.0`。
4. **Cella 要寫明**：每一個「值進入有型別的物件」的位置（初始化、指定、複合指定、引數綁定、回傳、容器插入）都包一個轉換節點，例如 `conv{kind: fp→int, rounding: toward-zero, from: double, to: int}`。超出範圍的情況 Cella 已經會判成 UB。
5. **現況**：已實作；目標型別不明而值是浮點就保留。

### 2. 非 bool → bool（非零即 true）
1. **規則**：算術值轉成 bool 時，零是 false，其餘是 true（[conv.bool]）。
2. **在哪個檔**：`contract.ts:113-115`（`intValue` 的 bool 分支），註解原文是「放進 bool：C++ 非零就是 true（`bool b = 5;` 印 1），Python 原樣存 5、印的時候 int(b) 是 5（462 量到）⟹ 值不是 bool 就包 bool(…)」。bool 陣列的預設值是 `False`（`array_declare:9`、`array_2d_declare`）。
3. **量到過的失真**：462，`bool b = 5;`、`b = n - 4;` 印出 5／2，C++ 印 1。
4. **Cella 要寫明**：`conv{kind: to-bool}` 標在每一個轉成 bool 的位置。條件運算式的情境轉換（contextual conversion）也要標，不過 Python 的真值判斷與它同義，semorphe 沒有另外處理。
5. **現況**：已實作。

### 3. 整數 → char 的指定
1. **規則**：char 是整數型別。`c = c + 1` 右邊先提升成 int，再窄化回 char。Python 用長度 1 的字串表示 char，所以要加 `chr()`。
2. **在哪個檔**：`var_assign/to-python.ts:11-16`（目標是 char、值不是 char ⟹ `chr(…)`，目標型別 Cella 不給時問 `varTypeOf`）、`var_declare/to-python.ts:21-24`（初值是整數 ⟹ `chr()`；沒有初值 ⟹ `chr(0)`）。
3. **量到過的失真**：進行中.md 第 174 行的紅燈：「219（11-09）起到 478 上線前，char 變數收整數運算的值（`c = c + 1`）換成 `c = ord(c) + 1`——C++ 印 B、Python 印 66、兩邊 accept」，478 修好，回歸測試是 941a7fe83（479）。478（history 411 後續）的 `c = (c ^ 22)` 少了 `chr()`。
4. **Cella 要寫明**：在指定的位置標出 `conv{kind: int→char, narrowing}`，同時給左值的宣告型別（第〇節第 1 條）。⚠️ 窄化超出 char 範圍的情況，見第 Ⅸ 節第 6 條。
5. **現況**：已實作。char 的 `+=`、`++` 照實保留（見第 Ⅹ 節）。

### 4. 放進容器的值照元素型別轉換
1. **規則**：`push_back`、`push`、`insert`、填充建構、大括號初值，都把引數轉成容器的元素型別（這就是 copy-initialization）。
2. **在哪個檔**：`contract.ts:411` 的 `elementValue`（整數截斷、bool 包 `bool()`、vector 元素複製 `list()`、pair 逐格轉換）。呼叫的地方：`container_append:12`、`container_push:12`、`container_push_front`、`set_insert:10`、`deque_declare`、`vector_declare:37`、`vector_make:13`。
3. **量到過的失真**：465（history 411 後續）：「印 `2.5 3.95 1000.0`，C++ 印 `2 3 1000`」。
4. **Cella 要寫明**：容器插入的呼叫節點上，標出引數的 `conv{to: 元素型別}`。
5. **現況**：已實作；換不了就保留（needs-types）。⚠️ `vector_declare:30` 的大括號列出（`vector<int> v = {2.5}`）沒有走 `intValue`。C++ 的大括號初始化不准窄化，所以這種寫法本來就不合法，應該不是漏洞。

### 5. 引數照參數型別、回傳值照回傳型別轉換
1. **規則**：呼叫時，引數以 copy-initialization 綁定到參數（[expr.call]）。`return e` 把 e 轉成函式的回傳型別（[stmt.return]）。
2. **在哪個檔**：`func_call/to-python.ts:10-13`（`paramTypesOf`，引擎在 `cpp-to-python.ts:186-191` 收集），`return/to-python.ts:15-16`（`withReturnType`，在 `func_def:207` 設定）。同名的函式有兩種參數型別（多載）時保留。
3. **量到過的失真**：473（history 411 後續），StudyCpp `AP325/7/7_5_TLE` 的 `return 1e9;`，C++ 印 `1000000000`、Python 印 `1000000000.0`；`int g(int x)` 收到 2.5。
4. **Cella 要寫明**：呼叫節點的每個引數都帶 `conv`，並標出解析到的是哪一個多載（宣告 id）；return 節點也帶 `conv`。
5. **現況**：已實作；多載整支保留。

### 6. 條件運算子兩分支轉成共同型別
1. **規則**：`c ? a : b` 的兩個分支先轉成共同型別（[expr.cond]），所以 `c ? 1 : 2.5` 的 1 是 1.0。
2. **在哪個檔**：`ternary/to-python.ts:11-28`。整數分支放進浮點結果時補 `float()`；`char[N]` 退化成 `char *` 的照原樣；其餘型別不同的保留。
3. **量到過的失真**：無紀錄（455 一開始就照實）。
4. **Cella 要寫明**：兩個分支各帶 `conv{to: 結果型別}`（陣列 → 指標的退化也標出來）。
5. **現況**：部分。例如 `c ? 'a' : 66` 保留。

### 7. 明確轉型的意思
1. **規則**：`(T)x`、`static_cast<T>(x)` 的意思取決於來源型別與目標型別：浮點 → 整數截斷，整數 → 同寬或更寬的整數值不變，char → 整數取字碼，整數或 double → double。
2. **在哪個檔**：`contract.ts:285` 的 `castToPython`（`CAST_RANK` 在 `:273`，LP64：long 與 long long 同寬）。`cast` 與 `cast_static` 共用。另有無號長度轉 int 或更寬、而寫出來是一個 `len(…)` 的情況（470），照原樣。
3. **量到過的失真**：無紀錄（453 為了換得過去而做）。
4. **Cella 要寫明**：轉型節點標出 `kind`（fp-trunc／identity／widen／narrow-modular／char-code／int→fp-exact／fp→fp-round…），讓 semorphe 只照 kind 挑寫法。
5. **現況**：部分。窄化成 int（會繞回）、轉成 float（降精度）、轉成 char／bool，以及無號值不是 `len()` 的，一律保留：「其餘…照實保留——不猜」。

### 8. char 的整數提升（算術、比較、位元運算）
1. **規則**：char 參與算術時先提升成 int（[conv.prom]）。結果是整數，不是字元。
2. **在哪個檔**：`arithmetic/to-python.ts:9-19`（char 那一邊取 `ord()`；`+ - *` 可以；`& | ^` 要另一邊是有號整數或 char，478）、`compare/to-python.ts:14-16`（char 對 char 直接比；char 對整數 ⟹ char 那一邊取 `ord`）。
3. **量到過的失真**：無紀錄。364 起就照實。
4. **Cella 要寫明**：每一個 char 運算元標出 `promote{char→int}`；結果型別要給 `int`（現在已經有）。
5. **現況**：部分。char 的 `/`、`%`、`<<`、取負號照實保留；`s + c`（字串加 char）見第 Ⅸ 節第 8 條。

### 9. 比較與邏輯運算的結果型別是 bool
1. **規則**：關係運算、相等運算、`&&`、`||`、`!` 的結果型別是 bool（[expr.rel]、[expr.log.and]）。
2. **在哪個檔**：registrar 的 `yieldsBool()`（`contract.ts` 介面），由 `compare`、`logic`、`logic_not`、`container_empty` 宣告；引擎在 `cpp-to-python.ts:248` 用到。
3. **量到過的失真**：219 R8 第 2 條，「Cella 的型別表對 C++ 的比較與邏輯運算式回報 `int`……`cout << (a > 5)` 照型別表會被當成整數照印，Python 印出 `True`」。

## Ⅲ、求值次數與順序

### 25. 複合指定的左邊只算一次
1. **規則**：`E1 op= E2` 裡的 E1 只算一次（[expr.ass]p7）。
2. **在哪個檔**：`map_at/to-python.ts:10-15`、`:35`（先讀再改時鍵要寫兩次 ⟹ 只收 `pureKey`：變數、字面量、`a[i]` 這種形狀）、`struct_at_member:49`（索引裡有呼叫就保留）、`truncatedRemainder` 只收 `isSimple`（`contract.ts:267`）、`trunc_mod` 小函式讓每邊只算一次。

### 26. 運算式裡的 `++`／`--`

## Ⅳ、物件語意與別名（值語意對上 Python 的參考語意）

### 33. 容器的指定與初始化是複製
1. **規則**：`b = a`、`vector<T> b = a;`、`push_back(row)` 都複製一份；Python 的 `b = a` 讓兩個名字指到同一個物件。

## Ⅸ、⚠️ 讀碼推論的疑似漏洞（沒有實測，建議先寫判決例證實）

全部是同一類：**規則在一部分位置寫明了，另一部分位置漏了**。也正是「Cella 寫明，semorphe 不再自己猜」最能消除的那一類。

1. **char → 整數的指定沒有 `ord()`**：`int x = 'a'; cout << x;`，`intValue`（`contract.ts:110`）只處理浮點 → 整數與 → bool，所以換成 `x = "a"`，Python 印 `a`、C++ 印 97。同一個洞也出現在 `x = s[i]`（x 是 int）、`push_back('a')` 進 `vector<int>`、引數、回傳。之後 `x - 1` 會 TypeError（看得見），但**只印出來的情況是靜默的**。
2. **`&&`／`||` 的值**：`logic/to-python.ts:8` 寫成 `a and b`，Python 回傳的是運算元本身。`cout << (a && b)`（a=3、b=5）會變成 `int(3 and 5)` = 5，C++ 印 1；`int x = a || b;` 也一樣。當條件用時沒有差別。
3. **比較的結果存進 int 再印**：`int k = (a > b); cout << k;`，`intValue('int', …)` 不轉換，k 是 `True`；印的時候 k 的型別是 int，照原樣印出 `True`，C++ 印 `1`。
4. **無號的 `+ - *` 與 `++`／`--`**：`arithmetic:54-55` 落到 `${l} ${op} ${r}`、`increment` 寫成 `x -= 1`，兩處都不看有號性。`unsigned int u = 0; u--; cout << u;` C++ 印 4294967295、Python 印 -1。Cella 不會報 ubOverflow，因為無號繞回是有定義的。`v.size() - 1` 在 v 是空的時候也是同一件事。
5. **有號與無號混用的比較**：`compare/to-python.ts` 不看有號性。`int i = -1; if (i < v.size())` C++ 是 false（-1 先轉成無號），Python 是 True。
6. **整數的窄化轉換**：`intValue` 不處理 `long long → int`、`int → short`、`int → char` 超出範圍的情況（C++20 起照模數繞回，有定義、不是 UB）。`int x = big_ll;` 在 Python 保留大值；`char c = 300` 換成 `chr(300)`（'Ĭ'），C++ 是 ','（44）。
7. **`pow` 是 double，Python 的 `**` 是精確整數**：`(long long)pow(3, 39)`，C++ 是 4052555153018976256（捨入過），Python `int(3 ** 39)` 是 4052555153018976267。只在超過 2^53 時才會出現。
8. **字串加 char**：`s + 'a'` 進到 `arithmetic` 的 char 分支（`:11-18`），換成 `s + ord("a")`，Python 丟 TypeError。看得見，但這是錯的換法；`s += c`（compound）倒是對的。
9. **`float` 的單精度**（見規則 21）；**char 大於 127 時 `ord()` 的值與 C++ 有號 char 的值不同**（`ord('\xe9')` 是 233，C++ 是 -23）。規則 48 只擋了字面量，從輸入讀進來的字元沒有擋。
