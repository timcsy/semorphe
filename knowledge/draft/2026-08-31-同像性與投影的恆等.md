# 同像性 ＝ 投影是恆等函數——而 734 個投影檔就是「不同像」的價碼

> 2026-08-31。起點是一句提問：「函數和資料可以互相表達，這要如何處理？」
> 而它不是抽象問題——**這個專案已經同像了 7%，然後停住。**

## 一、🟢 它不打破「執行是觀測」，它說明 f 是高階的

公理／情境的切線是**「資訊從哪來」，不是「型別是什麼」**。程式建構程式再執行它，
建出來的那段仍由「結構 ＋ 輸入」決定——切線活著。改變的只有一件事：

> **f 的定義域與值域可以裝「程式」。**

⟹ 對追蹤的具體後果：**一次觀測的值可以是一棵樹**。
那正好是 [內部狀態要怎麼顯示](2026-08-31-內部狀態要怎麼顯示.md) 需要的那個放寬。

## 二、🔴 但有一個地方真的咬到：世界可以遞【結構】進來

`concepts/三維錨定.md:230` 逐字：

```
T = Protocol_fixed ∩ Data_dynamic | Agency_responsible
```

**`Protocol_fixed`**——公理維度是固定的。而同像性說：如果輸入可以是程式，
**情境維度就能生產公理維度的材料**。

那不是假設——**那正是 Prompt／LLM 那條線**：模型吐出來的是結構，不是純量。

🔴 **這是同像性對這個知識庫真正的挑戰，而它挑戰的是那個 `∩` 的方向。**

## 三、最鋒利的一句

> **同像性 ＝ 投影是恆等函數。**

```
一般語言   code ←→ tree   要 parse／generate，而它【有損】——raw_code 就是那個損
同像語言   code  =  tree   雙射免費，R0 不用努力
```

**Semorphe 最貴的那部分工程，在同像語言裡不存在。** 而它的價碼量得出來：

```
投影用的 .ts（render／strategy）    734 個
純 component.json 就跑得動的元件      0 個
```

🟢 而這給「加語言」一個沒被講過的判準：**加一個同像語言（Lisp／Scheme），最難的
那一半是白拿的**——而它同時是最好的自我檢驗，因為**投影恆等時，模型裡剩下的東西
才是真的模型**。

## 四、這個專案已經走了 7%，然後停住——而那條線是偶然的還是有原則的？

```
元件 332 顆 ── 純宣告 23   ｜  帶 execute.ts（行為是程式碼）309
```

宣告是資料（`comment-syntax`／`skip-declarations`／`dropdown-sources` 都是登記處），
**而行為與投影是程式碼**。三個可能的位置：

```
甲  現狀     宣告是資料、行為與投影是程式碼
             理由：行為是圖靈完備的，硬塞進 JSON 會發明一個爛語言
             🟢 有實測前例支持——「剩餘手寫 strategy」就是硬塞的技術債

乙  一步     行為【宣告化成引用】：component.json 不寫行為，寫
             「這顆的行為由某個符合協議的執行器提供」
             🟢 = draft/執行器是可插拔的 已經在講的東西
             🟢 不需要發明語言——引用是資料，被引用的仍是程式碼

丙  全同像   語義樹能表達語義樹（自舉元教學的極限形態）
             🔴 而 concepts/三維錨定.md:227 已經先寫好了它的天花板：
                「系統可以優化所有分支，但根公理必須由外部預設」
```

**傾向乙**，理由不是它比較優雅——是**它是唯一一個已經有現成消費者的**：
執行器外包、Prompt 元件、AI 動態改模型結構，三條線指向同一個介面。
