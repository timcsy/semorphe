# CLAUDE.md 是「經驗」的第二個家，而知識庫不知道它知道什麼

> 日期：2026-09-26（第二次 `/knowie-judge` 掃出來的）
> 🟡 **狀態：待人拍板**——它不是技術選擇，是**哪一份檔是那些教訓的家**。
> ⚠️ 照本庫的體例**不寫完成條件**。

## 量到的

```
CLAUDE.md 裡蒸餾過的引言          12 條
其中 experience.md 找不到的       8 條   ← 逐字比對（去空白後子字串）
CLAUDE.md 連到 history 的次數      2 次   （240 · 254）
```

那 8 條（節錄前綴）：

```
一條「本機全綠就等於好了」的習慣,量到的是本機那台機器的寬鬆程度
一支在乾淨機器上綠、在忙碌機器上紅的測試,量到的不是你的改動
`npm test` 驗的是「這些函式做對了嗎」;e2e 驗的是「使用者按得到的東西還在不在」
一次「輸出的文字表示變了」的改動,會讓每一份【寫死了那段文字】的東西過期
本機那一台比 CI 那一台寬鬆的地方,量不出來的不是缺陷——是【我的判準有多寬】
兩個名字很像的檢查,差別常常不在判準,在母體
殘差量的是「我沒認出來」,而它對「我認錯了」保持沉默
一個只錯在 `execute` 那一路的缺陷,形狀是完美的——而形狀完美正是它活下來的原因
```

## 🔴 它解釋了一個獨立的讀數

判官同一輪掃到 **15 筆 history 零入連結**，而抽樣三筆（`262` 判準綁在本機那台編譯器 ·
`249` 括號剖錯 · `247` 兩個 lift 來源）在 `experience.md` 裡**一個字都找不到**
——它們的教訓**反流到 CLAUDE.md 去了**，而 CLAUDE.md 幾乎不連 history。

⟹ 那 15 筆孤兒不是「少了一條連結」，是**反流去了另一個家，而那個家不留因果**。

## 那一題

> **一個庫如果有兩個「經驗」的家，哪一份是真相？**

三條路，而它們的代價不同：

```
A  兩邊都留       最省事,而它是雙重真相 —— 這個庫判過很多次(宣告登記處)
B  教訓進 experience,CLAUDE.md 只留「什麼時候跑什麼」並指過去
                 單一真相,而 CLAUDE.md 會失去它現在的衝擊力
                 ⚠️ 而它每個 session 都會被讀,experience.md 不會
C  承認兩個投影    CLAUDE.md ＝【操作】的投影,experience ＝【教訓】的家;
                 判準是「一句話是在教我做什麼,還是在說一件事為什麼」
                 ⟹ 那 8 條要在 experience 有家,CLAUDE.md 引用它
```

🟡 **傾向 C**，理由是它與這個庫已有的判準同形（投影不是複製，而每一族有自己的簽名）。
⚠️ 而 C 的代價要說清楚：**它把 8 條教訓搬進一份每個 session 不會被讀的檔**
——而那正是 CLAUDE.md 當初收下它們的原因。所以 C 成立的前提是
**CLAUDE.md 那一行留得住操作的衝擊力**（「改了 X → 跑 Y」），只把「為什麼」搬走。

## 誰不該回答這一題

🔴 **不是我**。CLAUDE.md 是使用者與我之間的操作契約，
把 8 條教訓搬出去會改變**我每個 session 讀到什麼**——那是他的決定，不是我的整理。
