# printf 產碼的型別表——推不出型別的那一行怎麼辦

> 狀態：🟡 待使用者決定（2026-11-04；附推薦）。in-flight：vision 路線圖〈printf 產碼的型別表〉的設計依據，那一項完成時退場。來源：spec 213 第一次在判決層量到（history/337）——課文 11 支按下 printf 風格，執行結果就變。
> 缺陷帳 2026-09-20 那一根：`printf` 對每一個運算式都寫 `%d`（`src/components/cpp/print/generate.ts`）。

## 量到的

| 情形 | 今天產出 | 跑出來 |
|---|---|---|
| `char c = 'A'; cout << c;` | `printf("%d", c)` | 印 `65` 不是 `A` |
| `double d = 1.5;` | `printf("%d", d)` | 未定義行為（Cella 判 ubPrintf） |
| `long long x` | `printf("%d", x)` | 未定義行為 |
| `string s` | `printf("%d", s)` | 未定義行為（Cella：把字串當指標印） |

## 要做的

產碼端一份輕量的型別推斷：宣告（變數、參數、struct 欄位）→ 名字的型別；字面值（`1`／`1.5`／`'A'`／`"s"`）；算術的型別提升；比較與邏輯 → int；陣列與容器的元素；使用者函式的回傳型別；`size()` → `size_t`（`%zu`）。
推得出的照型別產：`%c`、`%f`（`double` 的 printf 是 `%f`）、`%lld`、`%s`（字串要 `.c_str()`）、`%zu`。

## 🟡 要你決定：推不出型別的那一行怎麼辦

| 選項 | 學生看到的 | 後果 |
|---|---|---|
| **A（推薦）那一行保留 `cout <<`，旁邊註明原因** | 大部分是 printf，少數幾行是 cout，註解寫「這一行的型別判斷不出來，保留 cout」 | 照實；程式跑出來與 cout 版一致（判決層的不變式成立）；混用在 C++ 裡合法 |
| B 照舊寫 `%d`，另外出一個警告 | 全部是 printf，有些行有黃色警告 | 程式可能跑出錯的東西（學生不一定看警告）——就是缺陷帳那句「有的對有的錯看起來像對的」 |
| C 整支程式拒絕切到 printf，說明是哪一行推不出 | 切換按鈕說「這支程式還不能切成 printf：第 N 行」 | 最保守；但一行推不出就整支不能切 |

**推薦 A**：它是唯一「切換之後跑出來的東西保證不變」的選項（換形態，判決不變），而且把「系統還不會」照實攤在那一行上（P6 誠實降級），不擋住整支程式。
