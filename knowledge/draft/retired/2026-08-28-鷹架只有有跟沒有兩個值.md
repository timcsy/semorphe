## 量出來的現況（三層，而其中一層是假的）

| 這一格 | 誰決定 | 狀態 |
|---|---|---|
| 哪些元件**是**鷹架 | 元件自己的性狀（`scaffold`／`scaffoldInMain`） | 🟢 真的宣告——4 顆（`include`／`include_local`／`using_namespace`／`return`） |
| **露多少** | 課程組態（`hidden`／`ghost`／`editable`） | 🟢 2026-08-28 接上 |
| 外框**長什麼樣** | `Target.entryShell` | 🔴 **值域只有 `'main'` 與 `'none'`** → 🟢 2026-08-28 打開 |
| 樹裡**哪一塊是外框** | 🔴 **當時沒有人宣告**——寫死在六處 | 🟢 `Shell.entryFunctions`（`history/188`） |

🔴 **`entryShell: 'none'` 不是「Arduino 的鷹架」，它是「沒有鷹架」。**

`cpp-scaffold.ts:59` 逐字：`if (this.entryShell === 'none')` → preamble／entryPoint／epilogue
**全部是空的**。`setup()`／`loop()` 之所以在頂層，是因為**沒有東西包住它們**
——不是因為有人宣告了一個 Arduino 外框。

## 「算不算一種元件？」——不是，而它的每一格已經是元件了

```
元件    使用者拖得到 · 可以有很多顆 · 位置由他決定
鷹架    使用者拖不到 · 每支程式恰好一份 · 位置固定在最外層
```

而 `#include`、`func_def(main)`、`return` **本來就都是元件**。

> **鷹架不是一顆新積木，是「哪幾顆元件組成外框，以及它們怎麼排」。**

所以它的形狀應該是一份**宣告**，不是一顆元件也不是一個列舉：

```jsonc
// src/languages/cpp/shells/main.json
{
  "id": "main",
  "preamble":  [{ "component": "cpp:include", "properties": { "header": "iostream" } },
                { "component": "cpp:using_namespace", "properties": { "name": "std" } }],
  "entryPoint": { "component": "cpp:func_def", "properties": { "name": "main", "return_type": "int" } },
  "epilogue":  [{ "component": "cpp:return" }]
}
```

🟢 那樣的話 `arduino` 就是 `preamble: []` ＋ 沒有 `entryPoint`
——**「沒有鷹架」變成一份空的宣告，而不是一個特例的 `if`**。

## 🔴 而這一刀**不做它**〔🪦 當天翻面，見下方「而它為什麼當天就翻面」〕

三個理由：

```
今天只有兩種形狀       而 entryShell 撐得住
第三種會逼出正確的欄位  現在設計是憑空猜的——preamble 要不要排序？entryPoint 可以有參數嗎？
另一半今天就有用       「露多少由課程決定」有 65 堂課在等
```

⚠️ 而它已經有一個**已知的裂縫**：`auto-include.ts:77` 逐字
「`int main() { … }`，把 `setup()`／`loop()` 包進去」——
**同一個決定在鷹架與補丁器兩處各實作了一次**
（`tests/unit/target.test.ts` 的 `entryShell` 註解記著這件事）。
宣告化的第一個好處會是那兩處問同一份東西。

## 而它為什麼當天就翻面

三個「不做」的理由，**第一個當天就不成立了**：

```
「今天只有兩種形狀」   🔴 使用者接著要 Python 的鷹架 → 第三種【當天】就到了
「第三種會逼出欄位」   🟢 這句是對的，而它逼出來的欄位就是下面那份 jsonc
「另一半今天就有用」   🟢 也對——而兩半是【可以同一天做完的】，不是二選一
```

> **一個「等真的需要再說」的判斷，它的有效期取決於【誰在提需求】
> ——而使用者的下一句話就會讓它到期。**

而第三個理由（「另一半今天就有用」）之所以看起來像個理由，是因為
我把兩件事當成**互斥的排程**。它們不互斥：`ScaffoldMode` 管「露多少」、
`Shell` 管「長什麼樣」，**兩個軸各自獨立**，做完一個不會擋住另一個。

## 重開條件〔🪦 已觸發：Python 的外框，2026-08-28〕

> **真的出現第三種外框的那天**——不是「又想到它了」。

候選（各自都會逼出不同的欄位）：

| 第三種 | 它會逼出什麼 |
|---|---|
| Python 的 `if __name__ == '__main__':` | entryPoint 是一個**條件**，不是一個函式 |
| 競賽的快速 IO 前言（`ios::sync_with_stdio(false)`） | preamble 要**排序**（它必須在 main 裡的第一行） |
| Java 的 `class Main { public static void main }` | 外框有**兩層**巢狀 |

⚠️ 三個裡面**任何一個**進來，`entryShell: 'main' | 'none'` 就不夠用了。
