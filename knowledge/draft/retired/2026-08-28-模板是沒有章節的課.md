# 模板是「沒有章節的課」——而它與課差在一格

> ⚠️ **已交付並退場（2026-08-30）。** `templates/` 六份 ＋ `core/template.ts` ＋ 第八十七條護欄 `audit-templates` ＋ `e2e/templates.spec.ts`。「沒選課程時那一格」現在是「選擇範例」。本檔留的是**它與課差在哪一格**的推導（不收窄可見元件）。

> 日期：2026-08-28
> 怎麼冒出來的：三層選單做完之後，使用者問
> 「**如果沒有選擇課程時，要不要有選單去選擇 template？**」

## 一、它填的是哪一格

```
沒選課程   目標 · 課程 · 【？】 · 風格 · 語言 · 版面
選了課程   目標 · 課程 · 章節  · 風格 · 語言 · 版面
```

那一格今天是空的，**而它不是真的空**——有一個隱形的預設在跑：
目標的 `entryShell` ＋ `scaffold: editable` ＋ 一支空的 `int main()`。

> 🎯 **所以這一刀真正做的是：把一個隱形的預設變成一個看得見的選項。**

## 二、🔴 它與課差在一格，而那一格決定了整個形狀

| | 課（`lesson.json`） | 模板 |
|---|---|---|
| 有順序 | ✅ 第 1 章接第 2 章 | ❌ 平的 |
| 收窄可見元件 | ✅ `components` | ❌ **不收窄——它是「拿去改」** |
| 程式碼住哪 | 課文的 `## 完成的樣子` | **它自己**（模板就是一段起始程式） |
| 釘組態 | `pins` | `pins`（同一份格式） |

🔴 **「不收窄」是關鍵的那一格。** `draft/工具箱裡的範例` 早就切過這一刀：

```
預組   一組總是緊鄰出現的呼叫       防【裝錯】
教材   線性、有順序、有目標         給【路徑】
範例   完整、可跑、有註解，拿去改   給【動機】   ← 這裡
```

而它逐字寫著：「**範例過不了預組那條判準**——沒有人會『裝錯』一個範例，
範例的價值不在防錯。」同理，**範例的價值也不在收窄**：
一個把工具箱關掉的範例，學生改不動它。

## 三、形狀

```
templates/
  README.md
  01-空白程式/
    template.json   { title, description, target, scaffold, order }
    code.cpp        ← 🔴 起始程式，一個真的檔案
```

**為什麼程式碼是獨立檔案而不是 JSON 裡的字串**：

```
獨立檔    語法高亮 · grep 得到 · 護欄可以真的餵給編輯器跑
JSON 字串 每一行都要 \n 跳脫，而沒有人讀得下去
```

⚠️ 與 `lessons/` 的「程式碼只寫在課文裡一份」是**同一條規矩的兩個實例**：
**程式碼住在一個地方，而那個地方要人讀得下去。**

## 四、要人拍板的三件事

- [ ] **模板要不要跟著目標過濾？** 傾向**要**——與課程那顆同一個理由
      （使用者拍板過「先選目標再選課程」）。而它的代價是：
      切目標會讓目前選的模板消失。
- [ ] **切模板要不要清空使用者的程式？**
      🔴 **傾向不要自動清**——那會吃掉他的作品。
      而不清的話「選了模板卻沒看到模板」也很怪。
      **候選解**：只在畫布是空的時候套用；否則問一句。
- [ ] **第一批要哪幾個？** 見下。

## 五、第一批（提案）

每個語言一個「空白」＋ 一到兩個「拿去改」：

| | 目標 | 給什麼 |
|---|---|---|
| 空白程式 | cpp | 最小可跑 |
| 讀一個數字 | cpp | `cin` ＋ `cout` 的骨架 |
| 讀 n 個數字 | cpp | 陣列 ＋ 迴圈——競賽題的開場 |
| 空白 C 程式 | c | `printf`／`scanf` |
| 空白 Python | python | |
| 讀輸入 Python | python | |
| Arduino 閃燈 | arduino-uno | 硬體的 hello world |
| Arduino 讀感測器 | arduino-uno | 類比讀 ＋ 序列埠印 |

⚠️ **每一個都要量過**（`write-lesson` skill 第 1 步）：`raw_code` 為零、
真的跑得動。一個跑不動的模板比沒有模板更糟——它是**內建的壞例子**。
