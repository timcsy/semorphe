# 假設教室裡有老師——一個定位決定，而它一次擋掉四件工作

> 日期：2026-08-27
> **狀態：使用者傾向這個選項（「我覺得第三個或許不錯」），未正式拍板。**
> 它不像同日那幾則是「怎麼做」，它是「**做不做**」。

## 一、問題是怎麼冒出來的

使用者問「在編輯器要如何連結到這互動式教材？」，並舉例：
堆疊是一堂課、用互動式動畫理解、可以自己從頭拼也可以用 STL。

查證下來，「互動式教材」是**三類不同的東西**，而它們的家不同：

| | 例子 | 隨什麼變 | 住哪 |
|---|---|---|---|
| ① 狀態投影 | 堆疊現在裝什麼 | 執行 | 元件（[形態槽第六格](2026-08-05-圖解形態與資料結構圖鑑.md)） |
| ② **指引** | 「請看第 4 行」 | 教材的進度 | 教案 → **需要一個新通道** |
| ③ 概念說明 | 盤子疊起來 | **什麼都不隨** | 老師的網頁 |

🔴 **而我第一版把三類都歸給元件，那是錯的**：`std::stack` 那顆膠囊
沒有理由知道「用盤子比喻堆疊」——那是教學選擇，不同老師會選不同比喻。

## 二、② 那個通道的設計【早就存在】

`draft/教材要如何呈現 §二` 逐字：

> 一課的單位**不是段落，是「請注意這裡」**
> 🔴 而那個機制已經存在：`execution:at-node` 廣播一個 `nodeId`，每個視圖自己決定怎麼亮。
> ⚠️ 而它**不該直接重用那個通道**——那是「執行走到哪裡」，教材要的是「請看這裡」。
> **同一個形狀，不同的通道。**
> （`history/062`：殘差與診斷共用一個通道，剛翻過車。）

**所以「編輯器怎麼連結到教材」的答案是：教材說一個 `nodeId`，其餘的視圖自己處理。**

## 三、🎯 而決定是：**先不做那個通道——老師就是那個通道**

> 使用者：「我覺得第三個或許不錯」（三個選項中的「先不做，老師用嘴巴說」）

意思是：**這個產品假設教室裡有一個老師。**

### 🟢 它一次擋掉四件工作

```
不做   teaching:focus 通道
不做   跨頁通訊 / postMessage
不做   「怎麼嵌入 Semorphe」的說明與支援
不做   概念動畫進 Semorphe（它住老師的網頁 → 信任模型那一整題也不必答）
```

### 🟢 而它消掉了使用者最初擔心的那個「麻煩」

使用者原話（2026-08-27）：「或是教師要把他的教材網站裡面嵌入 semorphe 編輯器，
**有點麻煩**」。

```
要跨頁指引   → 要 postMessage → 要嵌入
不做指引     → 🟢 兩個分頁就好，老師的網頁只放一條連結
```

**那個需求本身消失了，不是被繞過去。**

> ⚠️ **一則更正**：本檔第一版把上面那句「有點麻煩」寫成「你說過那很麻煩」，
> 並據此把 iframe 當成**被否決的選項**。**那是誤引**——原話是一個
> 權衡中的一項，不是否決。
> 🔴 記在這裡是因為：那個誤引如果留著，下一個讀的人會以為 iframe 討論過並被排除了。
> > **把一句有分寸的話收緊成一個結論，會讓後來的人少掉一個選項。**

## 四、⚠️ 它換來的邊界，要寫清楚

```
課堂上   老師是通道                    🟢 決定成立
回家     教材在、老師不在、編輯器在     🔴 三者之間沒有連結
```

> **我們假設有老師在場。沒有老師時，教材退化成「一頁步驟」——而那是可以接受的。**

⚠️ 而它與 [教案是一個宣告 §零](retired/2026-08-27-教案是一個宣告.md) 有交互：
那則說「認知負擔來自沒有意見的選項」，而**有老師在場時，那些負擔有人吸收**。
自學時兩者都要靠介面，而介面今天答不出來。

🔴 **所以這個決定要寫清楚，因為它會被誤讀成「還沒做」而不是「不做」。**

## 五、🟢 而它是可逆的——這是現在就定的理由

`execution:at-node` 已經證明那個形狀跑得動（一個 `nodeId`，視圖自己決定怎麼亮）。
哪天要加 `teaching:focus`，**它不是一個新設計，是一次複製**。

> **一個「先不做」如果已經知道怎麼做，它就不是欠債，是排序。**

      **要重新打開評估，不得引用本檔當作它被否決過**。
