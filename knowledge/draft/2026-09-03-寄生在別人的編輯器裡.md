# 寄生在別人的編輯器裡

> 日期：2026-09-03
> 狀態：**設計未決**——出口是 vision 路線圖（要人拍板），不是直接清償。
> 怎麼冒出來的：使用者：「能不能在瀏覽器上用 chrome extension **寄生**在別人的
> 文字區，就是你一開始要選擇針對哪一區，之後外掛就會可以在旁邊點選圖示展開，
> 可以切換各種視圖，包含程式碼視圖，有點類似**行動版的一個框框**這樣」。

## 一、它在架構上是「第四個宿主」

網頁、VSCode、Theia 之後的第四個。而它要的東西**都已經有了**：

```
CodeView 介面        getCode / setCode / onChange / applyEdit ← 別人的文字區就長這樣
HostProfile 宣告     控制項投影到哪、有沒有行動版版面
行動版版面           窄框 ＋ 分頁列 ＋ 一列工具列 ← 使用者說的「那個框框」
VSCode 那側的協定    webview 跑應用、主行程持有文件、applyEdit ＋ 版本號 ＋ 回音守衛
```

🟢 **順帶的價值**：它是「宿主抽象是不是真的成立」的**證偽測試**。
第一刀如果只需要「填一份宣告 ＋ 實作一個 CodeView」，那份抽象就是真的；
如果要動核心，那代表它還沒說實話。

⚠️ 而第一百條護欄（行動版的 CSS 規則要問過宣告，不准用寬度斷點猜）
**正好是為這個宿主守的**：外掛的框是窄的，但它不是手機——它要**宣告**。

## 二、心法：不要對「畫出來的東西」做同步

> **那些 `.cm-line` 是投影，`EditorView.state.doc` 才是真相。**

這就是 P1 用在別人的 app 上。而不去找模型的代價是具體的：

🔴 **CodeMirror 6 會虛擬化長文件**——畫面外的行**根本不在 DOM 裡**。
讀 `.cm-line` 拿到的是「看得見的那幾行」，而它**看起來完全正常**。
短的 sketch 會過，兩百行的檔安靜地少一半。（＝我們記過很多次的靜默降級。）

## 三、五級梯子（這是設計的核心，不是實作細節）

```
① 這個站有已知的介面卡嗎（Arduino Cloud → 它自己的 sketch API）  → 用它
② 抓得到編輯器的模型嗎（CM6 / Monaco / ACE）                      → 用它
③ 是 contenteditable 嗎    → execCommand('insertText') 全量覆寫
④ 是真的 <textarea> 嗎     → value = x ＋ 送 input 事件
⑤ 都不是                   → 圖示變灰，說「這一區我讀不了」
```

| 級 | 可靠度 | 代價 |
|---|---|---|
| ① 官方 API | 🟢 最穩、沒有虛擬化問題 | 登入權杖；非公開 API 會改 |
| ② 模型 | 🟢 精確、進得了它的 undo | 內部屬性路徑隨版本變 → **探測一次寫成測試**，不准用猜的 |
| ③ contenteditable | 🟡 **與編輯器無關**（同一段碼在 CM6／HackMD／任何 CE 上都能寫） | 全量覆寫，游標會跑；讀那一半要走剪貼簿路徑 |
| ④ textarea | 🟢 最簡單 | 只有一部分站是這樣 |
| ⑤ 讀 DOM | 🔴 **會安靜截斷** | 只能當最後手段，**且必須出聲** |

🔴 **第 ⑤ 級是這個設計裡最重要的一格**，而它最容易被省略：
一個「點了沒反應」的外掛，與一個「說我讀不了」的外掛，在使用者心裡是兩種東西。

而每一級都要能回答「**我現在在第幾級**」——降級了就寫在面板上
（「唯讀模式：這個站我只能讀畫面上看得到的部分」）。**降級可以，安靜不行。**

## 四、跑在哪裡：自己的 iframe，不要注進別人的頁面

三個理由，每一個都會咬人：CSP 常擋 wasm ／ 樣式互相汙染 ／ 商店審查。

做法：content script 只做兩件事（畫那顆圖示、讀寫那一格），
應用跑在 `chrome-extension://` 自己來源的 **iframe** 裡，兩邊 `postMessage`。

🟢 **這個形狀已經有了**：VSCode 那側就是「webview 裡跑應用、主行程持有文件」，
訊息協定幾乎可以照抄。

⚠️ 而回音守衛在這裡**更難**：VSCode 的文件有版本號，別人的編輯器沒有。
只有「我剛寫進去的字串」可以比對——就是 2026-09-02 那一輪用的鏡像那一招，
它在這裡是**必要的**，不是加分的。

## 五、綁定：「先選一區」這個設計是對的

element picker（hover 高亮、點一下綁定）。而綁定要**記得**：

```
綁定 = { 網域, 選擇器/錨, 使用者給的名字 }   → chrome.storage
一頁多格（多題）→ 綁定是一個【清單】，不是一個值
```

🔴 這是 `doc-prefs.ts` 那條教訓的同一個形狀：
**一份偏好寫回去的範圍，不得大於它描述的東西**——綁定是 per-文字區，不是 per-站。

而「使用者主動選一區」順便把權限模型變乾淨：不要一開始要 `<all_urls>`，
用 `activeTab` ＋ 使用者點擊觸發，要記住某站再要那個站的權限。

## 六、Arduino Cloud：使用者的第一個目標，而我要潑冷水

實測（使用者的 DevTools 截圖，2026-09-03）：

```
class="cm-content"  contenteditable="true"  role="textbox"
data-language="cpp"  子節點是 .cm-line
caret-color: transparent          ← 游標是它自己畫的
-webkit-user-modify: read-write-plaintext-only
```

＝ **CodeMirror 6**（梯子的第 ② 級，或退到第 ③ 級）。

而它是**登入後的 SPA**，帶三個成本：切 sketch 不重新載入頁（要監聽 SPA 換頁）·
只有有帳號的人用得到（學生大多沒有）· 它自己會改版而你不會收到通知。

### 🔴 更該先想的：你要 Arduino Cloud 的什麼？

大概是**編譯**與**燒錄**——那是我們沒有的。而寄生只拿到它的**輸入框**，
沒有拿到它真正值錢的東西。另外兩條路直接給你那個東西：

- **Web Serial**：Chrome 本來就能從網頁直接開序列埠燒錄。
  ⚠️ 而 Arduino Cloud **要裝 Cloud Agent**（使用者的截圖底下那句
  "make sure the Cloud Agent is installed" 就是它）——**我們不用**。
- **編譯**：這才是真正缺的那一塊（雲端 `arduino-cli`，或 Arduino 的編譯 API）。

> **寄生一個站，可能是在繞過去拿一個你本來就可以擁有的東西。**

## 七、待查（沒辦法用推論解決的）

1. 🔴 **CM6 的 `EditorView` 從 DOM 節點怎麼拿**——內部屬性鏈隨版本變。
   要在真的頁面上探測一次，並把結果**寫成測試**（不然它爛掉的樣子是安靜的）。
2. MV3 把 content script 注進 **main world** 的支援與限制（跨世界怎麼傳訊）。
3. Arduino Cloud 的 sketch API 形狀與 ToS——第 ① 級可不可行。
4. 第一刀挑哪個站（見下）。

## 八、我的建議：把兩件事拆開

- **寄生**這個能力值得做，而第一刀該挑一個**真 textarea** 的站（ZeroJudge 那種
  ——也正好是台灣學生真的待著的地方）。先把梯子、綁定、回音守衛做對，
  CM6 當第二級再加。
  ⚠️ 用 Arduino Cloud 當第一刀＝同時賭「寄生可行」「CM6 內部屬性穩定」
  「SPA 不改版」三件事。
- **Arduino Cloud** 先回答「你要的是它的輸入框，還是它的編譯與燒錄」。
  如果是後者，Web Serial ＋ 一個編譯服務是更短的路，**而那條路上每一塊都是我們的**。

## 九、最小可證偽的第一刀

> 在目標站挑一題，用外掛把那一格的內容變成積木，**改積木**，
> 然後按那個站自己的「送出」——**評測真的通過**。

最後半句是關鍵：它一次驗完讀、寫、游標、事件、以及
「我們寫進去的東西對那個站是合法的」。少了它，前面全部可以是假的綠。

## 十、要意識到的長期成本

**每支援一個站，就多一份會爛的相依。** 這與其他東西不同：課程、語言套件
都是我們說了算，而別人的 DOM 不是。所以第 ⑤ 級（出聲）不是禮貌，是這個
產品能不能長期活著的條件。
