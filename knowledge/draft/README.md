# draft — 短期記憶

從討論卸下來、還不值得定案的東西。**一個主題一個檔**：`YYYY-MM-DD-主題.md`，加一行「怎麼冒出來的」。

## 運作方式（像短期記憶）
- **預設衰減**：沒被再碰的主題會淡出——遺忘是功能，不是失敗。大部分本來就該淡出，只有少數固化。
- **被使用救起**：一個你反覆回來看的主題，證明它該固化 → 蒸餾進三檔 / concepts，然後刪掉這裡的檔。
- **新近度看 git**（最久沒碰的＝該處理的候選），不手動維護。
- **三種出口，都離開 draft**：固化 · 放手（刪） · 否決（在 `history/` 留墓碑）。

## 🧪 待決的固定區塊（2026-11-05 起試點）

要使用者決定的事，在那份 draft 裡用一個固定區塊寫（決策佇列由腳本篩這個區塊）：

```markdown
### 🟡 待決：<短名>
- 推薦：…
- 最強反方：…
- 預設值（不回答時會發生什麼）：…
- 卡住什麼：…
```
