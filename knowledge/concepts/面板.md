# 面板（Panel）

**一個面板要說得出「我被什麼驅動、我什麼時候變」。說不出的，它是控制項不是面板。**

**三視角投影：**

- **原則**：唯一真實、各式投影——而面板是投影落地的那一面。`history/202` 的判決逐字：「**主控台不是投影，是【執行的輸出】**」，那一刀證明了面板不只一種。
- **願景**：可插拔的宿主（網頁／VSCode／別人的編輯器）× 可插拔的後端（直譯器／g++／實體板子）——而面板與後端**正交**。
- **經驗**：把「這個面板被誰驅動」寫死在它的實作裡，會讓「同一個面板換一個後端」變成重寫。

## 四種，而分界是**內容**的驅動源

| 種類 | 內容被誰驅動 | **什麼時候變** | 例子 |
|---|---|---|---|
| **真實的投影** | 語義樹 | 編輯時 | 積木 · 程式碼 · 流程 · 3D 模型 |
| **執行的輸出** | 這一次執行 | 跑的時候 | 主控台 · 變數 · 遊戲畫面 |
| 🔴 **外部的觀測** | **外部世界** | **你什麼都沒做也會變** | 遙測 · 感測器 · 實體機器人 |
| **登錄表的視圖** | 登錄表 | 裝／移除套件時 | 工具箱 · 課程選單 |

🔴 **第三種的性質沒有一個既有面板有**：

```
積木面板    你不編輯,它不變
主控台      你不跑,它不變
🔴 遙測面板  你【什麼都不做】,它也在變 —— 因為【世界】變了
```

⟹ 它繼承 IoT 域的全部（延遲 · 會斷線 · **沒有全域時鐘，事件只有偏序**），
而**匯流排上要多一種事件**：今天的事件是「編輯了」「跑到第幾步」，
遙測要的是「外面傳來一筆，而**時間戳是它的不是我的**」。

## 🔴 而驅動源不是一個——它是**內容 ＋ 疊加**

流程面板被**語義樹**驅動（第一種），**同時**吃執行事件。積木面板的分步播放也是。

```
內容     被語義樹驅動     編輯時變       ← 它是哪一種,看這個
🔴 疊加   被執行驅動       跑的時候變      ← 疊在內容上,不取代內容
```

> **一個只問「誰驅動它」的分類，會在一個面板同時被兩個東西驅動的時候
> 把它塞進其中一格——而塞進哪一格會變成品味問題。**

## 剪枝力有兩條，而第二條問的是**動作**

**① 說得出「我被什麼驅動、我什麼時候變」嗎？**

```
❌ 設定對話框   它不顯示任何一種真實,它【改】宣告
🟡 錯誤清單     邊緣 —— 它是【診斷】的投影,而診斷掛在語義樹上 ⟹ 算第一種
🟢 工具箱       是,第四種
```

**② 🔴 它的編輯原子動作跟現有的不一樣嗎？**

第一條分不開積木／流程／程式碼——**它們的內容是同一棵樹**。分開它們的是動作：

```
積木   把一顆元件放進一個槽   ⟹ 結構上蘊含「恰好一個父」＝ 組合律
流程   從一個接點拉一條線     ⟹ 沒有那個限制
程式碼 打字                  ⟹ 什麼都不蘊含（所以要 parse 回來）
```

> **一個視圖的第一等公民，是它的【編輯動作】操作的東西，
> 不是它畫面上最大的東西。**

⟹ **積木不是「主要呈現組合」，是它的編輯動作就【是】組合律的具現**
（見 [連接](連接.md)）——做不出非組合的關係，不是因為畫不出來，是因為**拖不出來**。

🟢 而它讓「這是不是一個新面板」從品味變成可檢驗的：

```
深色主題的積木面板   動作一樣 ⟹ 是主題,不是面板
唯讀的流程面板       沒有動作 ⟹ 🟡 邊緣（它是一個模式）
「接線圖」           動作＝拉線 ⟹ 🔴 與流程面板【同一個】—— 不要開第二個
```

## 🔴 後端與面板正交

與「結構 × 關係正交」同一個形狀：

```
同一個後端 → 餵多個面板    實體板子 → 主控台（序列埠）＋ 遙測圖表
同一個面板 ← 由不同後端餵   主控台 ← 直譯器的輸出  或  實體板子的序列埠
```

⟹ **不要把面板綁在後端上。** 中間要有一條匯流排——**而我們已經有了**
（`SemanticBus` ／ `ViewHost`）。

```
執行器後端   直譯器 · g++ · 硬體模擬 · 實體板子 · debugger ·（cella）
     ↓ 事件
   匯流排
     ↓
面板        主控台 · 變數 · 遊戲畫面 · 遙測 · 3D
```

## ⚠️ 一條跨過去就不一樣的線：能寫回實體的面板

```
模擬的機器人   執行輸出         🟡 與遊戲同一格
🔴 實體的機器人 外部的觀測       而如果面板【能按】,它就變成【控制】
```

控制是**不可逆**的，而 `L1`（執行期檢查）的價值前提是「違反了還能重來」。

⟹ 一個能寫回實體的面板，需要別的面板都不需要的東西：
**解除／鎖定**（預設是鎖的）· **死人開關** · **界限**（而它是一條[契約](契約.md)）。

> 🟢 **而這是契約框架第一個【使用者看得見】的消費者**——
> `severity` 不是一個給驗證用的欄位，**它決定那顆按鈕長什麼樣**。
