# 改存檔格式（migrate-storage）

## 這把刀先問一句

> **使用者上次存的那一份，升上來之後少了什麼？**

答不出來 → 先別寫升級步驟，先列**這次動到的每一個欄位**，逐個回答它去哪了。

（緣起：這個 repo 到 2026-08-24 已經改過 **9 次**（`CURRENT_VERSION = 10`），
而那 9 次踩過的坑全部寫在 `src/core/storage-version.ts` 的註解裡——
這份 skill 是把它們變成一張會被讀的清單。）

## 步驟

### 1. 先分歸屬，再改欄位

一份存檔裡常常混著三種東西，而它們的生命週期不同：

```
屬於【檔案／主體】   換一個檔案就換一份     程式碼、語言
屬於【那個主體的外觀】 可以丟，丟了重算       積木座標、節點位置、摺疊
屬於【使用者】       跨主體不變             介面語言、風格、佈局偏好
```

**判準**：問「**換一個檔案時它該不該變？**」該 → 前兩類；不該 → 使用者。
分不出來的**先列成第四類「待判」**，不要猜——猜錯的歸屬會在第二個檔案出現時才爆。

### 2. `SAVED_STATE_FIELDS` 要跟著改，而它擋得住漂移

```ts
export const SAVED_STATE_FIELDS = { … } satisfies …
```

`storage-version.ts:26` 的檔頭逐字：

> 「**`satisfies` 是這裡的重點**：漏一個或多一個都編不過（實測 `TS1360`）。」

⚠️ **所以不要繞過它**。它是「型別在執行期不存在」的替身，
而繞過它等於讓存檔的欄位清單重新變成推斷。

### 3. ⚠️ 升級步驟**遲早會被跑第二次**——所以它必須冪等

`storage-version.ts:207` 逐字：

> 「匯出那條路曾經把每一份檔案標成 `version: 1`（2026-08-11 修掉），
> 於是一份**已經轉換過**的內容會再被餵進這一步一次。
> **一個「只跑一次才對」的轉換，遲早會被跑第二次。**」

**做法**：改名表要**先判「它是不是已經是新名」**，是就跳過，不要當成未知。

### 4. ⚠️ 只改你**確定是那個東西**的位置

`storage-version.ts:200` 逐字：

> 「`field_dropdown`……**字面一模一樣而意思完全無關**——兩邊都是 string，
> **型別檢查看不到**。上一次『同一個欄位名長在三個型別上』的改名回退了 121 個檔。」

**做法**：只在**已知結構**上遞迴（`blocks.blocks[]`、`inputs.*.block`／`.shadow`、
`next.block`／`.shadow`），認不得的原樣通過。
**不要**寫「把所有叫 `type` 的欄位都換掉」。

### 5. 表是空的時候不得把全部當成未知

```ts
if (Object.keys(renames()).length > 0 && unknown.size > 0) throw …
```

⚠️ 少了前半，**一個還沒開始的遷移會把所有舊檔擋在門外**。

### 6. 兩條路徑必須得到同一個判定

自動載入（每次開頁面）與匯入檔案是**兩條路**。
`storage-version.ts:4` 的檔頭記著它們曾經鬆緊度不同：
「自動載入那條什麼都不檢查，匯入那條只檢查 `version` 欄位存在」。

→ 判定住在**這一個模組**，兩條路都問它。

### 7. 🔴 拿掉一個欄位之前，先問它是不是「行為上的真實」

`storage-version.ts:269` 逐字：

> 「積木狀態是載入時的**主要還原來源**，所以它**行為上是真實**，適用 P8 的例外條款。」

**一個欄位如果是還原的主要來源，拿掉它就是改變真相住在哪**——那不是格式改版，
那是一次架構決定，要先有路線圖項。

### 8. 護欄：`audit-storage-integrity`

它量三個數字（欄位守恆／判定分歧／缺升級步驟），而基線的 note 自己寫著：

> 「這條護欄的三個數字都是 0，而**『健康的 0』與『什麼都沒量到的 0』產出一樣**。
> 判斷它有沒有壞的唯一方式是『注入已知違規』那組測試。」

→ **動手前先跑一次那支**，確認注入那三條真的在跑。

### 9. 真的用舊存檔試一次

型別與護欄都綠 ≠ 使用者的東西沒掉。
**開瀏覽器、貼一份 v(N-1) 的 JSON 進 localStorage、重新整理、看畫面。**

## 明確否決

| 做法 | 為什麼不行 |
|---|---|
| 「舊格式就讓它壞掉，反正還沒發布」 | `history/026`：P8 不做向後相容**管投影與程式碼，不管存檔** |
| 跳號（10 → 12） | 升級步驟是一條鏈，缺一格就整條斷 |
| 在升級步驟裡呼叫會變的東西（登錄表、目前語言） | 升級要能在**任何時候**重跑，而那些東西會變 |
| 把新欄位設成必填 | 舊存檔沒有它 → 每一份都變成不合法 |
