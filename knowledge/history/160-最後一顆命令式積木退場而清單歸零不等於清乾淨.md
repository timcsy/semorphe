# 160 · 最後一顆命令式積木退場，而「歸零」不等於清乾淨

**日期**：2026-08-26

## 起點：`cpp_raw_code` 卡了三輪的那個理由，被拆成兩件事

`retire-imperative-block` §3 拿它當**反例**在教「比對通過而不能刪」：

> 「`cpp_raw_code` 比對通過**而它不能刪**：`loadExtraState` 會依
> `degradationCause` 換顏色與 tooltip，**而比對只比「剛建好的樣子」**。」

而這一輪能刪，**不是因為宣告終於表達得出「依 extraState 換視覺」**
——是因為那兩件事**本來就不該由那顆積木做**：

```
保存 extraState  →  preserveForeignExtraState 補上「純轉手」那一支
套用視覺        →  面板的 applyExtraStateVisuals（它本來就對每一顆積木在做）
```

第二件事尤其有意思：`unresolved` 那一段**與它旁邊的降級／信心兩段是同一族**，
而只有它留在積木自己身上。

> **一個機制搬家的時候，留在原地的那一半會看起來像「它需要特別處理」
> ——而它其實只是沒被搬。**

## 🔴 而第一件事是一個藏著的缺陷，不是新功能

Blockly **不會替沒有 `saveExtraState`／`loadExtraState` 的積木留住 extraState**
（實測回傳 `{}`）。於是自從積木改成宣告式建起來的那天起，
**每一顆宣告式積木的 extraState 都在切風格時整份掉光**——含使用者自己打的行內註解。

它沒有任何測試看得到，因為沒有人在切風格之後去讀 extraState。

## 起點的另一半：一句「有差異 0 顆」

刪完之後比對報表說**「🟢 一模一樣（可刪）0 顆／🔴 有差異（不准刪）0 顆」**。

而我把入口條件從「用建構子的宣告不得被略過」推廣成
「**兩份定義都有的，一顆都不能從母體裡消失**」之後，多出**七顆**：

```
cpp_var_declare · cpp_var_declare_expression · cpp_array_declare ·
cpp_array_2d_declare · cpp_vector_declare · cpp_forward_decl · cpp_initializer_list
```

它們的宣告是**空殼**——連 `message0` 都沒有，於是比對器把它們**略過**，
而略過與通過在報表上長得一模一樣。

> **「有差異 0 顆」不等於「清乾淨了」
> ——那七顆是從母體裡消失的，而消失與沒問題長得一樣。**

處置：新增 `hollowDeclaration` 棘輪（逐顆指名），並在基線的 `note` 寫下
**兩個數字必須一起看**的理由——一顆積木的宣告從「有內容但不一樣」退成
「空殼」，會讓 `differ` 下降而看起來像進步。

## 🔴 第十次撞上錨點會爛，而這次是**成功**讓它變紅

第七條護欄（雙重真相）的入口條件錨在

```ts
expect(dynamicBodies.size).toBeGreaterThan(10)   // 動態註冊的顆數
```

而那正是這條護欄要推向零的量。最後一顆退場那天它剛好掉到 10。

改錨在**掃描器讀進了多少字**（`> 10_000`）——與第四十一條 2026-08-25 的修法同一招。
顆數仍然量、**但不設下限**：它有一天會是 0，而那天這條護欄該退休，不是變紅。

## 🔴 而最重的一筆是 e2e 抓到的：左值接點化拆掉了一個區別的載體

`block-registrar.ts` 那段註解自己寫著：

> **「兩個下拉長得一樣，不代表它們問的是同一個問題。」**

當時那個區別住在**積木型別**裡——`cpp_var_ref` 是讀（變數 ∪ 板子常數），
`cpp_var_assign` 的 `NAME` 是寫（只有變數，否則學生選得到 `HIGH = 5`）。

而**左值接點化把那兩個型別合成了一個**：賦值的左邊現在裝的就是一顆 `cpp_var_ref`。

> **一個靠「你是哪一種積木」成立的區別，
> 在那兩種積木合而為一的那天會安靜地消失。**

它不拋錯、不讓任何單元測試變紅（**5749 支全綠**），症狀只是下拉多了幾個名字。
抓到它的是 **e2e 的 spec 149**——而那一支是三天前寫的，測的是**沒有人再去看的舊路**。

修法：區別搬到**位置**——下拉問「我坐的這一格，是不是宣告過的寫入目標」，
而「哪一格是寫入目標」由元件自己宣告（`traits.writesTo`）。
🟢 順帶讓 `writesTo` 有了**第一個產品消費者**——在此之前只有測試在讀它。
