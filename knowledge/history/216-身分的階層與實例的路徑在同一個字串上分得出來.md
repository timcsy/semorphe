## 為什麼現在做，而不是等有人用到

**兩種完全不同的東西，將要用同一個符號。**

```
身分階層   python:numpy.linalg.solve    「這是【哪一種】東西」——型別側
實例路徑   car.wheelFL.speed            「這是【哪一個】東西」——實例側
```

今天不撞：帶 `.` 的身分 **0 顆**，實例路徑那種東西**還不存在**。

而 vision 逐字：**「①（路徑語法）排第一是因為它是唯一一個三個域都會用到、
而且錯了要全改的東西」**——等到兩邊都有東西之後才解那個撞號，就要改三個域。

> **一條規範沒有機械化的檢查，它本身就是殼——而殼看起來像完成。**
> （`concepts/執行機構.md`）

## 🔴 判別器回**三種**答案，不是一個是非

```
有擁有者    python:numpy.linalg.solve   → 身分
沒有擁有者而帶 `.`   car.wheelFL.speed  → 🔴 【歧義】
```

`numpy.linalg.solve` 少了 `python:` 就與 `car.wheelFL` **逐字同形**，
而它兩種都讀得通。

> **一個回答「是」或「否」的判別器，在遇到「兩者都可以」的時候
> 必須說出第三個答案——否則它會把一個未解的衝突報成一個已解的答案。**

⚠️ 而歧義**要出聲，不要被解掉**：

> **一個會自動解掉歧義的機制，會讓那個歧義永遠不被討論。**

## 三條規則各有一支測試指得到

```
①  分得出來            三種答案各有標本
②  階層不得是我們的分類  `cpp:containers.vector` 會紅（明文清單，刻意很短）
③  `.` 是真實，`/` 與 `_` 是投影   python:numpy.linalg.solve → 目錄／積木型別名
```

🔴 **②「現在守的是未來」**——今天帶 `.` 的身分 0 顆，它會在第一個人
寫下 `cpp:containers.vector` 的那一刻紅。前科是
[047](047-模組是搬家的中途站不是終點.md)：**分類會變，而變了就是搬家**。

## ⚠️ 為什麼分隔符是 `.` 而不是 `/`

`concepts/元件.md` 逐字：**核心純淨性**——`/` 需要核心知道這顆是哪個語言的，
而**分隔符不能跟語言走**。第一百一十條護欄有一支專驗判別器裡沒有語言名。
