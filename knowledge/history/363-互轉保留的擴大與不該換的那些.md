## 做了的

| 方向 | 構造 | 寫法 |
|---|---|---|
| C++ → Python | `cin >> s`（string） | Cella 在這格報的是 `operator>>` 那次呼叫的型別（`std::istream`），要回頭看宣告 |
| C++ → Python | 二維陣列的初值 | 逐列寫滿的整數才換；沒寫滿要補 0，double 的整數字面量到 Python 會印成整數 |
| C++ → Python | 運算式的取餘數 | 小函式 `trunc_mod`，每邊只算一次（照定義展開會算兩次） |
| C++ → Python | `main` 中途 `return 0` | `raise SystemExit`（`import sys`、`exit()` Cella 的 Python 家族還不支援）；非零的結束碼不換 |
| Python → C++ | `split`／`upper`／`lower`／`replace`、印 `list[int]`／`list[str]`、切片、整數的 `**` | 補在開頭的小函式；切片與指數只收非負的字面量 |

## 走錯一次的

小函式的索引先用 `size_t`：Cella 判 unknown（「標頭有沒有宣告 size_t 要看函式庫」），改 `int`。
`replace_all(s, string("X"), string("--"))`：兩個引數都是建構呼叫，先後沒有規定，Cella 判 unknown；改收 `const char*`。
這兩個都是**我們寫的 C++ 帶進來的假設**，判決攔下來了。

## 沒做的（不是忘了）

- **`float` 的印法**（3 支）：Python 印最短來回表示，C++ 要自己找精度；試的寫法（`ostringstream` 配 `stod`）Cella 還翻不出。
- **dict 系列**（5 支）：`std::map` 依鍵排序、Python 依插入順序，走訪的輸出不同，是意思差。
- **try_catch**（3 支）：`int("x")` 的例外要對應到 `stoi` 的例外，種類與訊息都不同，還沒有設計。
- **無號除法**（`sum / v.size()`）：負數時 C++ 繞回；要忠實寫，結果再轉回 `int` 又是另一層。
- **串列推導**：C++ 沒有對應的運算式，要先把一段敘述提到前面，引擎還沒有那個機制。
