# 003：從「可轉換 / 不可轉換」到「R0-R4 降級分級」

> 日期：2026-03-07

## 轉移

- **舊**：投影被隱含地當作二分——一個表示要嘛能雙向轉換，要嘛「不支援」。遇到轉不了的東西時，答案是「這個做不到」。
- **新**：**不存在「不可轉換」，只存在「降級程度」**。可逆性依投影種類分五級：R0 雙射 / R1 語義保留 / R2 結構可逆 / R3 片段可逆 / R4 單向。

## 為什麼變

二分模型讓系統無法回答「要不要支援流程圖/敘事/呼叫圖」這類問題——它們顯然不可逆，但顯然有用。二分之下唯一的選擇是「不做」，於是整個投影族群被排除在架構之外。

分級之後，判準從「能不能轉」變成「這個投影屬於哪一級，因此需要什麼驗證」：

```
R0-R1 → 可編輯視圖 → roundtrip 是判定標準
R2-R4 → 唯讀視圖   → 不需 roundtrip，但需驗證投影完整性（不遺漏節點）
```

這一步直接解鎖了七個投影族群（文字、視覺結構、行為、分析、教育、可及性、分發）約 45 種 viewType 的設計空間，而且**不需要改核心管線**——它們都是 `project(structure, scope, viewType, viewParams)` 的實例。

同時釐清了一個曾經混淆的區別：**投影可逆性 ≠ 語義樹完整性**。code 投影永遠是 R0，不管語義樹多殘缺；巨集導致大面積降級是「語義樹完整性下降」，不是「投影管線從 R0 退化成 R4」。根公理因此不動搖——它說「程式是語義結構」，不說「所有文字都能被語義化」。

## 狀態

✅ 已採用。分級表見 [投影](../concepts/投影.md)。「轉不了怎麼辦」的標準答案成為：不存在轉不了，只有降級程度。
