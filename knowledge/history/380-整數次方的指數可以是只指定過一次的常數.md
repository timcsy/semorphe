# 380 · 整數次方的指數可以是只指定過一次的常數

> 日期：2026-11-11（406）
> 轉變：Python → C++ 的 `a ** b` 只在指數是非負整數字面量時換成 `int_pow`（負指數在 Python 是浮點，C++ 的整數函式給不出來）。課文 `04-算一算/rebuild.py` 寫的是 `b = 2` 再 `a ** b`，整支保留。
> 改成：指數是變數，而這個變數在整支程式裡只被指定過一次、指定的是非負整數字面量，也換。

## 為什麼這樣算忠實

型別表是照一份輸入觀察到的，換一份輸入型別可能不同（程式第一行寫著）。如果只看「這次觀察到的指數不是負的」就換，換一份輸入時 C++ 會默默算錯。只被指定過一次字面量的變數，在任何輸入下都是同一個值，所以不受這個限制。

不算的：迴圈變數、複合指定（`b += 1`）、讀進來的值、在函式裡出現同名（參數或 `global`）、指定寫在 if 或迴圈裡。
