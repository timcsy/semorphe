# 107 — 第一條跨語言的等價邊，而契約沒有「一個語言正在建構中」這個狀態

**日期**：2026-08-20 · **spec**：`156-python-equivalence-evidence` · **狀態**：完成

## 轉變

```
之前   233 顆元件全是 cpp: scope，一個等價類的證據都沒有
之後   🟢 跨語言   ioRole=print：cpp:print、cpp:print_formatted、cpp:serial_print、python:print
       🔴 分歧點   ioRole=input：只有 cpp（cpp:input、cpp:input_formatted）
```

**第一個分歧點是一個【位置】，不是一句猜測**——那是 vision 階段 7 改寫後的驗收。

## 🔴 而第一次量錯了，錯的是我的探針

第一版探針只寫 `conceptId` ＋ `traits`，跑全套 **25+ 檔紅**。
我一度把它記成「25 條護欄假設了元件是 cpp」——**而根因只有一個**：

```
膠囊 python/print：缺少 paths。五路要全部列出，沒有的寫 null ＋ 理由
```

`allComponentDefs()` **在載入階段拋錯**，於是每一支碰元件清單的測試都倒。

> **一個在載入階段就拋錯的探針，量到的是它自己不合格，不是被測系統的性質。**

補齊契約後 **8 檔**；再把「宣告了卻沒有形態的接點」拿掉後 **5 檔／6 條**。
⚠️ **那兩次縮減都不是「修好了什麼」，是【探針本身變合格了】。**

## 五條檢查，五個不同的「只有一個語言」假設

| 檢查 | 假設的面向 | 處置 |
|---|---|---|
| `audit-identity-namespace` | **白名單** `SCOPES = ['cpp']`（在**核心**裡） | 🔴 換成**結構對應**：身分的 scope 必須等於它的資料夾 |
| `component-move-parity` | **凍結清單**——前提是「搬家前後相同」 | 收窄到 cpp：**新增一個語言不是搬家** |
| `audit-completeness` | **基線**不認得「這個語言此刻沒有那一路」 | 記成**誠實的缺**（見下） |
| `audit-curriculum-coverage` | **課程清單**是 cpp 的 | 明確策展：**Python 還沒有課** |
| `audit-declared-slots` | **未判定桶**要求人給理由 | 給理由（`語料沒覆蓋`），基線 +1 |

🔴 **只有第一條是「機制不支援多語言」；其餘四條都是【要求人說明】**。

> **一條好的護欄遇到新情況時，會要求你【說明】，而不是直接錯。
> 五條裡有四條做到了。**

🟢 而第一條的正解**不是把 `python` 加進白名單**：

> **一份白名單會在第二個成員出現時擋住它；
> 而一個結構對應只擋【不一致】。**

⚠️ 順帶掀出 `allCppConcepts()` **名字說謊**——它回的是**全部**語言的概念。

## 🔴 而最大的發現是一個【契約的缺口】

`python:print` 的 `render`／`extract`／`execute` 三路沒有實作。
第一版用 `skipPaths` 宣告成「刻意不提供」——**而 `skip-declaration-gate` 當場擋下**：

```
理由的詞彙只有三個：declarative｜consumed-by-parent｜degradation-target
而【沒有一個是「還沒做」】——那是刻意的（history/018：
「第三個值就是在替『還沒做』找一個體面的名字」）
```

> **膠囊契約沒有「一個語言正在建構中」這個狀態。**

🟢 處置是**誠實**：那三路記進完備性基線的「**缺**」，附理由——**不洗成設計**。
⚠️ 而「缺 0 → 3」是這個專案第一次讓那個數字離開零，
**重開條件是「Python 有了自己的 topic 與積木」，不是「加第三個理由」**。

## 等價的機制不必發明

`toolbox-builder.ts:118` 逐字：「第四版問的是那條**等價邊**本身：
`cpp:print` 與 `cpp:print_formatted` 宣告了同一個 `ioRole`（＝同一個等價類）」。

🟢 觀察集直接取 `{ioRole}`——**它已經是生產路徑在用的等價關係**，不是為這一刀發明的。

⚠️ 而護欄自己寫明了它量不到什麼：

```
量得到   在【宣告的性狀】這個觀察集下，誰跟誰同類
量不到   它們是不是【真的】做同一件事——那要行為證據，而 Python 還沒有執行期
```

> **一條等價邊是一份【主張】，而觀察集決定那份主張有多強。**
