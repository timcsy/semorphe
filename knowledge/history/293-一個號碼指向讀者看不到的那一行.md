# 293 · 一個號碼指向讀者看不到的那一行

> 日期：2026-09-29（第 269 刀）
> 觸發：使用者帶學生上課時回報的第二、三件——
> 「跟著做最終完成的好像也有點怪」「上面 cmath 的積木好像放錯地方」。
> 轉變：對照圖的號碼**從錨出發**（積木起始那一行），沒有錨的積木一個號碼都不拿；
> 新增護欄 `audit-blockmap-badges`（三條硬性零）；346 張圖重產。

## 症狀

```
cpp-beginner/06 step5   片段 4 行,badge [1,2,4] —— 2 是【空行】,第 3 行的 cout 沒有號碼
arduino/13-溫濕度        程式 14 行,而 badge 編到 15    ← 超出行數
arduino/12-液晶顯示       程式 10 行,而 badge 編到 11
python-bridge/06        空行在 3、6、10、13,badge 落在空行 10
```

## 🔴 根因有兩層，而我先修的是第一層（不夠）

**第一層：位移不是映射。**

```ts
const s0 = r.startLine + 1 - (win.firstLine - 1)
```

`codeRangeForNode` 回的是**編輯器裡那份**程式碼的行號，而那一份是產生器重新吐的
——它補鷹架、正規化、**而且吃掉片段裡的空行**。單一位移假設兩邊逐行一對一。

> **兩份文字之間的對應，只有在它們逐行一樣的時候才是一個減法。**

⟹ 換成 `tools/demo/line-map.ts` 的逐行映射表。重產之後「超出行數」歸零，
**而「落在空行」還在**。

**第二層（真正的根）：號碼的指派走的是「誰在這一行勝出」。**

```
step5   第 1 行  include 勝出           → ①
        第 2 行（空行）只剩【合成出來的 int main(){…}】涵蓋它 → 它拿到 ②
```

那顆 `main` **在課文裡根本不存在**。而它拿到了一個號碼，指著一個空行。

> **一個號碼是一句「去看那一行」的指示。而它指的那一行，讀者必須看得到。**

🟢 判準因此換成：**一顆積木只有在讀者看得到它起始那一行時才配號碼。**
而那讓那個檔案裡**本來就寫著的**那句話第一次真的成立
——「一顆積木只有一個號碼，而那個號碼是它【開始】的那一行」。
舊的實作寫的是「它第一次勝出的那一行」，兩者對一顆包在外面的積木不同。

## 🔴 而沒有機構在看這件事

`audit-lesson-blockmaps` 與 `audit-step-blockmaps` 比的是 `engineHash`／`codeHash`
——它們問「**這張圖過期了沒**」。

> **一份產物有兩個獨立的正確性：它是不是最新的，與它指的位置對不對。
> 只錨住前者的檢查，會在後者壞掉時保持全綠。**

新的 `audit-blockmap-badges` 收三條硬性零：號碼不得超出行數 · 不得落在空行 ·
每一個號碼都要有一顆**從那一行開始**的積木。第一次跑抓到 **3 類 / 7 個檔**。

⚠️ 而它第一次跑也誤報了一筆：`steps/_skipped.json` 是**記錄檔不是對照圖**
（記哪些片段被跳過與原因），而「沒有 code 欄」對它是正常的。

> **一個判準掃一個目錄時，先問那個目錄裡是不是只住著一種東西。**

## 這一刀沒有做的（②，等使用者的判準落地）

同一次回報還有一件更根本的：抽取器用**標題有沒有編號**判斷「這一節是不是跟著做的步驟」，
於是把講解與**反例**也畫成了積木圖（10 張含 ❌／💥／不要這樣的標記）。

使用者的判準（2026-09-29 逐字）：

> 「如果要有，後面必須明確說要移除積木，或是說這段積木只是示範，
> 又或者可以改課程去符合這個需要。」

⟹ 那是**宣告**不是推論，而它要一個新的機制（圍籬上的身分 ＋ 圖上的標記 ＋ 硬性零）。
量到要處置的是 **79 / 277 段、40 課**。

⚠️ 而我先想的「改用『那一節有沒有說照著打』當判準」是**錯的**，量測擋下了：
269 個編號小節裡只有 35 個說了，換過去會刪掉 **86%** 的圖。

> **一條只認得一種變體的規則，它漏掉的是那些沒有用那個字的。**
