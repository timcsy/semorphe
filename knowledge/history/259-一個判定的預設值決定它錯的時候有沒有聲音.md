# 259 — 一個判定的預設值，決定它錯的時候有沒有聲音

> 2026-09-19｜轉型的三種寫法、除以零、八進位、二維扁平初值

## 四個各自獨立的缺陷，而它們的共同點是「安靜」

```
寫的                    我們                       g++
(ll)(x+1)               UNDEFINED_FUNC: (ll)       8
int()                   UNDEFINED_FUNC: int        0
(1.0*5)/0               DIVISION_BY_ZERO           inf
0103                    103                        67          ← 安靜
int a[2][3]={1,2,3,4,5,6}  全 0                    1 2 3 4 5 6  ← 安靜
```

前三個會出聲，後兩個**不會**——而後兩個正是落在
「內容真的不同」那一欄的，**那一欄從 2026-09-16 補上第五個面向以來，
八刀都沒有動過**。

> **一個會出聲的缺陷會被排進待辦；
> 一個安靜的缺陷會被算成「這個工具就是這樣」。**

## 🔴 而最貴的一課是我自己製造的

`(X)(args)` 這個形狀在 C++ 裡有兩種意思：

```cpp
(ll)(x+1)     轉型         ll 是一個型別
(fp)(3)       函式指標呼叫  fp 是一個變數
```

第一版的判準是「**查不到這個名字 ⟹ 它是型別**」。而實測：

```
改之前   (fp)(3)  →  UNDEFINED_FUNC: (fp)   誠實出聲
第一版   (fp)(3)  →  3                      安靜地錯（g++ 是 4）
```

因為 `int (*fp)(int) = f;` 這種宣告**我們沒有記下來**，於是「查不到」
被讀成「它是型別」。

> **一個 fail-open 的判定，它錯的時候不會停下來——
> 它會把「我不知道」變成「我確定」。**

🟢 改成**有正面證據才當型別**：`Declaration` 多一格 `kind: 'variable' | 'type'`，
`typedef` 與「值長得像型別」的 `#define` 標成 `type`。
於是 `(fp)(3)` 回到 `UNDEFINED_FUNC`——**與改之前一樣，而那是對的**。

⚠️ 順帶修好了一個說謊的函式名：`isKnownType(name)` 問的其實是
「這個名字查得到嗎」，而變數也查得到。新的 `isTypeName` 才答得出那一題。

## ⚠️ 「只有整數除以零是未定義行為」

IEEE 754 說 `5.0/0` 是 `inf`、`0.0/0.0` 是 `nan`，而 C++ 的浮點除法就是它。
`AP325/3/3_14.cpp` 的那一行**永遠不會**除以零（`||` 會短路），
而我們在它上面丟了 DIVISION_BY_ZERO。

> **一個把「有定義的結果」當成錯誤的檢查，
> 會讓合法的程式停在一行它本來跑得過去的地方。**

⚠️ 順帶：`Infinity`／`NaN` 是 JavaScript 的字，C++ 印的是 `inf`／`nan`。

## ⚠️ 「只認 X」與「只認我想到的那幾種 X」

`literal_number` 已經處理過**數字分隔符**（2026-09-16）與**字尾**（2026-08-17），
而**八進位**沒有。`basic/3_literal_constant.cpp` 整節在教
「開頭 0b 是二進位、開頭 0 是八進位、開頭 0x 是十六進位」——
三種裡我們只做對了兩種，而**錯的那一種正是它在教的那一行**。

> **一個把 `0103` 讀成 103 的工具，在一堂教八進位的課上，
> 教的是「這個規則不存在」。**

## ⚠️ 二維初值的第二種寫法

```cpp
int a[2][3] = {{1,2,3},{4,5,6}};   // 認得
int a[2][3] = {1,2,3,4,5,6};       // 🔴 六個值一格都沒填進去
```

舊的迴圈假設「每一項是一列」，於是六個純量只跑兩圈、而且一格都沒填中。
`basic/15_nD_array_1.cpp` 的檔頭逐字寫著
「**看這樣 input 就懂多維陣列是如何儲存了**」——它教的正是「列是接著排的」，
而我們印出六個 0。

🟢 判準是**第一項是不是一層 `{…}`**（C++ 不准混用，所以看一項就夠）。
