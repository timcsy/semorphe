# 211 — 兩份宣告對同一個欄位說了相反的話，而執行的是驗證那一份

> 2026-09-06。vision「網頁版有檔案」的第三個驗收
> （「**side-car 刪掉 ＝ 自動排版**，不是壞掉」）。

## 轉變

```
舊   blocklyState 同時是「sideCar 桶（可以丟）」與「REQUIRED_FIELDS（必填）」
新   從必填移除；型別上改成選填

舊   丟掉 side-car → 整份存檔被拒絕 → 畫布空的、【程式碼也是空的】
新   丟掉 side-car → 從程式碼重排版
```

## 為什麼

### 一、🔴 「可以丟」是一句宣告，而執行它的是另一份東西

`FIELD_OWNERSHIP` 把 `blocklyState` 歸在 `sideCar` 桶，而那個桶的定義**逐字**是：

> `sideCar    屬於【那個檔案的外觀】  可以丟，丟了重算`

而 `SavedState` 的註解也寫著「side-car 刪掉 ＝ 自動排版」。
兩處都說它可以丟。

而 `REQUIRED_FIELDS` 說它必填——**於是丟掉它的結果是整份存檔被拒絕**。

實測（`e2e/sidecar-droppable.spec.ts`）：刪掉 `blocklyState` 之後重新整理，
`blocks: 0`、**`codeLen: 0`**——使用者的程式碼一起不見了。

> **兩份宣告如果對同一個欄位說了相反的話，
> 執行的是【驗證】那一份——而寫下另一份的人以為自己說了算。**

⚠️ 而 `FIELD_OWNERSHIP` 那張表 2026-08-24 建的時候，理由逐字是
「不宣告的代價會在『多檔案』那天一次付清」——**它宣告了，
而沒有人去問那個宣告有沒有被執行**。

### 二、⚠️ 一份「可以丟」的快取，丟掉會壞掉，那它就不是快取

```
一份可以丟的快取   丟了重算   → 慢一點
一份不能丟的東西   丟了壞掉   → 它是【第二份真相】，只是沒有人這樣叫它
```

> **一份「可以丟」的快取，如果丟掉它會讓畫面壞掉，
> 那它不是快取——它是第二份真相，只是沒有人這樣叫它。**

🟢 而程式碼那一側（`app.ts` 的 `sideCarUsable` ＋ `else if (state.code)`）
**早就寫對了**——它會從程式碼重建。壞的是**它前面那道形狀驗證**：
存檔在到達那段邏輯之前就被拒絕了。

🔴 **所以這個缺陷躲在一段正確的程式碼後面**，而讀那段程式碼看不出來。

### 三、新的硬性零：可以丟的欄位不得是必填

`audit-storage-ownership` 多一條：**`sideCar` 與 `context` 桶的欄位
不得出現在 `REQUIRED_FIELDS` 裡**。注入 → 紅並指名（驗過）。

⚠️ `context` 也算：那個桶是「屬於現在在上哪一課」，
而**沒有課的時候它本來就不該在**——把它列為必填等於要求每一份存檔都在上課。

## ⚠️ 這條驗收只做了一半

驗收原文是「**檔案存原始碼**，佈局存 side-car；side-car 刪掉 ＝ 自動排版」。
**後半做完了，前半（真的檔案）沒有**——它要 File System Access API，
而那需要使用者手勢，e2e 驗不到（同 [210](210-把例外換成回傳值之後接例外的那一段安靜地變成永遠成功.md) 的判斷）。

## 🟡 同一天的姊妹發現：一個「已交付」只在一個宿主上驗過

查證「面板協定第三頻道」那筆的兩個未決時翻到的：

```
積木的位置   網頁版 存檔的 blocklyState ｜ VSCode ViewStateStore
流程的佈局   網頁版 存檔的 flowLayout   ｜ VSCode 【零筆】
```

vision 上「**重開後在原位（持久化）**」打了勾——而它**只在網頁版成立**。

> **一個「已交付」的驗收如果只在一個宿主上驗過，
> 它記的是「那個宿主可以」，不是「這件事做完了」。**

⚠️ 為什麼會這樣：開發在瀏覽器裡進行。網頁版做完就看得到，IDE 那側要建置、
安裝、重開一個 IDE——於是「兩個宿主」讀起來像「一個宿主，而另一個之後再說」。
🔴 **而「之後」沒有一個時間點。**

🟢 第一百零九條護欄（**棘輪，不是硬性零**）釘住它只准變少。
⚠️ 刻意不是硬性零，因為今天真的缺一項：

> **一條每天都紅的護欄，與一條沒有的護欄，在第二天之後是同一個東西。**

### 而那兩個「未決」其實早就有答案

```
A  per-panel 狀態跟著誰   → 跟著主體。FIELD_OWNERSHIP 早就這樣宣告了
                            （sideCar ＝「屬於那個檔案的外觀」）
B  能不能同時兩個焦點     → ＝開兩個檔案。vision 自己上面一行就寫了
```

> **一個「未決」如果別處已經有一份宣告回答了它，
> 那它不是未決——它是【沒有人去對過】。**
