# 一個「以防萬一」的交集，擋掉的第一個東西通常是別人刻意放進去的

2026-09-20｜第 206 刀（課說了算）

## 一句話

> **一個「以防萬一」的交集，擋掉的第一個東西通常是別人刻意放進去的。**

## 事情

第 205 刀讓層級樹退場，而它只做了一半：拿掉了「分支」那一層，
**而 `主題 ∩ 課` 那個交集還在**——天花板換了個名字。

🔴 **抓到它的是瀏覽器**，而它抓的正是那一刀要修的那個案例：

```
?lesson=arduino/13-溫濕度
  課宣告 13 顆，其中一顆是 cpp:container_iter
  工具箱 14 種積木，而 cpp_container_iter 【不在裡面】
```

改完之後同一個網址：工具箱 **18 種**，而「〔 〕的 **開頭位置**（**成員形式**）」
那塊積木就在「陣列與列表」那一格裡，拖得出來。

## 那個交集的理由把兩件事混成一件

它的註解逐字寫著「課宣告了一顆這個目標根本沒有的元件時，它不該憑空出現」。

```
課宣告了一顆【不存在】的元件     🔴 是錯的 → 幽靈引用，該由護欄擋
課宣告了一顆【主題沒列】的元件   🟢 是課的決定 → 而交集把它靜默吃掉了
```

**一個判準同時擋兩種東西的時候，它擋對的那一半會替它背書。**

🟢 處置：課說了算（`want` 直接進可見集合），而「不存在」那一半交給一條
**指名它自己**的護欄（第 125 條 `audit-lesson-blocks-reachable`）。

> **把一個「順手擋掉」換成一條「指名它」的檢查，
> 數量上是多一條，而它擋的東西第一次有名字。**

## 🔴 而這一刀最該記的是：我自己漏掉了一半

使用者選的那個選項逐字寫著「自由模式＝該主題全部；
**課程模式＝課說了算（不再取交集）**」，而我實作時只做了前半。

測試全綠、tsc 乾淨、e2e 439 綠——**而那一半沒做**。

🟢 抓到它的是**開瀏覽器打開那一課**，而那是使用者自己要求的最後一關。

> **一個「做了一半」的重構，它做完的那一半會讓全部的測試變綠
> ——因為測試問的是「還在的東西對不對」，不是「該走的東西走了沒」。**

📌 判準：一個決定如果寫成兩句話，**驗收就要有兩條**。

## 量到的

```
arduino/13-溫濕度 的工具箱   14 種 → 18 種（cpp_container_iter 進來了）
新增第 125 條護欄            課宣告的每一顆都要真的存在（幽靈引用 0）
e2e                          八片 442 綠，零重試
```

## 判準

- 看到 `A ∩ B` 而 B 是「刻意的宣告」時，問「A 擋掉過 B 的什麼」
- 一個判準同時擋兩種東西時，把它拆成兩條——**其中一條會發現自己沒有存在必要**
- 一個決定寫成兩句話，驗收就要有兩條
