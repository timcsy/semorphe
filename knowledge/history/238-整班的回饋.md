# 238 · 整班的回饋——而我上一刀量錯了軸

**日期**：2026-09-15
**觸發**：使用者交來**整班** 24 則課後回饋（前五課，而那五課我剛做過可讀性）

## 分佈（不挑好的講）

```
🟢 正面              6   「還滿好用的」「漸進式引導受益良多」「很新奇，能自己寫」
                        「有點難但很好玩」「步驟很慢很棒」
🔴 字太多·找不到重點   5   「文字敘述好多數字好多，眼花繚亂，腦子好痛」
                        「老師做得很詳細，只是字太多有點找不到重點」
🔴 看不懂要我做什麼    5
🔴 純粹「好難」       5
⚠️ 具體卡點          6   空格×2 · 不知道可以跳過×1 · 想複製積木×1 · 找積木×2
```

## 🔴 我上一刀量的是「打斷次數」，而他們說的是「總量」

前五課的強調密度砍了一半（粗體 154 → 81），而**字數只降 5%**（1265 → 1201）。

更難堪的一個可能：**「找不到重點」有可能是我造成的**——粗體本來就是給人
跳讀用的地標，我把密度降下來，地標也少了。

> **一個只往下調的指標，會在「調過頭」的那一側保持全綠。**

⚠️ 而正面那 6 則說了一件重要的事：「步驟很慢」「一步步漸進式」
——**結構是有效的**，壞的是「動手之前要先讀完一大段」。

## 這一刀做了什麼（都是不必判斷品味的）

```
① 只差一個空白也要說得出來   describeLineDiff：「只差在空白——「你打的是」後面少了一個空格」
② 右鍵選單翻成中文           19 個 Blockly 內建鍵 ＋ 第 1 課補一句「可以按右鍵複製」
③ 「跳過」看得出來是按鈕      對比 1.45:1 → 3.3:1
```

## 🪦 而 ③ 我第一次量錯了軸，而且注入是綠的

學生說「我完全不知道**那個東西可以按**」。我量的是**文字對比度**（AA 4.5:1）
——而 `#888` 在深色主控台上有 4.6:1，**把舊顏色放回去，護欄是綠的**。

他說的不是「字看不清楚」，是「看不出它可以按」——那是**邊界**的對比
（WCAG 1.4.11，3:1）。換了尺之後：舊的 1.45，而我第一次「修好」的那一版
也只有 2.40。

> **把使用者的原話拆成名詞，然後問「我量的是哪一個名詞」。**

🟢 而抓到這件事的是**注入**：它第一次就綠，而那本身就是訊號。

## 🪦 「不准藏起來」寫在註解裡，而樣式違反了它

`console-panel.ts` 逐字寫著「跳過的按鈕一定要在，**而且不准藏起來**」，
而 CSS 是 `#888` 的字配 `#3a3a3a` 的框、透明底。

> **一條寫成「不准 X」的規矩，要問「X 是量得出來的嗎？」
> ——量不出來的話它只是一句話。**

## 第二刀（同一天稍後）：剩下那三件

```
④ 課文減量        第 1 課「開工前要讀幾個字」374 → 201
                  ——搬走的是「這個工具會怎麼跟你說話」那張表（4 個介面慣例）
⑤ 說得出要做什麼   第 2 課「四種基本型別」放了四行碼而【沒有一句話說照著打】
                  ＋ 第一百三十一條護欄（棘輪，205 / 240）
⑥ 冷開指一條路     沒選課時是 12 個分類、196 顆積木，而入口藏在狀態列
```

### ④ 搬走的那張表，每一行都會在它發生的時候出現在畫面上

琥珀色虛線框 · 猜猜看 · 「跟這一課要的不一樣」 · 題目的「2/3」
——四件都是**看得到才需要解釋**的東西，而它們被放在他動手之前。

> **一段「先看一次就好」的說明，如果它講的每一件事都會在畫面上出現，
> 那它的位置是「那件事發生的時候」，不是「開始之前」。**

### ⑤ 那個歧義由讀者付

一段程式碼放在課文裡有兩種意思（照著做／看一眼就好），而它自己說不出是哪一種。
全庫 240 個有程式碼的講解節裡，**205 節說不出**。

⚠️ 判準是一份動詞表——**啟發式的**，會漏報而不太會誤報。
偏低是安全的那一側（棘輪只要求往下走）。

### ⑥ 那條線的機制早就在，只是那條路上沒有人叫它

`LessonNudgeBar` 從 2026-09-10 就在，而它只在 `markOutOfScopeBlocks()` 裡更新
——**冷開那條路從來不呼叫它**。

> **一條只在「某件事發生時」才更新的提示，在那件事從不發生的那條路上
> 等於不存在——而它不會報錯，它只是安靜。**

## 🪦 而第二刀裡我又踩了兩個自己的坑

```
加動作句時順手寫了一個 ⚠️   → 那本身就是一次打斷，第 3 課的喘息從 20 掉到 18
                            （第一百三十條當場紅）
字面的三連反引號            → 今天第三次。整個檔的反引號配對錯開一位，
                            生出假的「程式碼片段」餵進 C++ 殘差語料
```

🟢 而兩次都是**護欄先出聲**，不是使用者。

## 🪦 而 ⑥ 讓 CI 紅了一次，而紅的那一項不是我以為的那個

`vscode-preflight` 說「🔴 預檢不通過」，**而上面每一行都是 🟢**。
逐項印出來才知道是 **`畫布佔比`**——那條指路的線在擴充裡吃掉了畫布高度。

而它**不是我這一刀才違反的**：那條線一直是 `flex: 0 0 auto`，只是它原本
只在「有積木被打暗」時出現，而預檢走不到那個情境。我讓它**開場就有**。

> **一條規矩如果只在某個少見的狀態下才會被違反，它會一直是綠的
> ——直到有人讓那個狀態變得常見。**

🟢 修法是把它改成**浮在畫布上**（`position: absolute`），兩種指路條一起解決。
🟢 並且讓預檢**說出不合格的是哪一項**——那個檔頭早就記過「每一行都是 🟢 而
它不通過」，當時的修法是「通過也要說一句」，**沒有解決「不通過時說哪一項」**。

⚠️ 中間我還踩了一次「改了沒用」：**預檢跑的是建置後的檔，而我沒重建**
（今天第四次「量到的不是我剛改的那一份」）。

## 🪦 而「浮起來」又換來第二次紅——這一次是遮擋

改成浮起來之後，`slot-view-picker` 三條 e2e 全部 `click` 逾時
——指路條以**整個欄**為基準浮著（`#blocks-column` 是最近的 positioned 祖先），
於是它貼在欄的頂端，蓋住那一排 `slot-picker`。

> **把一個東西從排版流拿出來，它就不再跟旁邊的東西讓位
> ——而它會蓋住的第一個，是它上面那一個。**

🟢 掛進畫布容器（並讓它 `position: relative`）之後，它蓋的是積木
——那本來就是它要講的東西。
🟢 並補一條**驗它不遮擋**的 e2e：把每一顆按鈕的中心點對那個浮層做命中測試。

⚠️ 而上一刀我只驗了「它出現」與「它該閉嘴時閉嘴」，**沒有驗它擋到誰**
——那一次是 CI 告訴我的。

## 而 ⑥ 的措辭使用者改了一次，而那不只是措辭

> 「指路的部分我比較喜歡說**打開課程**，然後按相關按鈕」

第一版的按鈕是「從這一課開始」，按下去**在編輯器裡換一課**
——而那會**跳過課文**。而課文正是「要做什麼」的來源，是他缺的那一個
（同一批回饋裡「看不懂要我做什麼」出現 5 次）。

> **把人帶到工具的另一個狀態，與把人帶到【說明那件事的地方】，
> 是兩件事——而他缺的是後者。**

🟢 改成開課文那一頁（`lessonDocHref`），而那一頁的每一題都有一顆進編輯器的按鈕
（2026-09-12 那一刀做的）——照著按才是完整的一條路。
🟢 而 e2e 多一條驗**它不得在編輯器裡換課**（`currentLesson` 按完仍然是 `null`）。

   「程式碼憑空出現」205 → 0（補了 190 節引言，升級成硬性零）、
   「喘息不足一句」55 → 0。見 [history/236] 的續篇。

🔴 **而下一步仍然不是繼續量**：這兩把尺量的是「被打斷幾次」與「有沒有引言」，
   量不到「他有沒有比較看得懂」。**要拿這一版去問同一批學生**——
   而那件事至今沒有做。

> **一個沒有回到人身上驗證的可讀性指標，量的是作者的自律，不是讀者的理解。**
