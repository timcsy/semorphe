# 195 · 市集上架，而擴充 ID 是一個發佈之後改不了的決定

**日期**：2026-08-31
**前一步**：[194](194-網域、分享卡、與一段自己會驗自己的示範.md)

## 一、使用者要的是「在市集搜尋得到」，而包裡少了四樣東西

上架前量了一次 vsix 的內容，四個欄位是空的，而其中一個比「沒有」更糟：

```
readme.md    168 位元組，逐字寫著「⚠️ 這是階段 6.13 的第一刀……雙向同步尚未實作」
keywords     完全沒有
icon         沒有（原有那三個是 contributes.commands[].icon，不同的東西）
LICENSE      manifest 宣告 MIT 兩個月，而倉庫裡沒有那個檔（打包一直靠 --skip-license 繞過）
```

那份 README 寫於 2026-08-17，**當時是真的**。而雙向同步早就是這個專案的主打
——網頁標題、根 README、demo GIF 全部繞著它。

> **一份「先湊著、之後再說」的 README，在上架的那一天
> 會變成公開頁面上唯一有人讀的東西。**

⚠️ 而 `description` 還留著「唯一真實，各式投影」——那是**專案的公理**，
不是對外的第一句話。使用者 2026-08-25 換掉網頁標題的理由是「不然很黑話」，
而同一句話還留在市集清單上名字底下那一行。**兩個讀者，兩句話。**

## 二、關鍵字：排不進前 40 的那一格是白填的

0.11.0 上架後用 `extensionquery` API 實測（`filterType: 10`）：

```
積木          共 1 筆 → 第 1 名
視覺化程式     共 1 筆 → 第 1 名
block-based  共 11 筆 → 第 2 名
blockly      共 16 筆 → 第 16 名
flowchart    共 40 筆 → 🔴 排不進前 40（被 mermaid／draw.io 那批佔滿）
```

> **一個排不進前 40 的關鍵字，與沒有填是同一件事
> ——而 vsce 只送 5 個，它還佔掉了其中一格。**

換成 `圖形化程式`（實測競爭者 **0**，且那是 108 課綱的用詞）。順帶量到：
**中文詞在這個市集幾乎沒有競爭**（`程式教學`／`拖曳`／`積木程式` 都是 0 筆）。
🟢 而這是量出來的，不是猜的——判準是排名，不是「這個詞聽起來對不對」。

## 三、🔴 而真正不可逆的是 publisher

擴充 ID 是 `<publisher>.<name>`，**發佈之後改不了**：換 publisher 等於換一個
全新的擴充，安裝數與評價歸零。

使用者已經有 `timcsy`（TextBricks 掛在那裡，206 installs），而 `semorphe`
那個 ID 當時還沒被佔走。兩條路的差別**不在搜尋**（publisher 不影響排名），
只在品牌與設定成本。**這一題交給人**，選了 `timcsy`：

```
timcsy.semorphe-vscode     零額外設定、與既有作品同一個發佈者
semorphe.semorphe-vscode   與網域／npm／CLI 一致，而名字有點重複
```

⚠️ 而這個決定要留在**程式碼旁邊**（`manifest.ts` 的 `PUBLISHER` 上方），
不是只留在這裡——下一個想「改個好聽的名字」的人會先讀到那一行。

## 四、Azure DevOps 那條路走不通，而它不是必要的

使用者的學校租戶要求綁 Azure subscription 才能建 organization，而
PAT 又必須掛在 organization 底下。**卡住的是自動發佈，不是上架**：

> **市集的網頁 UI 可以直接上傳 vsix——PAT 只是為了讓 CI 自動發。**

所以 0.11.0 是手動上傳的，而 `VSCE_PAT` 至今沒設，CI 的 Marketplace
那一步會印 `::notice::` 跳過（⚠️ **跳過要出聲**，不是靜靜地不做）。

## 五、發出去的檔名帶版本，而理由不是「比較好看」

Arduino IDE（Theia）的解壓快取**以資料夾名字為鍵**，而那個名字來自 vsix
的檔名。每一版都叫 `semorphe-vscode.vsix` 的話，覆蓋舊檔 → 名字沒變 →
**它不會重新解，而且不報錯**：面板照開，裡面是舊版。

> **一個以名字為鍵的快取，只要讓版本進到名字裡就失效得掉。**

⚠️ 所以那不是包裝，是**把一個陷阱從使用者手上拿掉**——否則 README 就得
叫他們去刪一個看不見的資料夾。而第一版的 README 真的那樣寫，被使用者
當場糾正（見 [196](196-第一次打開就不能用，而沒有人測「什麼都還沒做的時候」.md) 一、）。
