# 126　「還沒支援」的邊界，會在別的東西做出來的那天變成擋路的

**日期**：2026-08-21 ｜ **交付**：Python 元件 24 → 41，第五十條護欄三軸歸零
**前一則**：[125](125-跑測試的瓶頸不在直覺的地方.md)
**觸發**：使用者的目標——「把 Python 那邊可以做的積木都盡量完成，像 C++ 那樣完整，
至少教學上是可以好用的，原則就是**大部分 AI 生的 Python code 也是可以處理的**」

## 轉變一：先蓋量測，而語料按「AI 會寫什麼」挑

那句話被翻成第五十條護欄（`audit-python-coverage`），而它的語料
（`tests/assets/python-corpus.ts`）**按「AI 會寫出什麼」挑，不是按「我們有哪些元件」挑**。

> **一份照著實作挑的語料，量出來的永遠是滿分。**

起點：

```
🔴 來回不同  4 段   ← 產出【不合法】的 Python
   降級節點  33 個（11%）
   通用桶    30 個
```

## 轉變二：🔴 護欄少了一整軸，而它是最重要的那一軸

三批元件做完之後，使用者在瀏覽器貼一段程式：**積木全部畫對、零灰色方塊、
5068 支測試全綠**——按下執行看到「這一段程式我看不懂」。

而**這條護欄當時也抓不到**：它量 lift 與來回，那段程式兩樣都完美。

> **一段能來回轉換的程式，不代表它跑得動——那是兩個不同的投影。**

加上「執行失敗」那一軸之後，真相是 **15 段有 12 段跑不動**。而它同時改變了
另一欄的意義：「通用桶 30」原本讀起來像個潔癖問題（「不降級但身分沒了」），
配上執行才看得出它是**六段程式跑不動的原因**。

> **三個數字各自看都不夠。而一個只量得到投影、量不到行為的護欄，
> 會把「畫得出來」讀成「做得到」。**

## 轉變三（這一則的標題）：五個誠實的邊界，同時過期

每一個原本都有一句**寫得很好**的理由：

| 邊界 | 它的理由（原文大意） | 什麼時候過期 |
|---|---|---|
| 函式的預設參數整顆降級 | 「收一半會讓 `def f(a, b=1)` 產回 `def f(a, b)`」 | 收得了的時候 |
| 只收一個 `except` | 「收一半會產出少了分支的合法程式」 | 教學語料的**第一段**就有兩個 |
| 複合指派的左邊限定變數名 | 「認一半不如誠實降級」 | 類別做出來之後 `self.n += k` |
| `for` 只走得動 `range(...)` | 「認不出來的可走訪物件丟錯」 | 串列做出來的**同一天** |
| 迴圈的 `obj` 用 `extract: "text"` | 「`for a, b` 的 `text` 會拿到 `a, b`，那是已知的邊界」 | `for k, v in d.items()` |

> **一個「還沒支援」的限制，會在別的東西做出來的那天變成擋路的。
> 而它的理由不會自己過期——只有語料會告訴你。**

🟢 而五支釘住舊邊界的測試**改成釘新邊界，不是刪掉**：

> **一條「還沒支援」的測試，在支援的那天要改成「支援到哪裡」
> ——刪掉的話下一個人不知道曾經有過一條線。**

## 轉變四：追了三輪字串，而那筆樣式的 `_why` 早就寫著答案

`obj.method()` 的名字用 `extract: "text"` 拿到整段 `obj.method`，
而那筆樣式的 `_why` 逐字：「🔴 **那是一個已知的邊界**，方法呼叫要等自己的元件」。

而我先在執行器裡追了三輪：`line.strip()`（鏈式）→ `"-"`（字面接收者）
→ `parts[0]`（索引接收者）。每一種都是一道新的字串解析題。

> **一個把運算式壓成字串的欄位，
> 會讓每一種新的運算式都變成一個新的字串解析題。**

做了 `python:method_call`（接收者是**接點**）之後，三種形狀一次全通，
而執行器裡那些字串處理全部刪掉。

## 轉變五：擴語料立刻讓「0」變回「2」

四批做完之後 15 段語料三軸全零。而那正是護欄檔頭警告過的那種漂亮數字，
所以加了五段更難的（巢狀資料／字串處理鏈／類別多方法）——**當場 2 段跑不動**。

> **一個漂亮的數字，在語料停止成長的那一刻就不再是量測。**

（語料棘輪只准上升，正是為了這件事——見 [124](124-護欄有了而量測機構自己沒有人量.md)。）

## 順帶：詞彙表也是「全域單槽」的又一個實例

`audit-naming` 的詞彙住在 `languages/cpp/naming.ts`，而它檢查**每一顆**元件
——於是第二個語言的每一顆都要用 C++ 的詞彙表達自己。

→ `languages/python/naming.ts`，護欄取聯集。
🟢 而**操作詞刻意仍然共用**——那正是那份詞彙表存在的理由：
讓 `append` 在兩個語言裡是同一件事。
