# 一面鏡子不說話

**日期**：2026-09-08 · 路線圖：課程的第六刀之二「拆輪子的曲線」——待決 D 結案

## 轉變

```
舊  edit-tally 在記「這一課改了哪一邊」——而【零人讀】（機制有了沒人接）
新  章節清單裡每一課一條兩色橫條；走完一軌時主控台畫三段曲線
```

## 🔴 D 開了三輪，卡的不是技術，是一句話

那個數字**本質上是關於這個人的**（他改了哪一邊＝他的行為），
而這個專案的判準是「**它說的是任務、過程，還是這個人？說到人就砍掉**」。
我兩次提的措辭都有「你」：「這一課**你**改了 8 次」。

而 draft 早就寫著為什麼那句話危險：

> 一個「你還在用積木」的數字，寫不好會變成**羞辱**而不是鼓勵。

## 出路：不用字

```
積木 ████░░░░░░ 程式碼        ← 沒有任何一個字在評價
```

> **一面鏡子不說話。** 它在數字好的時候與不好的時候**長得一樣**
> ——所以「沒出現」不會變成一種訊號。

⚠️ 而那條「禁『你』」的測試是一個**代理判準**（「說到人」不好量，所以量
「有沒有『你』」）。它便宜、擋得住大部分，**而它會誤傷**——「你改了 8 次」
說的其實是過程。所以保留它當預設，而 D 這一格用一個**根本不含文字**的形狀。

## 三個決定，而每一個都有理由

**① 放在章節清單，不放狀態列、也不放題目格。**

```
狀態列常駐    「一直在盯著你」——那是監視，不是鏡子
題目格        那一格沒有「這一課」的列，硬塞會變成一個按得下去而沒反應的項目
章節清單      🟢 每一課一列，各自一條橫條——16 條排成一列【就是曲線】
```

而**學生要主動打開才看得到**——一面你自己走過去照的鏡子，與掛在你面前的，
感覺完全不同。

⚠️ 這裡偏離了拍板時說的「題目那一格」——理由在上面那張表，而它是
做到一半才看清楚的：題目格裡沒有「這一課」那一列。

**② 參照系寫在旁邊，而那句話說的是課程。**

第 1 課全是積木是**對的**，第 15 課全是積木才是訊號。所以每一列的
`description` 寫「建議：對照」——那是 `Track.view`／`pins.view` 那條曲線
（上一輪剛做的），而它說的是**課程**，不是他。

**③ 畢業不做門檻，做曲線。**

draft 寫的是「你最後五課有 80% 是直接寫程式碼的」——那句話說的是人，
而且**如果是 20% 呢？** 那句話就變成羞辱，所以它只能在數字好的時候出現
——而選擇性回饋會讓「沒出現」變成訊號。

```
前段（5 課）  積木 ████████░░ 程式碼
中段（6 課）  積木 █████░░░░░ 程式碼
後段（5 課）  積木 ██░░░░░░░░ 程式碼
```

任何方向的變化都畫得出來。⚠️ **往上走的曲線也誠實地畫**——那不是羞辱，
那是一個學生自己看得懂的訊號。

## 兩條硬性零，量的是「鏡子」這件事本身

```
橫條裡不得有任何文字節點          textContent === ''
title 只准是數字                  「還」「才」「只」「已經」「你」「太」「不夠」一個都不准
兩邊都是 0 → 兩塊都是 0 寬        「還沒開始」與「一半一半」是兩件事
```

## 🔴 而它結清的是一個反模式

`edit-tally` 在 2026-09-07 建的時候**零消費者**——只記不讀。
那正是這個 repo 反覆記過的「機制有了沒人接」。
D 不能永遠開著：**要嘛顯示，要嘛讓機制退場**——留一個沒有消費者的機制是最差的選項。
