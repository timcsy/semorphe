# 077　虛擬硬體往後推——先讓貼進來的 Arduino 程式碼轉得動

> 日期：2026-08-17　使用者逐字：
> 「**因為時間的緣故，我希望虛擬硬體元件等等可以晚點再做。目前我覺得最重要的事情是把
> ESP32、ArduinoNano 還有一些 Arduino 常用的套件也補進來，至少讓學生在寫 Arduino 程式
> 的時候可以雙向轉換，然後甚至 AI 給的 Code 他們貼上來也是可以順利雙向轉換的。**」

## 轉變

```
old  階段 6.11 的順序是 1→2→3→4→5→6，而 4（板子視圖）是下一個
     理由是 draft §五「1–4 做完就有一個能教 Arduino 的工具了」
new  🔴 4／5／6（虛擬硬體）往後推。先做的是【寬度】：
     板子型號（ESP32／Nano）＋ 常用套件 ＋ 雙向轉換的覆蓋率
```

## 一、為什麼這個轉向站得住

`draft/2026-08-13-支援Arduino要加什麼.md`§五 的原理由是「**1–4 做完就有一個
能教 Arduino 的工具了，而一塊板子都還沒接**」——⚠️ **而那句話隱含一個假設**：
學生用的是**我們的**工具箱。

而使用者的場景不是：**學生貼一段別處來的程式碼**（教材、網路、AI）。
在那個場景裡，**「轉得動」比「畫得出板子」重要得多**——
一段轉不動的程式碼，板子畫得再好也沒有東西可以顯示。

> **一個工具的價值，在「使用者帶什麼進來」與「我們準備了什麼」之間，
> 由前者決定。**

## 二、🔴 而它是可量的，而量它的工具剛好造好了

2026-08-17 的盲測（`component-fuzz`，20 段 hard 難度的 Arduino sketch）
**同時給出了這個目標的第一個基準**——⚠️ **而報表的軸不對**：

```
lift 殘差      20 段裡 14 段是 0     ← 辨識得出來
round-trip     20 段裡 3 段漂移      ← 🔴 這兩個才是「雙向轉換」
執行不拋錯     20 段裡 7 段          ← 而報表的標題數的是這個
```

**「PASS 7」那個數字答的是另一個問題。**

> **同一份量測，換一個目標就要換一個軸——而舊的軸不會自己失效，
> 它會繼續給出一個看起來像答案的數字。**

→ **第一步是用對的軸重量一次**，而語料要換成**AI 寫的真實 Arduino 程式**。

## 三、而卡住的多半**不是 Arduino 的東西**

那 13 筆待修，按族分：

```
🔴 const／static ＋ 陣列   6 筆   ← 純 C++，而 `const byte PINS[3] = {9,10,11};`
                                    是 Arduino 教材的招牌寫法
🔴 帶參數的 #define        1｜char 陣列與 String  1｜struct 參考參數  1｜無號環繞  1
⚪ 真的是 Arduino 的        3 筆   byte 別名、Serial 進位常數、float 位數
```

> **要讓 Arduino 程式雙向轉換，卡住的多半不是 Arduino 的東西，是 C++ 的東西。**

## 四、而「哪一塊板子」是 `provides` 的第一個真消費者——**而且不需要硬體**

```
Nano vs Uno    ⚪ 幾乎只差腳位數與編號
ESP32          🟡 analogWrite → ledcWrite、ADC 0–4095、Serial1/2、WiFi
```

也就是說**「哪一塊板子」＝「哪些函式與常數存在」**——那正是 `target` 的 `provides`。

🔴 **而它翻轉了一個排期假設**：`history/076` 與 draft 都說 `provides`／`reference`
的消費者是第 5–6 項（接線／真板子）。**而板子型號比接線先需要它，且不需要任何硬體。**

## 五、套件：量比猜好

使用者自己給了判準：「**AI 給的 Code 他們貼上來也是可以順利雙向轉換**」。

→ 讓 AI 生一批真實 Arduino 程式，**量殘差，用量出來的分佈決定收哪些套件**
——不是先開一張清單。

⚠️ 而套件裡有一類會撞到既有的墓碑：
`Adafruit_SSD1306 display(128, 64, &Wire, -1);` 這種**物件建構 ＋ 參考傳遞**，
是 C++ 類別的完整語義，不是「多收一個函式」。

## 順序（已與使用者確認）

```
1  量  用「殘差 ＋ round-trip」重跑，語料是【AI 寫的真實 Arduino 程式】
2  修  const／static ＋ 陣列（6 筆，純 C++，擋住最多真實程式碼）
3  寬  provides → 板子型號（Uno／Nano／ESP32）　⚠️ 不需要硬體
4  收  套件——照第 1 步量出來的分佈決定
```
