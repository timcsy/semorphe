# 394 · 序列指派的目標是一個樣式（交換、展開、巢狀認得了）

> 日期：2026-11-12（421）
> 轉變：`a[i], a[j] = a[j], a[i]`、`first, *mid, last = r`、`a, (b, c) = …` 從「整句誠實降級」變成 `python:var_assign_sequence` 的新接點 `pattern` ＋ 新形態（軸 `target_kind`）。做法與 [393](393-for-的目標是一個樣式.md) 的 `for` 相同，這裡只記不一樣的地方。

## 與 `for` 不一樣的地方

- **葉子是左值，不只是名字**：指派可以寫進索引與屬性（`for` 那一刀不收它們，因為迴圈的目標不綁新名字時下拉沒地方放）。交換兩格（`a[i], a[j] = a[j], a[i]`）是學生程式最常見的寫法。
- **切片目標不收**：Cella 的切片指定還在路上，收了也只會判 unknown；等它到了再放開。
- **變數下拉**：`PATTERN>NAME` 也會收到 `a[i]` 裡讀的 `a`、`i`——它們本來就是已有的變數，不會多出不存在的名字。

## 右邊的裸元組

走真積木抓到一個舊的正規化：`a, b = 1, 2` 走一趟積木回來是 `a, b = (1, 2)`（元組的「沒寫括號」是排版註記，積木那一趟不存它）。
改成序列指派右邊最外層的元組預設不帶括號、原文寫了（`x, y = (1, 2)`）才帶——與目標那一側同一條規則，學生寫的樣子是不帶的那一種。
