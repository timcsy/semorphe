# 206 — 「零外部資源」有了一個具名的例外

> 2026-09-03。使用者：「**應該要有 icon 才對**」——課文頁的瀏覽器分頁上是一顆地球。

## 轉變

```
舊   課文靜態頁：零 JavaScript、零外部資源（一條全稱的規矩）
新   零 JavaScript ＋ 零外部資源，【除了 favicon】——而那個例外要說得出理由
```

## 為什麼留它

那條規矩是為了一件具體的事立的：**打開就在那裡**。所以判準不是「有沒有外部請求」，
是「**它在不在渲染路徑上**」。

```
一支 <script>      擋畫面、可能拖進整包 bundle    → 擋
一張 <img>／字體    佈局跳動、慢                   → 擋
favicon            瀏覽器拿去畫分頁的圖示          → 不在渲染路徑上
```

而**省下它的代價是使用者看得見的**：分頁上一顆地球，與旁邊那個有 logo 的分頁並排。

> **一條規矩要擋的是它的【理由】所指的東西，不是它的字面。
> 一個不在渲染路徑上、而且省下它會讓畫面變差的東西，不是它要擋的對象。**

⚠️ 而例外要**具名**：它用的是應用同一個檔（`public/favicon.svg`）——同一個網域、
同一份快取，改 logo 時也不會有第二個地方忘記改。護欄跟著加了一條
（每一頁都必須有它），所以「例外」不等於「這裡不管」。

## 與 204 同一個形狀

[204](204-身分不准問除了一個附病歷的檔.md) 那次是「身分不准問」開了一個附病歷的例外。
