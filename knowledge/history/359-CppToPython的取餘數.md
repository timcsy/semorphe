# 359 · C++ → Python 的取餘數（spec 224）

> 日期：2026-11-09

## 三個選擇

| 選擇 | 為什麼 |
|---|---|
| 照 C++ 的定義寫、不用 `math.fmod` | `fmod` 更短，而 Cella 的 Python 家族還不支援（判 unknown）——**判決證明不了的寫法不用**。cella 確認改寫是對的過渡做法、`fmod` 排進今晚那一版 |
| 只收兩邊是變數或字面量 | 照定義改寫每一邊出現兩次——`i++ % 3` 會把 `i++` 算兩次，意思就變了（反例在護欄裡） |
| 64 位元（`long`、`long long`）的 `%` 與 `/` 保留 | 值可以超過 2^53，浮點不精確。**順手修**：219 的整數除法 `int(a / b)` 也收了 `long long`——`9007199254740993 / 1` 換出來會錯（反例在護欄裡） |
