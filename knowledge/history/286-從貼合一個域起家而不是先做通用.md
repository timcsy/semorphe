## 為什麼變

使用者連續三則把它拉大了兩層，而第三則把「教育」歸位：

> ①「我最終的目標是希望 semorphe 可以成為 **vericoding 的先鋒**。」
> ②「其實我想要的應該**不只是 vericoding，這只是在程式的領域**…**我可以在其他領域
> 安全的操作**是我的目標。」
> ③「至於教育，我認為這是**銜接這工具與人類心智認知的一個介面**。」
> ④「我希望 semorphe 也是從 vericoding 起家，**再延伸到其他領域**。」

### 🔴 而③把一條我以為存在的張力拆掉了

我原本把它讀成「教育 vs 一般開發會在某些格子上打架」。而如果教育是**銜接工具與
人類心智的介面**，它就不是一條競爭線：

```
Vericoding 有的   規格 · 驗證器 · 可驗證的程式碼
🔴 缺的            給【人】看的那一面
```

**Dafny 滿是 invariant 的程式碼讀不下去，不是因為它太嚴謹，是因為它沒有人面的投影。**

⟹ `漸進揭露`／`鷹架可退場`／`可重現 > 擬真` 不是教學的妥協，**是人面投影的參數**
——而那與根公理是同一句話（各式投影，其中一式是給人腦的）。

🟢 它順帶解釋了同一天為什麼會定出「抽象度」那條形態軸：**粒度切換就是「這個人
現在要看多細」**，而那服務的不只是學生，是任何一個人在讀一份被驗證過的程式。

### 🔴 而④更正了我一次誤讀，而那個誤讀已經寫進 draft

我把「像 Claude Code 一樣擴散」讀成「機制會不會轉移」，並寫了一整節**反駁一個
沒有被提出的主張**（「它擴散的不是同一個機制，是相反的那個」）。

使用者的原意是**起家的順序**：Claude 從 Claude Code 起家再延伸到 Design 等領域。

⟹ 兩個推論，而兩個都對得上既有讀數：

```
① 起家要挑「使用者最會抱怨」的域    Claude Code 是開發者,vericoding 也是
                                ⚠️ 而我們今天真實的使用者是【學生】—— 回饋最慢的那一批
② 延伸帶出去的是【協定】           而 18 個域填過同一張模板,連續六個只長詞彙
                                ⟹ 那份填寫不是為了完備,【它就是延伸得出去的證據】
```

## 🔴 而這個定位帶著一句否認，它與定位本身一樣重要

> **一個軟體的保證不構成物理的安全。**

不可逆的動作要的是 L3**或者物理上的攔截**（限位開關、力矩上限）。

⚠️ 理由是「事前說得出保證」**很容易被讀成過度承諾**——而在軟體域讀成過度承諾的
代價是一支跑錯的程式，**在機器人域是一台壞掉的機器**。

🟢 而 cella 那側 grep 過自己的知識庫，**沒有任何「驗證過所以安全」形狀的句子**，
並同意這條否認。
