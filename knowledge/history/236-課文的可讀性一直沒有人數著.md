# 236 · 課文的可讀性一直沒有人數著，所以它單調地變差

**日期**：2026-09-15
**觸發**：兩個學生的回饋，方向相反

```
學生 A   「叫我們自己做做看的地方需要更努想出來」「寫這個程式很有趣」
學生 B   「雖然中間的文字寫得有點難理解，但整體講得很詳細，做起來滿輕鬆的」
```

## 兩個學生的瓶頸不在同一個地方，而那正是可以分辨的

A 卡在**做**，B 卡在**讀**。而 A 用的動詞是「**想**」——對照這一輪其他回報
（「找不到判斷的積木」「不太知道要幹嘛」「看不懂」「沒教過」），那些是工具在收費。

> **問「你哪裡難」問不出這個差別；而他自己選的動詞會說出來。**

所以兩種難要往相反方向調：A 的那個要留下（136 題只有 3 題走到「做一個」那一階），
B 的那個要減——而減的不是內容，是強調與重複。

## 量出來的：不是「寫太多」，是「一直被打斷」

```
沒有被標記過的文字，一段中位 14 字       而一句中文是 20–25 字
全庫 69 課的全距只有 9–22               → 不是幾課走鐘，是文體
小節中位 71 字，781 節裡 538 節不到百字   → 沒有任何一節超過 600 字
```

> **當每三個詞就有一個被標成重點，讀者就建不出層次——他只好每一句都用力讀。
> 那讀起來正是「很詳細」而且「有點難理解」。**

## 🔴 而那些強調不是憑空來的——上一條護欄的帳單記在這裡

第 2 課「四種基本型別」那一節裡的「`//` 是註解」，是**「課文用了還沒教過的
東西」那次稽核（63 筆）補進去的**——而它加在**最近的那一節**，不是它自己的位置。
於是那一節標題說一件事，實際教四件（四種型別／`bool` 印成 1／`//`／單雙引號），
而四件都標成重點。

> **一個只錨住「正確性」的檢查，它的修法會在「可讀性」那一側收費
> ——而那一側沒有人數著。**

⚠️ 而「沒有人數著的維度會單調地變差」——前五課還撐得住（學生說「有點」難理解），
66 課累積下去不會。

## 做了什麼

```
硬性零   程式碼註解與表格逐字說同一句話 —— 7 節 → 0（冗餘效應）
前五課   中位喘息 11–16 → 19–22 字，粗體 154 → 81
護欄     第一百三十條 `audit-lesson-emphasis`（棘輪：55 / 69）
```

⚠️ **門檻 20 字是量出來的**，不是挑一個好看的數字：這幾課的句長中位是 22–27。

## 🪦 而這一刀的每一個判準都被偽陽性修正過一次

```
「有註解的程式碼 ＋ 表格」＝冗餘        38 節 → 逐字比對之後只有 7
比對跳不跳表格第一欄                   不跳 → `# str` 對上 `| str |`（那是交叉參照）
共同子字串只看註解那一邊                → `改第一個` 對上「拿掉第一個等於 v 的」
「引言裡的粗體是第二層強調」            🔴 **錯的**——課文頁的 blockquote 是灰的
```

最後那一條差點讓我砍掉 212 個粗體。查證只花一個 grep：
`blockquote{…color:var(--muted)}`。

> **一個「這裡重複標了兩次」的判斷，要先去看那兩層【在畫面上長什麼樣】。**

## 🪦 兩個自己造成的意外

**① 一次機械的減法，把剛加上去的東西一起減掉。** 我用正則把清單行的粗體
全部拿掉，而它打到了第 4 課的**齒輪三步驟**——那是同一個工作階段裡為了
「有同學還是看不懂」才加上去的「手往哪裡點」。已還原。

> **一次機械的減法不會分辨「修辭」與「功能」——而它不會出聲。**

**② 一個測試檔的排版，變成另一條護欄的輸入。** 新護欄的檔頭寫了字面的
三連反引號，讓整個檔的反引號配對錯開一位，於是生出橫跨數十行的假「程式碼片段」
——被第三十一／五十三／七十二條當成 C++ 語料吃進去（+3 段，而其中一段
讓「語法形狀全都要有判定」那條硬性零變紅）。

修的是來源不是基線：正則改用 `\x60`，圍欄用 `'\x60'.repeat(3)` 組出來。

## 🪦 而兩份實作對不上的時候，我差點直接調基線

同一份課文，Python 量到 58 課不合格、TypeScript 量到 69。差異有兩個，
兩個都是**實作細節而不是判準**：

```
界標用空白      課文裡本來就有空白（`⏱ 約 15 分鐘`）→ 每個空格都算一次打斷
中位數的定義    偶數筆時 Python 取平均、TS 取上中位 → 差 3 課
```

> **兩份實作對不上的時候，先找出哪一份錯了
> ——調基線是把錯的那一份寫進歷史。**

## 還開著的

🟢 **「程式碼憑空出現」那一族已經清完**（2026-09-16，六軌 190 節）
——第一百三十一條從棘輪升級成硬性零。而它**順帶**把喘息從 55 推到 52：
那 190 句引言都是平文。

> **一個維度的修法會在另一個維度收費（本文上面那一段），
> 而它也會在另一個維度找零——兩者都不是設計出來的。**

🟠 **而「字太多」那一族仍然只做了前五課**，其餘 64 課沒動（棘輪 52 / 69）。
🔴 而**下一步不是繼續往下清**：這把尺量的是「被打斷幾次」，
量不到「他有沒有比較看得懂」——要拿前五課去問**同一批學生**。

> **一個沒有回到人身上驗證的可讀性指標，量的是作者的自律，不是讀者的理解。**
