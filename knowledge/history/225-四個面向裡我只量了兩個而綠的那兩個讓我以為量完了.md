# 四個面向裡我只量了兩個，而綠的那兩個讓我以為量完了

**日期**：2026-09-10
**觸發**：使用者「`vector<int> C(n+1) , V(n+1);` 這邊會錯」，接著「**你到底有沒有整個仔細測過一遍？**」
**答案**：沒有。

---

## 我量了什麼，沒量什麼

前一輪（[[223]]／[[224]]）拿學生的競賽練習當語料，量到 144 支走樣、修到 2 支，
並且在 `history/224` 裡**親手寫下**這一句：

> 渲染那條路的測試產出的是 **BlockState（JSON）**——它對「Blockly 建不建得起來」
> 一個字都沒說。

然後**沒有把它套回那份語料**。

> **一個你剛寫下來的教訓，如果沒有立刻套回手上這份輸入，
> 它記的是「我知道有這回事」，不是「我檢查過了」。**

補完之後，一個宣告其實有**四個面向**：

```
① 產出的程式碼      lift → 產碼            ✅ 前一輪量了
② 語義的不動點      lift → 產碼 → 再 lift  ✅ 前一輪量了
③ 載得進工作區嗎    render → Blockly load  🔴 沒量  → 218 支裡 2 支【一片空白】
④ 走一趟積木回來    render → extract → 產碼 🔴 沒量  → 37 種形狀掉資料
```

⚠️ ①②綠而③④紅——而**使用者看得到的是③④**。

---

## 🔴 而我的量測工具自己有三個洞

追這一輪的過程裡，**有三次紅是探針壞了，不是產品壞了**：

```
215/218 支載不進去    → 我沒註冊 `cpp_return_types` 這個下拉來源
300/300 組編不過      → macOS 的 clang 沒有 `bits/stdc++.h`
每一支都產出空字串    → 我的抽取沒有沿著 `next` 走完整條鏈
```

還有兩次是**判準太鬆**：

```
把 `n+1` → `n + 1` 算成缺陷      → 排版是產生器的，不是缺陷
把 `int a(n), b(n)` 算成正確     → `b` 沒有人用，所以掉了也看不出來
```

🟢 最後定下來的判準有三層：

1. **先問參照編譯器「這一段是合法的 C++ 嗎」**——不問的話，`stack<int> a(5)`
   （沒有那個建構子）會被算成缺陷，而那是我造的雜訊
2. **每一個宣告的名字都要被觀察**（`cout << sizeof(a)`）——不然「第二個宣告子
   蒸發」驗不出來
3. **文字不同 ≠ 錯**：兩邊都編得過而且輸出相同，那是投影不是缺陷
   （236 個合法組合裡有 121 筆是這種）

> **一個量測工具，在它自己被量過之前，它報的數字只是它自己的形狀。**

## 找到並修掉的（全部是既有缺陷）

```
vector<int> C(n), V(n);      →  vector<int> C(n);     第二個蒸發（整句被讀成函式的前置宣告）
int a(n), b(n);              →  int a(n);             同上，而型別沒有膠囊時走另一條路
string s(n, '0');            →  string s = n;         第二個建構引數蒸發，而且編不過
deque<int> d(n);             →  deque<int> d = n;     走一趟積木掉了「建構子形式」
stack<int>& r = a0;          →  stack<int> & r;       參考的初始值蒸發，編不過
int a[10], b[20];            →  int a, b;             走一趟積木掉了兩個大小
int* p, * q;                 →  int p, q;             走一趟積木掉了兩顆星號
cc[A[i]];                    →  一片空白              沒有敘述形態的運算式當語句用
return c; // 保底             →  一片空白              `return` 沒有下接點，而註解接在它後面
LiquidCrystal lcd(12,…,2);   →  殘差                  🔴 這一筆是我當天修出來的（見下）
```

---

## 🔴 而我在修的過程裡自己弄壞了三次

一、**「跳過接不上的積木」讓一課的參考解答變成無窮迴圈**。
`讀到 0 為止` 那一課少了一句，e2e 跑了 16.9 分鐘才逾時。
🟢 改成「接不上的**放成另一顆頂層積木**」——Blockly 的浮動積木是合法的，
而它在畫布上分開的樣子**正是它在程式裡的樣子**。

> **「硬接」與「丟掉」都是在替使用者決定；把它放在旁邊是把決定留給他。**

二、**「宣告說得下幾個就放幾個」把六個腳位的液晶整句降級成殘差**。
那幾顆 Arduino 元件的 `initializer` 寫的是簡寫（一個），
而**它們的真實契約在 `ctorCount` 那一格上**。

> **一個接點能裝幾個，可能寫在別的地方——
> 只讀一處就下判斷，會把「宣告過了」讀成「沒宣告」。**

三、**把殘差當成宣告子**塞進多宣告子裡，產出 `string x, x;` 這種垃圾。

> **降級要降在一個【自己站得住】的單位上。**
