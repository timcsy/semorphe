# 282 — 協定從一個主體變成三個，而拆的過程量到兩件看不見的

**2026-09-25／26** · 第 233–239 刀 · **零行產品碼**

使用者一句話開始：「**我想把我們的協定好好的整理一遍**」。

## ① 先量：協定住在三個地方，而沒有一個是協定的形狀

```
concepts/元件.md                816 行   骨架停在 2026-08 的五槽時代
draft/2026-09-22-契約化.md     3006 行   實際的協定住這裡,而它是【日誌】
349 顆 component.json                    兩邊都沒完全實作
```

`元件.md` 裡「契約」二字出現 **5 次，而沒有一次在講協定**（全是引用或散文）。
draft 是按**我學到的順序**排的，它的 §終點自己標著「今天最好的猜測」，
**而那一節已經比同一份檔案的 §十二（收斂後的結構）舊**。

## ② 四條不一致，而第一條是「五槽已經不是五槽」

```
2026-08  身分 · 接點 · 參數 · 形態 · 行為
2026-09  身分 · 埠  · 參數 · 形態 · paths(六路) ＋ pre/post/invariants
```

`接點` 已拆成 `slots`＋`ports`（`relation` 搬去邊），而契約三欄**不落在五槽任何一格**。

## ③ 四條判決

**投影是三族不是兩族。**`元件.md:488` 寫著「兩族並列」，而 draft:469 寫著
「證明義務是**第六條投影**」。`contract.cella` 不是「長什麼樣」也不是「做什麼」。

```
不是形態   用／提及   形態是同一句話的另一種寫法;形式是【關於】那句話的一句話
不是行為   一次／所有  行為吐一條軌跡;形式吐一個對所有輸入成立的敘述
```

🟢 而三族有**機械的簽名**，不必靠語感：

```
形態   成對、可逆   lift ↔ generate · render ↔ extract
行為   單向        execute   → 一條軌跡
形式   單向        formalize → 一個命題
```

**形態成對是因為它保存語義**；另兩族單向，因為它們產出的是**關於**語義的東西。

---

**契約不是第六槽，是加在槽上的精化**（`{x : T // P x}`）。
走過「第六槽」與「橫跨五槽的第二維度」兩個錯答案，而決定性的測試是**產物不同**：

| | 問什麼 | 產物 |
|---|---|---|
| 槽 | 填得出嗎 | **剪枝力**——填不出就剪掉 |
| 契約 | 填了有沒有人判 | **棘輪**——數得出來、只能往下 |

叫它第六槽，剪枝規則就是「填不出契約 ⟹ 不是元件」——**而 349 顆今天一個判定者都沒有**。
而「一個維度」也不對，戳破它的是 `invariants`：**它的宿主有兩個，第二個不在元件裡**。

---

**一個視圖的第一等公民，是它的編輯動作操作的東西。**

```
積木   把一顆元件放進一個槽   ⟹ 蘊含「恰好一個父」＝ 組合律
流程   從一個接點拉一條線     ⟹ 沒有那個限制
```

⟹ **積木做不出非組合的關係，不是因為畫不出來，是因為拖不出來。**

---

**粒度換的是結構，不是關係。**使用者問「是不是不同粒度關注不同連接形態」——
一半對。把粒度 × 關係填一遍，**九格都有東西**（組合在粗粒度有 URDF link；
守恆在細粒度有 Rust 的 move）。

## ④ 🔴 而拆的過程量到兩件本來看不見的

**其一：一整章關於「邊」的內容，在目錄上是「命名」的子節——持續了一年。**
`元件.md` 的 203 行關係律是 `###`，掛在 `## 命名` 底下。搬出去才看見。

**其二：同一份文件裡，同一句主張寫了兩次，而更正只改了它撞到的那一處。**

```
:295   🟢 改了   「結構與關係正交」那張表（2026-09-25）
:736   🔴 沒改   「組合＝樹 · 資訊＝有向邊 · 守恆＝網」原封不動
```

⚠️ 而它還有**第三個位置**：`vision.md` 的「分子」那一格寫著
「擁有 → 樹（積木／組裝），連接 → 圖（流程／接線）」——第 239 刀才改到。

> **一次更正只改它撞到的那一處；而另一處會安靜地繼續當對的來源。**

## ⑤ 組裝那一檔今天最誠實的內容是缺口清單，而四個零不是巧合

```
src/ 的 Edge／Net／Assembly 型別    0
"ports"  "relation"  "invariants"   0 / 349
```

今天的 `children` 全是**組合**關係，而組合是三種關係裡**唯一不需要組裝層**的那一種。

> **我們實作的那一種關係，恰好是不需要這一層的那一種
> ——於是這一層的缺席，一年來沒有任何東西會因為它而變紅。**
