# 135　通用桶歸零，而它一路照出九個執行期的錯

**日期**：2026-08-23 ｜ **交付**：Python 19 顆新元件（79 → 98）＋ 通用桶 36 → 0
**前一則**：[134](134-投影裝不下的那一格.md)
**觸發**：使用者——「把剩下的積木做完」

## 起點：一個**只被數過數量、沒有被對過答案**的桶子

第五十條護欄的五軸在 [134](134-投影裝不下的那一格.md) 之後是這樣的：

```
答案不同 0 · 執行失敗 0 · 來回不同 0 · 降級節點 0 · 通用桶 36
```

前四個零很好看，而**第五欄不是零**：36 個節點在語義樹上叫 `python:func_call`
——`.format`、`map`、`isinstance`、`.sort`、`.index`…它們**跑得動**，
而學生在積木上看到的是一顆泛用的呼叫積木。

> **一個掉進通用桶的呼叫仍然會被執行——而那份執行沒有人在對答案。**

這一則的九個 bug 全部藏在那句話裡。

## 做法：先問「是不是既有元件的邊界太窄」

21 個名字裡有 **3 個不該開新元件**：

| 名字 | 真正的問題 |
|---|---|
| `set(xs)` | 轉換那顆的名單裡沒有 `set`，而理由（「這個直譯器沒有集合型別」）**前一天就過期了** |
| `enumerate(xs, 1)` | 配序號那顆只收**一個**引數 |
| `xs.sort()` | 排序那顆只認 `sorted(...)`——而**就地排序改的是自己，回的是 `None`** |

其餘 18 顆是新的（19 顆連同後來補的集合加入）。

## 而**寫完之後**才是這一則的重點

模糊測試的**資訊隔離出題者**（看不到這個 repo）寫了 10 段中級 Python，
用真的 `python3` 對答案。第一次跑：**PASS 2、答案不同 2、跑不動 6**。

九個根因，全部當場修：

| 症狀 | 根因 |
|---|---|
| `"-7".zfill(5)` → `000-7` | 補零沒有把符號留在最前面 |
| `round(10.0, 2)` → `10` | 給了位數還回整數型別 |
| `map(f, "ab", [1,2])` 每一格第二個引數都是 `None` | 只讀第二個引數，不吃多串 |
| `filter(None, xs)` → 「這個東西叫不動」 | 沒有處理「判斷式是 None」這個慣用寫法 |
| `" ".join(f(x) for x in xs)` → `x` 沒宣告 | **裸的產生器被當成兩個引數** |
| `d.pop(k)` → `xs.splice is not a function` | `pop` 只當串列處理 |
| `repr`／`.setdefault`／`.add` 不存在 | 內建表的缺口 |
| `{1,2} & {2}` 整段降級 | 集合的四個運算沒有 |
| `def f(coins=(25,10,5,1))` 跑不動 | 預設值只認純量字面 |

🔴 **其中一個是這一輪自己造成的**：早些時候修「`xs.pop(0)` 忽略位置」時只想到串列，
而字典也有 `.pop`——**模糊測試在同一輪之內抓到同一輪的迴歸**。

## 兩條這一天付學費付出來的教訓

### 一、裸的產生器不是一個清單

```python
all([x > 0 for x in xs])     arguments 是 argument_list，底下一格
all(x > 0 for x in xs)       arguments 【就是】 generator_expression 本身
```

照 `namedChildren` 去數會數到**兩個**（本體與 `for` 子句），於是
「引數數量不合就讓路」把一個完全正常的呼叫踢進通用桶——**跑得動、印得對，
而身分沒了**。26 顆膠囊共用一份 `pythonCallArgs` 之後才一致。

⚠️ 而它還有第二層：同族的兜底有一筆**帶限制的樣式**（優先級 80）專門接那個形狀，
而**帶限制的樣式與簡單樣式的數字不可以直接比**——九顆會吃產生器的元件
各補了一筆同樣帶限制的樣式，才搶得回來。

### 二、一顆專屬元件會**搶走使用者自己的方法**

語料裡有 `class Counter: def add(self, k)`，而集合的 `.add` 當天剛做成元件
——於是 `c.add(3)` 走進內建表，收到「串列沒有 add」。

> **一顆認名字的元件，認的是【所有】叫那個名字的呼叫，
> 包括使用者自己定義的那個。**

修法是既有的做法（`cast`／`enumerate` 早就這樣寫）：**讓路發生在執行期**
——先問使用者定義的類別方法，再回內建表。12 顆新元件一起改。

## 收尾：同一族只做了一半的那三個運算子

`&`／`|`／`^` 收了（集合與位元）之後，`~`／`<<`／`>>` 留在外面
——**一個「同一族只做了一半」的狀態**，而它讀起來像一個決定。當天一起收掉：
`python:bitwise_not` ＋ 移位進算術那顆。

🔴 **移位不用 JS 的 `<<`**：它先把數字截成 32 位元，而 Python 的整數沒有位寬
——`1 << 40` 在 JS 的 `<<` 底下會變成 256。同一條理由讓 `~x` 寫成 `-x - 1`。

⚠️ 最後留下的**具名邊界**只剩一個：預設值是一個**呼叫**時
（`def f(x=g())`）執行期出聲——容器字面已經收了。
