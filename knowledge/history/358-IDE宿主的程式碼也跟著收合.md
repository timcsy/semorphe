## 三個刻意的限制

| 限制 | 為什麼 |
|---|---|
| **單向**：IDE 裡自己摺，積木不會跟著收 | VS Code 的 API 沒有「摺疊改變」的事件——看不見就不猜 |
| 只在這份文件是**使用中的編輯器**時摺 | `editor.fold` 作用在使用中的編輯器；別的檔在前面時摺下去會摺錯檔 |
| 只展開**自己摺過的**、沒變就不重送 | 使用者自己摺／展開的看不見，重送會把他展開的又摺回去 |
