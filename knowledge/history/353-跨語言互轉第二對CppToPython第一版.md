## 三個選擇

1. **換法產出原始碼、不組 Python 的語意樹**（research R7，實作時改的）：Python 的元件幾乎都是 JSON 宣告的 lift，TS 建構子只有一顆；
   產出原始碼、交給 Python 自己的 lift 畫積木——它同時是第二道檢查（換出來的碼 lift 不回乾淨的 Python 樹，就是換法錯了）。
2. **每顆 C++ 元件的 Python 寫法住在它自己的膠囊**（`to-python.ts`），收集器依膠囊目錄對回身分——膠囊不寫自己的身分（就近性護欄）。
3. **整支換或不換**：第一對能逐行保留，是因為 C 與 C++ 同一個文法；Python 程式裡不能留一行 C++。

## 意思會變的地方（每一條都由 Cella 的判決證明，不是我們宣稱）

| 構造 | 決定 |
|---|---|
| 整數除法 | `int(a / b)`——向零截斷同 C++（32 位元 int 的浮點商在 2^53 內精確）；**不是 `//`** |
| 取餘數 | 只在與 0 比較時換（正負號不影響）；其餘保留 |
| 無號整數的除法（`sum / v.size()`） | 保留——負數時 C++ 繞回（有定義的行為），Python 不會 |
| 整數溢位 | 判決有 `ubOverflow` ⟹ 保留（只認這一種：沒有輸入時讀輸入的程式也判 reject，`ubUninit`） |
| char 參與運算 | 保留 |
| 輸入 | 同 cin 的讀法（`next_token()` 跨行讀詞）——原本「一句讀一行」對不上課文的輸入，量到後撤回 |
| 浮點輸出 | `format(x, "g")`（同 cout 預設）；bool 印 `int(…)` |
