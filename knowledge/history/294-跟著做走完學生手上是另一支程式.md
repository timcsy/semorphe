# 294 · 跟著做走完，學生手上是另一支程式

> 日期：2026-09-29（第 270 刀，使用者帶學生上課時發現）
> 使用者逐字：「06 算一算的跟著做最後完成的樣子是錯的，**這很嚴重**。」
> 轉變：第 6 課的 §三 §四 明確標成「試一下」，〈完成的樣子〉說出「這才是要交的那一支」。

## 我先前把它歸類錯了

第 269 刀我把這一件歸進「② 這張圖不該存在（反例被畫成積木圖）」。
而**它不是反例**，是更硬的東西：

```
課文頁的順序
  §一 換掉裡面的值   int score = 95; score = 100;        ← 跟著做
  §二 = 不是等於     score = score + 5;                  ← 跟著做
  §三 五種運算       int a = 7, b = 2; 五行 cout          ← 【另一支程式】
  §四 開根號與次方    cout << sqrt(16); cout << sqrt(2);   ← 【又一支程式】
  完成的樣子         int score = 95; score = score + 5;   ← 回到 §二
```

而編輯器裡「跟著做」**只有一個裁判**，它要的是 `分數是 100`。

⟹ **學生照著頁面一路打下來，最後手上是 `sqrt`——那一關永遠過不了。**
而頁面上最後一張積木圖畫的正是那支 sqrt。

🔴 **而它不只第六課**：「最後一步整段不在〈完成的樣子〉裡」的是 **23 / 69 課**。

## 🔴 診斷錯在哪裡，值得記

我是從**產物**（10 張含 ❌／💥 的圖）反推母體的，於是把整個 ② 讀成「反例」。
而第六課那兩節**一個反例標記都沒有**——它們是正當的示範，
問題不在它們是不是反例，在**跟著做是一條線而課文是四段各自獨立的程式**。

> **從一批產物裡挑出最醒目的那一族來命名整個問題，
> 會讓不長那個樣子的其餘成員留在原地——而它們可能才是嚴重的那些。**

⚠️ 抓到它的不是護欄，也不是我的量測，是**使用者站在學生旁邊**。

## 這一刀（A）：說清楚，不改結構

照使用者給的判準（2026-09-29 逐字）：

> 「如果要有，後面必須**明確說要移除積木**，或是說**這段積木只是示範**，
> 又或者可以**改課程**去符合這個需要。」

第 6 課取第二種 ＋ 第一種：

```
§三 開頭     ⚠️ 這一段是【試一下】,不是〈跟著做〉要交的那一支
            五種運算各看一次結果,看完把它清掉,回到上面那支 score 的程式
§四 開頭     ⚠️ 這一段也是【試一下】—— pow 與 sqrt 看過就好,不要留在程式裡
完成的樣子    🔴 這才是〈跟著做〉要交的那一支。第三、四節那兩段是試一下的
            ——如果它們還在編輯器裡,清掉,只留下面這一支
```

## ⚠️ 而護欄當場擋下我一個錯字

我把「完成的樣子」寫成 `〈完成的樣子〉`，而 `〈…〉` 這個記號**整個屬於題目名字**
（產生器會替它長一顆按鈕）。`audit-lessons` 的「題目名字對不上」當場紅。

那條護欄的檔頭逐字寫著它為什麼存在：

> **一個打錯的標記如果只是少長出一顆按鈕，
> 作者會看著那句話想不通，而沒有任何東西告訴他哪裡錯。**

## 還沒做的（B）

而那會動到 40 課。留給下一刀，要人拍板。
