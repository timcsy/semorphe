# 一門課教「哪一種比較快」，而它的裁判只問「答案對不對」

**日期**：2026-09-07 · 使用者放行的三項（① 效率的回饋 · ② 無名積木的判定 · ③ 說一次）

## 一、效率的回饋

### 轉變

```
舊  跑完 → 輸出對不對（二元）
新  ＋「這一趟走了 N 步」，而第二次會說它是上一次的幾倍
```

### 🔴 它補的是一個【教材已經在教而沒有回饋】的落差

`cpp-advanced` 第 1 課逐字：

> 題目會告訴你「n ≤ 100000」這種話——而那句話**直接決定你可以用什麼做法**。

而在此之前，O(n²) 與 O(n log n) 的兩份解答**在畫面上長得一模一樣**：
兩個都印出對的答案，兩個都得到一個綠勾。

> **一門課如果教「哪一種比較快」，而它的裁判只問「答案對不對」，
> 那學生學到的是「兩種都可以」。**

### ⚠️ 「一步」刻意是【我們真的數得到的那個】

```
一步 ＝ 直譯器走過一顆語義節點一次
```

🔴 那**不等於**課本的「基本操作次數」（`a[i] + a[j]` 在這裡是好幾步）。

> **一個量給學習者看的數字，寧可它「不是課本的定義」而說得出自己是什麼，
> 也不要它「像課本」而沒有人講得出它怎麼算的。**

### 三個界線

- **只在課程宣告的題目上說話**（`tasks[].compareSteps`）——它是一句給
  「這一題有兩種寫法」的話，在其他題上是雜訊
- **差 25% 以內不提倍數**——那是同一種做法的雜訊，而一句每次都出現的話
  會讓主控台變成沒有人讀的日誌
- 🔴 **說的是任務，不是這個人**：「這一版走了 8 倍的步數」，不是「你變慢了」
  （`draft/課程重新設計` §十一：「說到人就砍掉」）。**一條測試驗文案裡沒有「你」。**

🟢 而**執行器一行都沒改**：`execution:coverage` 早就帶著完整的 `counts`，
組裝點自己算得出來——**執行器不必知道「哪一題」**。

## 二、無名的積木：從「隱含扣掉」變成「宣告的判定」

族二扣掉了一批積木（畫面上只有佔位符）。而**扣掉一批東西要有人說得出理由**：

> **一份沒有理由的排除清單，與一條被關掉的護欄，
> 在第二天之後是同一個東西。**

13 顆逐一判定，三種理由：

```
名字在下拉裡   10 顆   `cpp:increment` 的名字是「加 1（++）」，而積木上只有 `%1 %2 %3`
名字是一個字     2 顆   「取」「對」——而單字當比對鍵會誤中每一課
形狀就是名字     1 顆   `python:splat` 畫的是那個星號，**一個中文字都沒有**
```

護欄**兩個方向都驗**：沒有判定的無名積木 → 紅；判定過期了（它現在有名字了）→ 紅。

### 🪦 而我一度把判準改錯，又改回來

我一度讓護欄**連下拉的選項也算**——因為 `cpp:increment` 的名字確實在下拉裡。
收進來之後族二多了 14 筆，而**那 14 筆多數是誤報**：

```
cpp:arithmetic 的下拉有「餘數／左移／右移」   而那一課只用加減乘除
python:literal_bool 的下拉有「沒有值」        而那一課只教 True／False
```

> **一個下拉裡的選項，是使用者【選了才會出現】的字
> ——要求課文提到每一個，等於要求它教完那個下拉。**

## 三、說一次「這個工具會怎麼跟你說話」

產品已經有預測、裁判、執行覆蓋、×N、解鎖——**而沒有一個地方告訴學生**。

⚠️ 而它**只在三條入門軌的第 1 課各講一次**，其餘 63 課不提
——`history/215` 記過：「**不要把怎麼用抹在 66 堂課上**」。

而那一段的最後一句是刻意的：

> 🟢 而**沒有分數、沒有等級、沒有排名**。這個工具只會說**那件事怎麼樣了**，
> 不會說**你怎麼樣**。

🔴 它把一條**設計原則**變成一句**對學生的承諾**——而那讓它更難被推翻。
