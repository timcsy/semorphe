# D 命名空間遷移：身分不只以字串字面出現

**日期**：2026-08-08 ｜ **spec**：`specs/103-namespace-migration` ｜ **狀態**：已完成

## 轉變

177 顆元件身分從 `cpp_vector_declare`／`if` 變成 `cpp:vector_declare`／`lang:if`。
`scope` 表示**所有權**，不是分類也不是位置。

| | 前 | 後 |
|---|---|---|
| 有命名空間的身分 | 3 / 177 | **177 / 177** |
| 舊格式引用 | 3251 處 | **0** |
| 積木型別指紋 | 186 顆 | **186 顆（不變）** |
| 存檔版本 | 2 | 3（附一次性轉換） |

## 主教訓：**身分不只以字串字面出現**

整個遷移的難度不在「改 3251 處字串」，在於**有十類身分根本不是字串字面**，
而 AST 掃描器只看得到字串節點。

| 類 | 例 | 壞掉的方式 |
|---|---|---|
| 裸的物件鍵 | `cpp_isalpha: (c) => …` | 是 Identifier；四顆概念變「孤兒實作」 |
| 正則裡的形狀 | `/^cpp_(\w+?)_declare$/` | 型別追蹤靜默失效 |
| 模板字串 | `` createNode(`cpp_string_${m}`) `` | 兩顆概念建不出來 |
| 型別聯集 | `UniversalConcept = 'if' \| …` | 24 顆 |
| 測試標題 | `[BLOCKED:cpp_xxx]` | 缺陷帳的阻斷者指不到 |
| 產出的程式碼文字 | `g.set('endl', () => 'endl')` | 產出 `cout << x << lang:endl;` |
| JSON 的 `routes` 值 | `routes['+'] = 'arithmetic'` | 運算式全部辨識不出來 |
| AST 節點型別夾具 | `mockNode('number_literal', …)` | 91 處 |
| 拿身分形狀當判斷 | `if (concept.includes(':')) return` | 單步除錯完全失效 |
| 與積木型別同名 | 66 顆，`cpp_class_def` 兩者皆是 | 改錯邊積木會消失 |

> **凡是「這個字串是什麼」需要靠人讀上下文才知道的地方，工具就看不到它。**

最值得單獨記的是第九類。那一行 `if (concept.includes(':')) return` 原意是
「語言專屬的概念不算除錯步驟」——它**把命名慣例當成了契約**。命名慣例一改，
它安靜地變成「什麼都不記錄」。而它本來就是多餘的：真正的閘門是 `debug_step` 標註。

## 分段是對的，而它的價值兌現在第三輪

第 ① 段跑了三輪：失敗數 **128 → 62 → 20 → 0**。每一輪都**回退整段**、
改遷移器、重跑，而不是就地補。三輪都靠回退才找得到根因——就地補會把
五類漏網變成五十處各自的修補。

`draft/2026-08-07-元件目錄與膠囊契約.md:187` 說的「紅得無法歸因」不是修辭：
089 的 560 處機械改名出錯三次，這次是它的 6 倍。

## 一個做錯的方向，值得記

第 ② 段（裸名）先試「只改角色分類得出的位置」——**952 支測試紅**。
裸名的身分引用有約 800 處落在分類器涵蓋不到的形狀（陣列、對應表），
**半套遷移比兩個極端都糟**。

改回第 ① 段驗證過的策略：**列舉「確定不是身分」的位置，其餘一律改**。
那份 deny-list 是量出來的（殘留 874 筆分桶，真正的非身分只有 14 處）。

⚠️ deny-list 誤擋了一筆，而**抓到它的是 C3 的引用完備性護欄**，不是我。
那條護欄（spec 101）在這裡第一次證明了它的價值：它掃的是執行期建出來的身分，
不是字串，所以它看得見掃描器看不見的東西。

## 中立性護欄擋下了一個設計錯誤

第一版把 174 筆改名表寫進 `src/core/storage-version.ts`，中立性當場報 **284 筆違規**。

那不是護欄太嚴。一個把 `cpp_vector_declare` 寫死在核心的檔案，就是核心認得
C++ 了，而下一個語言進來時沒有人會記得回來改它。

改成**核心給機制、套件給資料**（`registerIdMigration()`）。
登錄式機制天生有「機制有了沒人接上」的病，所以同時交付了涵蓋率檢查。

## 我自己的護欄指標第一版是錯的

「`blockDef.type` 落在身分清單中的處數」，基線 66。它**在遷移一落地就失效**：
身分變成 `cpp:x`、積木型別還是 `cpp_x`，交集自然歸零——它會在什麼都沒壞的
時候報 `66 → 0`。

> **量「兩個集合的交集」，量不到「其中一個集合有沒有變」。**
