## 一、GitHub 的星星按鈕，與它收掉的那條相依

使用者：「幫我做一個可以在 GitHub 給星星的按鈕」→「我還是想要星星 widget」
→「我要有 GitHub 的標誌」→「**我覺得不用把目前星星數寫出來**」。

🪦 而最後那一句收掉的比它看起來多：

```
有數字   要打 api.github.com → 第四十五條（離線可用）得從「硬性零」改寫成
         「只准是裝飾」＋ 一支「擋掉那個主機還要能用」＋ 具名豁免 ＋ 一份快取
沒數字   零外部請求，第四十五條【一個字都不用動】
```

> **一個看起來只是「少顯示一個數字」的決定，
> 收掉的是一整條相依、一次判準改寫、與一份快取。**

⚠️ 而它**做不到「按一下就加星」**（GitHub 沒有免登入的加星網址），所以它是一條
誠實的連結——與 `app-shell.ts` 那句「一個長得一樣而按下去沒反應的按鈕，
比沒有那顆按鈕更糟」同一條規則。

🔴 **宿主那側沒有多一格布林**：第六十三條護欄逐字「加一顆控制項，不得再多一格
布林——`HostFeatures` 只准下降」「那條路會爆炸，登錄表才不會」。改成跟著
**既有的宣告**走（`inToolbar('run')`：這個宿主自己畫不畫這條工具列），零新增欄位。

## 二、行動版：三個手勢都不能用，而根因是同一個

實測（400×780）：

```
100%    縱向可捲 = 0        直的完全推不動
縮小後  橫向也 = 0          整張圖完全推不動
刪除鈕  9×15 px，縮小後 6×9  比觸控建議值小五倍，而且【跟著縮放一起變小】
```

原生 `overflow: auto` 的捲動**只在內容比視窗大時存在**，而流程圖通常比手機畫面小。

> **「能不能移動畫面」不該取決於「內容夠不夠大」。**

🟢 改成 Blockly 的做法：內容掛在一個 `<g>` 的 `transform` 上，**畫布是無限的**。
只縮 `width`／`height`，**節點自己的座標一格不動**——存下來的佈局因此不會歪。

⚠️ 而三個手勢互相拉扯，`touch-action` 是那個結：

```
.flow-canvas  none          每一種手勢都由我們接（與 Blockly 一致）
.fc-node      none          不然按住節點拖曳會被判成「使用者要捲畫布」
```

## 三、🪦 兩個退場，各自帶著重開條件

### 三對「還原」收成一對

畫面上曾經有**三對**：程式碼工具列、快速列的 ↩↪、流程工具列的 ↶↷。

> **同一件事在同一個畫面上有兩個開關，是一個必然會不一致的東西。**

🔴 而**共用得了按鈕，共用不了歷史**：

```
code    一次打字（字元群組）——編輯器自己的顆粒度最好
blocks  一次工作區事件
flow    一次語義樹的改動（而版面位移根本不在樹裡）
```

三者的「一步」不是同一個東西。做法是**一對按鈕 ＋ 依「上一步在哪裡做的」轉送**，
而那個轉送**是近似的**（連按兩次可能跨到另一份堆疊）——這句話寫進了程式碼註解，
沒有假裝它是完美的。

### 「整份程式 ▾」那顆下拉

使用者：「這選單能不能先刪掉？現在好像還看不出有什麼用」。

它列的是「整份程式」＋每一顆有本體的頂層節點（也就是函式）。而**今天多數程式
只有 `main`**，兩個選項看到的幾乎一樣，卻在行動版佔掉工具列最寬的一格。

> **一個要等到「東西變多」才有價值的控制項，在那之前是純粹的成本。**

🔴 **重開條件**：一支程式真的有好幾個函式，而使用者說出「我只想看其中一個」
——**不是「又想到它了」**。⚠️ 而 `scopedRoot()` 那一層**留著**：它是「收窄範圍」
的接縫，重開時不必再挖回來。

## 四、而使用者的每一則回報都照出我做錯的地方

```
刪一顆換行整句不見   資料線的「下游」是消費者，不是孩子
節點沒辦法被選       preventDefault() 把 click 一起壓掉了
積木高亮傳不到流程   Blockly 對「點外面」也發 null，而我在下游猜它是哪一種
切回積木就沒了       我的修法「離開時順手收拾自己」
點空白處無法取消     我為了保住上面兩條，把整類 null 都忽略了
```

後三條是同一件事的三次嘗試，而**前兩次都錯在同一個位置**：

> **一個含混的訊號，要在【發出它的地方】被分辨清楚；
> 在下游猜它是哪一種，每一次都會少掉一個情況。**

🟢 Blockly 自己就分得出來：真正的「點空白處」有它專屬的事件
（`CLICK` ＋ `targetType: 'workspace'`）。改成在源頭分辨之後，四種情況一次都對。
