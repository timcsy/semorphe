# 185 · 生教材是一種測試——全綠的狀態下照出六個缺陷

**日期**：2026-08-28

## 轉移

- **舊**：「這個工具會不會壞」的答案是**測試套件**（5890 支單元 ＋ 53 支 e2e，全綠）。
- **新**：**把課綱做成教材本身是一種走查**，而它抓到的東西那個套件一支都看不到。

## 為什麼變

把課綱做成教材的那一輪，**在全綠的狀態下抓到六個缺陷**——
每一個都會讓一個學生照著課文做而卡住。

> **生教材是一次覆蓋率很不一樣的走查：
> 它逼你把每一個語言、每一個目標、從最簡單走到最進階各走一遍
> ——而那正是單元測試最薄的地方。**

## 六個

| # | 症狀 | 根因 |
|---|---|---|
| ① | **Python 的程式碼→積木整條不通**：`print(1)` 產出一棵空的 `python:program` | 組裝點一條樂觀簽章：`languagePack('python')?.styleExceptions?.analyzeIo(...)` 交出 `undefined`，而介面宣告「一定回傳」（`as never` 蓋過型別檢查），消費端直接 `result.verdict` → 崩潰被吞成空樹 |
| ② | `struct Node { Node* next; };` 丟出「**結構包含自己——要用指標**」 | lift 把星號放進**名字**（`name: "* next"`, `type: "Node"`）。`unwrapPointers` 的下降清單漏了 `field_identifier` |
| ③ | C 的 `struct Point p;` 執行時說「**變數 p（不是一個結構）尚未宣告**」 | 宣告的型別節點清單沒有 `struct_specifier` → `?? 'int'` 讓型別**靜靜降級成 int** |
| ④ | `strlen("hello")` 回報 **319** | 對一顆 char 陣列做 `String(val.value).length` → `"[object Object],…"`（20×15＋19 個逗號） |
| ⑤ | Python 的 `int("abc")` **不丟例外** | 走核心的 `toNumber`，而它是 `Number(x) \|\| 0` → 得到 0 不是 NaN。`try/except` 那一課整個教不了 |
| ⑥ | `Node* head = new Node;` 之後 `head->val` 說「變數 `[object Object]` 尚未宣告」 | `->` **只認得符號式指標**（`value` 是名字），對 `new` 配出來的那塊儲存體 `String(ptr.value)` 得到 `"[object Object]"` |

## 為什麼測試看不到它們

**六個的形狀完全一樣**：

```
lift 乾淨（零 raw_code）  →  積木長得正常  →  執行時才錯
```

單元測試驗的是「各語言的 lifter 對不對」與「各元件的 execute 對不對」，
**而沒有人驗那條組裝起來的路**。① 尤其明顯：Python 的膠囊測試全綠，
而使用者切到 Python 之後整個編輯器不會動。

## 留下什麼

- **`e2e/every-language-lifts.spec.ts`**——每個語言都要把一段最簡單的程式
  lift 成非空的樹，並且**主控台不得有被吞掉的崩潰**。注入驗過會報。
- **`e2e/lessons.spec.ts`**——52 堂課的程式碼與輸出，資料驅動，新增課不必新增測試。
- ⑥ **隔天修好了**，而它是這一條裡最值得記的一件事：

  > 我第一天把它判成「**指標存的是名字不是參照，那是設計層的缺口，
  > 不是一個小修**」，於是那一章沒有寫。
  >
  > 隔天真的去追，是**三個各自很小的修法**：
  > `new` 用 `defaultValue` 建結構（不認得）· `->` 只認一半的指標 ·
  > `toNumber` 對配好的儲存體回 0（於是 `p != NULL` 立刻不成立）。

  **「這看起來是架構問題」是一個假設，不是一個結論——而它讓人停止去看。**
  判準已寫進 [[write-lesson]]：判它之前，至少把錯誤訊息**追到丟出它的那一行**。

## 而量測工具自己也騙過我一次

量 Arduino 的輸出時，「每一批只有第一段印得出東西」的症狀
看起來像 `analogWrite` 有問題——**而根因是量測器沒有在每段之間重新載入**
（Arduino 的 `loop()` 不會結束，狀態殘留下來）。

決定性的證據是**結果與假設相反而且不自洽**：加了 `analogWrite` 的那段
印了 20 行，而最簡單的那段什麼都沒印。

> **一個把自己的狀態殘留算進結果的量測器，
> 產出的是一份看起來像發現的東西。**

（判準已寫進 [[write-lesson]] 的第 1 步。）
