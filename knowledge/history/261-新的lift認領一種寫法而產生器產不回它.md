# 一個新的 lift 認領了一種寫法，而產生器產不回那種寫法

2026-09-19｜管線 197 階段三（round-trip）｜刀口 194 → 197

## 一句話

> **形狀上是「多支援了一種語法」，實際上是「多了一種會壞掉的程式」。**

## 事情

第 194 刀讓 `cpp:cast` 多認領了兩種寫法：

```
寫的          tree-sitter 給的                                 它其實是
int()         call(function: primitive_type, args: [])         值初始化
(ll)(x+1)     call(function: parenthesized_expression, args)   C 風格轉型
```

驗收是綠的：`interpreter-matches-compiler` 新加的三條轉型測試全過，
全套 7465 綠，語料的「內容真的不同」從 7 掉到 5。**它合併了。**

三刀之後，197 的 round-trip 那一關拿語料重量面向①②，讀數是：

```
同一棵 216／218      走樣 2
```

兩支的原因是**同一個**：**產生器沒有跟上**。

```
寫的            產回去的        後果
int()           (int)           不是合法的 C++ ——再 lift 一次整段走樣
(ll)(x+1)*z     (ll)x+1*z       合法，而它算的是別的東西
```

## 🔴 為什麼 194 的驗收看不到它

那三條測試在 `interpreter-matches-compiler` 裡，而**那個檔只跑，不產碼**。

```
面向          194 有沒有量    結果
① 產出的程式碼     沒有        🔴 會紅
② 語義的不動點     沒有        🔴 會紅
⑤ 跑出來一不一樣   有          🟢 綠
```

⚠️ 而**那不是疏忽，是分工**：那個檔的職責就是⑤。缺的是
「**改了 lift 就要量①②**」這條連結——而語料的探針量得到它，
只是 194 那一刀沒有在改完 lift 之後再跑一次。

> **一個「新增了一種支援」的改動，它的風險不在它新增的那一路，
> 在它沒有一起新增的那幾路。**

## 同一族的第三、第四個

`(ll)(x+1)` 那個括號不是憑空來的，它是**運算元的優先級比轉型低**。
而同一個病在三顆一元運算子上一模一樣：

```
*(v.end()-1)    → *v.end()-1     pointer_deref
&(a+b)          → &a+b           address_of
~(x|y)          → ~x|y           bitwise_not
```

四顆全部用 `generateExpression` 而不是 `genChild(child, precedence(node), ctx)`。
括號原本靠 `layoutHints` 帶——⚠️ 而**積木上沒有 metadata**，
所以「走一趟積木回來」（面向④）就沒了。

> **一個靠排版提示帶的括號，在經過一次投影之後就不再存在
> ——而它保護的那個結合律仍然需要它。**

## 第五個：只錯在⑤那一路的那一顆

同一關順手量到 `ll(x)`（`#define ll long long` 之後的函式式轉型）：

```
(ll)(x+1)   🟢 cpp:cast       括號那一路問了 isTypeName
ll(x)       🔴 cpp:func_call  函式式那一路沒問  → 執行時 UNDEFINED_FUNC: ll
```

`ll` **早就**被標成 `kind: 'type'`（`lifter.ts` 的 `recordMacroAlias`），
而 `isTypeName` 在那之前只有**一個呼叫點**。

🔴 **它的①②③④全是綠的**——`ll(x)` 原樣吐回，一字不差。
語料 0 處，所以沒有任何一支語料走到它。

> **一個只錯在⑤那一路的缺陷，形狀是完美的
> ——而形狀完美正是它活下來的原因。**（這句話 2026-09-16 已經寫過一次，
> 而這一次它指的是**反方向**：上次是「形狀對而跑錯」，這次是同一句話
> 用在一顆**不會被語料走到**的缺陷上——它連「跑錯」都不會發生。）

## 判準（下一次怎麼不再犯）

**改了 lift ⟹ 五個面向全部重量一次，不是只量你新加的那一路。**
具體地說，`STUDYCPP_DIR=… npx vitest run tests/probes/studycpp-roundtrip`
（①②，十秒）是**最便宜的那一支**，而它正是 194 沒有跑的那一支。
