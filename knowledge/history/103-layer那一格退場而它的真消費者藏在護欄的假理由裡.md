# 103 — `layer` 那一格退場，而它的真消費者藏在一條理由為假的護欄豁免裡

**日期**：2026-08-20 · **spec**：`152-retire-layer` · **狀態**：完成

## 轉變

```
之前   233 顆元件每一顆都宣告 layer（universal 31 · lang-core 82 · lang-library 120）
       而生產路徑【零消費者】
之後   欄位、型別、getter、兩處抄寫點全部退場；一條護欄擋它回來
```

## 為什麼是現在

Python（階段 7）排期了。**不收掉的話，第二個語言要為它的每一顆元件再填一次
這個型別本來就不對的欄位。**

而「型別不對」這個說法來自 [draft/通解與特解](../draft/2026-08-20-通解與特解和小世界模型.md)：

> **齊次解是【算子】的性質，不是【解】的性質**
> ——「某個 `y` 是不是通解」這個問法本身不成立。
> 所以 `layer: universal` 是把**商空間的元素**寫成**某個元素的欄位**。

🔄 它比 08-11 那份 draft 的說法（「外延主張放在內涵位置」）更硬：
**不是寫錯地方，是型別根本不對。**

## 🔴 而「零消費者」差點又錯一次

前兩次的病歷：spec `144` 漏掉護欄、spec `146` 漏掉膠囊。
所以這次掃了 `tests/`——**掃出來一個真消費者**：

**中立性護欄**用 `layer` 把身分分成「語言專屬」與「universal」，
**只把前者算成違規**。它印出來的規則逐字：

> 「僅計語言專屬概念（lang-core／lang-library）；
> **universal 概念拔掉 C++ 後依然存在**，不妨礙 P9。」

🔴 **而那個理由是假的**：233 顆元件全是 `cpp:` scope，
`cpp:if` 拔掉 C++ 之後**不會依然存在**。

🟢 **而它今天豁免了 0 筆**（實測）。

> **一條理由為假、而目前沒有生效的規則——它不是無害的，
> 它是一顆等著在第一次被觸發時給出錯誤答案的地雷。**
>
> **而「豁免了 0 筆」正是拆它最好的時機：沒有數字要調。**

🟢 豁免拿掉之後護欄**更嚴**，數字仍是 0／0。
注入實測：把 `cpp:print` 放進 `src/core/concept-registry.ts` → **現在會紅**
（在此之前它是被豁免的）。

## 九支測試紅了，而它們不是證據

規格的 US1 先寫死了判準：「**若有測試紅，那是證據說我漏了消費者**」。
實際紅的九支**全部是測 `listByLayer()` 這個功能本身**，且用**合成資料**
——它們隨功能一起退場，並在原地留下為什麼。

⚠️ **這個分辨要在動手前寫下來**，否則事後很容易把「該退場的測試」
與「我漏了東西的證據」混為一談。

## 順帶：`concept-algebra.test.ts` 的 US8 少了一塊

那支測的是「元件代數」的三層查詢。**層級查詢退場之後，US8 的那一塊就沒有了**
——⚠️ 而 US8 的其他部分（父概念、等價）**沒有動**。
