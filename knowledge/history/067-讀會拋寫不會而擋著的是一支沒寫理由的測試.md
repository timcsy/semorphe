# 067　讀會拋，寫不會——而擋著修法的，是一支沒有寫理由的測試

> 日期：2026-08-15
> 觸發：第二課走完之後的坑清單（`specs/126`）。
> 本檔記的是**一個缺陷的分類被推翻**，不是交付了什麼（那在 spec `127`）。

## 轉變

```
old  `score = 90;` 沒有 int 也跑得完 —— 屬於「需要型別資訊」那一族，
     跟著 6.6 ⑤／6.7 ③ 一起被卡住
new  🔴 它【只需要已經存在的符號表】——Scope.get 早就會為同一件事拋錯，
     只有 set 不會。爆炸半徑實測 = 1 支測試

old  修它要動 32 個地方 / 需要一個被卡住的前置
new  🔴 一個方法、淨減少程式碼（拿掉一個 try/catch）
```

## 一、分類錯了，而沒有任何東西會發現

2026-08-15 我在 `vision` 收束 spec `126` 時寫下：

> 「⚠️ 後者屬於階段 6.7 的第三個缺口那一族（不是語法錯誤，**需要型別資訊**）」

**當天就被推翻**：

```
src/interpreter/scope.ts:33   get() 找不到 → 拋 UNDECLARED_VAR
src/interpreter/scope.ts:52   set() 找不到 → 【默默建立】
```

**讀會拋，寫不會。** 那個不對稱**與型別無關**。

> **一個被歸進「需要某個被卡住的前置」的缺陷，會跟著那個前置一起被延後
> ——而歸類錯了沒有任何東西會發現。**

⚠️ **它是被「量爆炸半徑」抓到的**，不是被讀出來的：
注入嚴格版跑全套 → **只有 1 支失敗**。
**沒有那個量測，這個提案會被當成大工程延後。**

## 二、而唯一擋著的，是一支把缺陷寫成規格的測試

```
tests/unit/scope.test.ts:64
  it('should set variable in current scope if not found anywhere')
  ← 8887e4d「Phase 2 foundational … TDD」，最早的地基階段
  🔴 沒有寫任何理由
```

> **一支沒有寫理由的測試，記的是「當時的實作」而不是「當時的意圖」
> ——而後來的人分不出這兩者，於是它變成一道看起來像決定的擋牆。**

⚠️ 而 TDD 產出的測試**特別容易犯**：它們是照著剛寫好的實作寫的。

**處置**：反轉它，並在測試裡寫下**為什麼**與**推翻它需要什麼**
——`只改斷言等於原地換一道同樣的牆`。

## 三、🔴 而只改最後一行，行為完全不會變

```ts
if (this.parent) {
  try { this.parent.get(name); this.parent.set(name, value); return }
  catch { /* 沒有，往下走 */ }
}
this.variables.set(name, value)     // ← 想改的是這一行
```

改成拒絕之後 `parent.set()` 也會拋，**而那個 catch 把它吃掉**。

> **一個為了「看看有沒有」而存在的 try/catch，
> 在被查的那件事本身開始拋錯的那天，會靜靜地把新行為吃掉。**

🔴 **而它看起來像修好了**：程式碼裡有一行 `throw`，而它永遠傳不出去。

→ 拿掉 try/catch，改成單純遞迴。**淨減少程式碼。**
⚠️ 而**單元測試看不見這條路徑**——spec 因此要求驗證必須是**行為端**。

## 四、教材第二次說謊，而這次比第一次嚴重

```
126  課文【沒說】要按「程式碼→積木」        漏講
127  課文說「不加 int 就會看到那句話」      🔴 講錯——實測它默默成功
```

**兩次都不是寫錯字，是把自己知道的事當成系統會做的事。**

> **寫教材的人知道【領域的規則】，而教材描述的是【這個工具的行為】。
> 兩者不同的那些地方，正是教材最容易說謊的地方——而作者最不可能發現。**

→ **課文裡每一句「你會看到 ○○」，都要有走查測試逐字釘住它。**
⚠️ 而那不是為了防止系統退步，是為了**當場抓出作者的假設**。

🟢 **而修好之後，那個繞路變成了更好的東西**：課文多了**第五步**
（讓學生真的試一次忘記 `int`），而錯誤訊息成了教學主軸。

## 五、限定寫在三處

> **不得宣稱「未宣告的指定不能跑了」——只能說「跑到那一行會停」。**

C++ 在**編譯時**拒絕，我們在**執行時**。寫在程式碼、spec、課文三處
（沿用 [history/064](064-量出來的東西不是我們要找的.md) 的做法：
「一句寫在四個地方的限定，拿掉它的成本也是四個地方——而那正是它值得的原因」）。
