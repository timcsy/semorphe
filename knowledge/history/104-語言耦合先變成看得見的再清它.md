# 104 — 語言耦合先變成看得見的，再清它

**日期**：2026-08-20 · **spec**：`153-language-coupling-visible` · **狀態**：完成

## 轉變

```
之前   護欄說「違規 0 筆」，而中立範圍裡硬編了 44 筆【積木型別】——它看不見
       視圖／UI 直接 import 語言套件 3＋2 處
之後   護欄有【兩個】數字：元件身分 0 · 積木型別 44（基線、只准降）
       視圖 3→0、其餘 UI 2→0，而「直接呼叫視圖」仍是 67（沒有把耦合換地方）
```

## 🔴 本來要清 5 個 import，而量了一次之後前提變了

中立性護欄掃的是**元件身分**（`cpp:print`），**不掃積木型別**（`cpp_print`）。

```
src/core/block-input-names.ts         9 筆  ← 在【核心】
src/core/projection/block-renderer.ts 2 筆  ← 在【核心】
src/ui/block-registrar.ts            33 筆
```

> **一條護欄如果只掃一種拼法，另一種拼法的耦合就對它不存在。**

⚠️ 而這與 `history/015`（「語言無關性從尚未驗證到已知是破的」）是**同一個病的第二次**
——那次也是「**因為第一次真的去量了**」。

🟢 處置：**先讓它看得見**（第二維、基線 44、只准降），**而不是先清它**。
44 筆的清償是 `block-registrar` 那 40 顆命令式積木，那是獨立的大工程。

## 🔴 第二維當場救了一個「假進步」

`block-registrar` 那三個 C 專屬常數，最短的修法是**搬進 `core/block-input-names`**
——而那個檔已經硬編 9 個 `cpp_*`。

```
搬過去   第一維（import）降   第二維（積木型別）升 9 → 12
```

**只看第一維的話，那會顯示成進步。** 注入實測：第二維會紅。
🟢 正解是**從組裝點注入**。

## 五個點各自的修法

| | 原本 | 修法 |
|---|---|---|
| ① | panel 的 `codeStyle = apcsStyle` | **刪掉**——`app.ts:218` 在建好之後**立刻**覆寫它。**一個立刻被覆蓋的預設值，買到的是耦合不是安全** |
| ② | panel 自己註冊抽取策略 | 改成**建構選項**——🔴 不是事後呼叫（那會多一筆「直接呼叫視圖」，且開一個「還沒裝」的窗口） |
| ③ | panel import `program/lift` | `buildProgramRoot` 建構選項 |
| ④ | registrar import 三個 C 常數 | 組裝點注入（**不是搬進 core**，見上） |
| ⑤ | sync import `style-exceptions` | `StyleAnalyzer` 由組裝點推進來；`StyleException`（完全中立）搬進核心 |

⑤ 的兩種做法**都論證過**：抽成核心通用機制 🔴 否決（「哪些算風格例外」是語言知識），
讓語言套件推 🟢 採用（與 `skip-declarations`／`comment-syntax` 同一個形狀）。

🔴 **而 `IoConformanceResult` 沒有搬進核心**：它帶著 `iostreamCount`／`cstdioCount`，
那是語言專屬的欄位名。改成中立的 `StyleConformance`（只有 `verdict`）：

> **視圖需要的是【判決】，不是【證據】。**

## 三條護欄在這一刀裡各抓到我一次

```
第四項獨立性   我用事後呼叫裝抽取策略 → 「直接呼叫視圖」67 → 68
語法耦合       我的降級字串寫成 `/* … */` → C 的註解記號跑進視圖層
中立性第二維   （注入驗證）把常數搬進 core 會被抓
```

🟢 第二個特別值得記：連「說不出來」都要用中立的說法
——專案已有 `UNGENERATABLE_PREFIX`（`⟨…⟩`）。

## 而 spec 152 留下的說謊報表也在這一刀修了

`audit-neutrality` 的 `RULE` 字串仍寫著已被移除的豁免——因為它在原始碼裡是
**兩個串接的字串字面**，152 的單一字串替換沒命中，**而測試是綠的**。

> **文案齊全，而沒有人查它**——這個專案第五次。

## ⚠️ 而它買到的不是「P9 通過」

`app.ts` 仍有 35 處語言 import（護欄明寫「可見，不入棘輪」），
中立範圍仍有 44 筆積木型別。

> **這一刀買到的是「Python 進來時，那 5 個檔不用改」
> ——而 `block-registrar` 裡的 40 顆命令式 cpp 積木，Python 一定要動。**
