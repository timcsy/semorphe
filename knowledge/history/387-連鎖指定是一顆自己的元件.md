## 為什麼是一顆新元件，不是讓既有的指定多收幾個目標

既有三顆（`var_assign`／`container_assign`／`member_assign`）各自的身分就是「左邊是哪一種」。連鎖指定的目標可以三種混著（`o.v = d["k"] = n = 1`），塞進其中任何一顆都得讓它認得另外兩種——那是三顆各長一份同樣的分支。另立一顆，目標是一串運算式插槽（每格接名字／下標／屬性積木），三顆都不必動。

形狀照 `var_assign_sequence`（`a, b = …`）抄：同是「一個值、多個地方」，差在那一顆是拆開來分、這一顆是同一個值存好幾次。

## Cella 那邊

Python 的程式形狀照 CPython 的 AST，`sAssign` 本來就帶 `targets` 串列——我們一直只送一個。所以模板就是 `sAssign` 帶多個 targets，已請 cella 收進對照表（他們下一版同步，本地先放同形的 `formalize.json`）。
