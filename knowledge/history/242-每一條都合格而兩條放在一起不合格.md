# 242 · 每一條都合格，而兩條放在一起不合格

**日期**：2026-09-17
**觸發**：管線 179（`cpp:container_pop_front`／`cpp:container_push_front`）的第六關
——`verify-in-browser`，那個「**還沒有人用眼睛看過它**」的出口。

## 進到這一關時，帳面是乾淨的

前五關全過：膠囊五路齊全、自證測各 7/7、真語料 18 支 lift／產碼／不動點全通、
模糊測試抓到的四族缺陷全部修好、`npm test` 6891 綠、可拿性護欄不紅。
整合那一關的**第五之三步（i18n 標籤一致性審計）也跑過了**。

而這一關抓到三件事，其中兩件與標籤有關。

## ① 逐條檢查天生看不見一致性

打開瀏覽器，走 production 的組裝函式把「堆疊與佇列」那一格問出來，
每一顆的文字都拿得到。**逐條對照 `component-generate` 的那張規則表，
新的兩顆每一條都合格**：中文是描述式動詞短語、沒有 `.method()`、
沒有語言關鍵字、沒有語法符號、tooltip 不重複 message0。

而把同族排成一張表之後：

```
移除 vec 末端元素      在 obj 尾端加入 ?       ← 既有（末端那一對）
移除 dq 最前面的元素   在 dq 最前面加入 ?      ← 新的（前端那一對）
que 的前端元素         從 que 的前端移除       ← 同一格裡，「前端」已經用了兩次
```

這個 repo 的標籤詞彙是 **頂端／前端／尾端／末端**。新的兩顆發明了第五個：**最前面**。

> **一條規則檢查的是「這一個對不對」；
> 一致性是【兩個之間】的性質——所以一張逐條的檢查表，
> 無論多長，都量不到它。**

⚠️ 而規則表**自己就有一條**寫著「同類概念用相同句式」。它沒有擋下來，
因為執行那條規則的人（我）是拿著新的那兩顆去看規則，不是拿著同族那一排去看新的兩顆。
**一條需要「並排」才能執行的規則，寫在逐條的表裡等於沒有寫。**

🟢 修法：對齊到既有詞彙——「移除 %1 前端元素」（對 `移除 %1 末端元素`）、
「在 %1 前端加入 %2」（對 `在 %1 尾端加入 %2`），流程視圖的兩條標題一起對齊。

🟢 順帶量到一條沒有人寫下來的慣例：**積木標籤用「前端／末端」，
tooltip 的散文才用「最前面」**（`queue_front` 正是這樣）。它也只有排出來才看得到。

## ② 一句叫學生去找找不到的東西的說明

同一次並排還看到 pop 的 tooltip：

```
「⚠️ 它不會把那個值交給你——要先用【%1 的最前面】讀出來再移除。」
                                      ↑ 這顆積木叫「%1 的前端元素」
```

**它引用了一顆不存在的積木。** 單看那一顆完全合理——那句話自己通順、
自己正確、自己教得會人。錯的是它指向的那個名字在別處。

> **比「沒有說明」更糟的是一句指向不存在的東西的說明**：
> 前者讓學生去問，後者讓學生去找。

## ③ 「新積木拿不到」有一個對偶，而兩邊都沒有護欄

貼一段真的程式進去（`deque<int> dq; dq.push_front(5); … dq.pop_front();`），
積木長出來了、拖得動、接得上、程式碼同步——**而畫面上第一行是橘色的**：

```
deque<int> dq;      🟠 「宣告 deque<int> 變數 dq」（cpp:var_declare）
dq.push_front(5);   🔵 「在 dq 前端加入 5」
```

`vector`／`queue`／`stack`／`priority_queue` 四個都有自己的**藍色**容器宣告積木。
於是在同一疊積木裡，造出 `dq` 的那一行與操作 `dq` 的那幾行是兩個顏色
——而顏色是分類的視覺編碼，學生讀到的是「第一行不是容器」。

更硬的一面：工具箱的「堆疊與佇列」拿得到「移除 dq 前端元素」，
**而拿不到造出 `dq` 的積木**。

> **「新積木拿不到」的對偶是：操作拿得到，而它的宣告拿不到。**
> 可拿性護欄兩邊都量不到——它問的是「**宣告了的**拿不拿得到」，
> 而這裡缺的東西根本沒有被宣告。

⚠️ **為什麼探索那一關沒問到**：管線的輸入逐字點名「前端操作」，
而探索照著目標走。宣告不在目標裡，所以它連「要不要做」都沒有被問一次。

> **一次探索只會回答被問到的問題。而「這個東西要怎麼被造出來」
> 不會出現在一份以「操作」為題目的探索裡。**

🟠 這一刀不做（補 `cpp:deque_declare` 是一次完整的管線，還會連帶碰
`registerContainerTemplate` 的樣板名登錄）。記在
`specs/component-discovery/cpp-container-ends.md` 當下一刀的入口。
