# 錯誤訊息的例句

> 由 `tests/integration/error-message-examples.test.ts` 產生——不要手改。每一種錯誤一支最小的程式，交給真的 Cella 判，
> 走產品同一條路（`toDiagnostics` → 兩側的文案），印出學生看到的字。改了文案或升了 Cella，這一頁會跟著變——看過再重產。

## 用到還沒有值的變數

```cpp
int main() {
    int total;
    cout << total;
}
```

判決：`reject`

- 積木：「total」還沒有值就拿來用了
- 程式碼：第 3 行：「total」還沒有值就拿來用了｜詳細資訊：C++17 [dcl.init]p12

## 除以零

```cpp
int main() {
    int a = 0;
    cout << 10 / a;
}
```

判決：`reject`

- 積木：「10 / a」除以零了
- 程式碼：第 3 行：「10 / a」除以零了｜詳細資訊：C++17 [expr.mul]p4

## 陣列越界

```cpp
int main() {
    int a[3];
    a[5] = 1;
}
```

判決：`reject`

- 積木：「a[5] = 1」讀寫到範圍外面了
- 程式碼：第 3 行：「a[5] = 1」讀寫到陣列（或容器）外面了｜詳細資訊：C++17 [expr.add]p4

## 整數溢位

```cpp
int main() {
    int x = 2147483647;
    x = x + 1;
    cout << x;
}
```

判決：`reject`

- 積木：「x + 1」算到超出範圍了
- 程式碼：第 3 行：「x + 1」的整數算到超出範圍了｜詳細資訊：C++17 [expr]p4

## 找不到名字

```cpp
int main() {
    cout << score;
}
```

判決：`reject`

- 積木：找不到「score」這個名字——用之前要先宣告它
- 程式碼：找不到名字「score」——用之前要先宣告

## 名字打錯（有長得很像的）

```cpp
int main() {
    int total = 1;
    cout << totl;
}
```

判決：`reject`

- 積木：找不到「totl」這個名字——是不是要寫「total」？
- 程式碼：找不到名字「totl」——是不是要寫「total」？

## 大小寫打錯

```cpp
int main() {
    Cout << 1;
}
```

判決：`reject`

- 積木：找不到「Cout」這個名字——是不是要寫「cout」？
- 程式碼：找不到名字「Cout」——是不是要寫「cout」？

## 串流配錯運算子

```cpp
int main() {
    int x;
    cin < x;
}
```

判決：`reject`

- 積木：「cin」要配「>>」，不是「<」
- 程式碼：「cin」後面要接「>>」，這裡寫成了「<」

## 等號左邊不是變數

```cpp
int main() {
    int a = 1, b = 2;
    a + b = 3;
}
```

判決：`reject`

- 積木：「a + b」不能放在等號左邊
- 程式碼：第 3 行：等號左邊要是一個變數，「a + b」是一個算出來的值

## 呼叫時引數不合

```cpp
int f(int x) {
    return x;
}
int main() {
    f(1, 2);
}
```

判決：`reject`

- 積木：「f」的引數型別不合
- 程式碼：第 5 行：呼叫「f」的引數型別不合

## 重複宣告

```cpp
int main() {
    int a = 1;
    int a = 2;
}
```

判決：`reject`

- 積木：「a」已經宣告過了
- 程式碼：第 3 行：「a」在同一個範圍裡已經宣告過了——換一個名字，或拿掉前面的型別直接用它

## 回傳值不合

```cpp
void f() {
    return 1;
}
int main() {
    f();
}
```

判決：`reject`

- 積木：void 函式不能回傳值
- 程式碼：函式宣告成 void（不回傳），這裡的 return 卻給了值

## 運算元型別不合

```cpp
int main() {
    string s = "a";
    int x = s * 2;
}
```

判決：`reject`

- 積木：std::string 和 int 不能用 * 運算
- 程式碼：第 3 行：「s * 2」——std::string 和 int 不能用 * 運算

## 型別轉不過去

```cpp
int main() {
    int x = "abc";
}
```

判決：`reject`

- 積木：const char * 不能轉成 int
- 程式碼：第 2 行：「int x = "abc"」是 const char *，這裡要的是 int，兩者不能互轉

## 跑太久（可能是無窮迴圈）

```cpp
int main() {
    while (true) {
    }
}
```

判決：`unknown`

- （沒有標示）｜說明：跑太久了，判不出來（可能是無窮迴圈）（指不到是哪一塊）
