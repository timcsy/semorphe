# `src/core/` — 引擎

**這裡不知道任何語言、任何宿主、任何面板的名字。**
相依只准往下：`core` 不得 import `ui`／`languages`／`components`／`vscode`／`interpreter`
（由第六十條護欄 `audit-layering` 守著）。

## 十個子目錄，各自說得出它是什麼

| 目錄 | 它是 |
|---|---|
| `blocks/` | 積木這個**投影**的共用件：型別名、覆寫、下拉來源、分類顏色、降級積木、工具箱 |
| `component/` | 元件的身分、性狀、參數規格、lift 樣式 |
| `flow/` | 流程這個**投影**：節點圖、連線、詞彙、佈局鑰匙 |
| `host/` | **宿主可抽換的那些埠**：程式碼視圖、主控台、存放、控制項、面板登錄表 |
| `lesson/` | 課程：課、章節、關卡、預測、步數、語意波、範例 |
| `lift/` | 程式碼 → 語義樹 |
| `projection/` | 語義樹 → 程式碼／積木，以及回來 |
| `registry/` | 登錄表的機制本身 |
| `storage/` | 存檔、版本升級、帶得走的匯出 |
| `sync/` | 匯流排、同步、視圖契約、步進 |

## 🪦 2026-09-13 之前，根目錄有 61 個平鋪的檔

而它們的共同點只有一個：**不在任何子目錄裡**。

那不是模組，是抽屜。把 import 圖算出來之後，四群自己浮出來
（課程 · 積木投影 · 存檔 · 同步），而**分群沒有製造任何新的環**
——唯一一條回邊是 `toolbox-builder → block-spec-registry`，
而 `toolbox-builder` 本來就屬於積木那一群。

> **一個目錄如果裡面的檔彼此不說話，它不是一個模組，是一個抽屜。**

⚠️ 根目錄仍然留著 27 個檔，而那是**刻意的**：`types.ts`、`semantic-tree.ts`、
`identity.ts` 這些是**所有群都在用的地基**。把地基也塞進某一群，
會讓那一群變成「大家都要 import 的那一個」——那是另一種抽屜。
