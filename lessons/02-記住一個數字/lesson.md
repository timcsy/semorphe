# 第二課：記住一個數字

> 這一課大約 15 分鐘。走完之後，你的程式會**記住**一個數字，而且會改它。
>
> **前置**：走過[第一課](../01-印出一句話/lesson.md)。

## 你會學到三件事

```
變數      給一個值取一個名字
指定      把新的值放進那個名字裡（包括「用它自己算它自己」）
印出變數  第一課的「印出」，這次印的是一個【會變的東西】
```

⚠️ **只有三件。** `main`、`印出`、`"文字"` 是第一課的，這一課當你已經會了。

---

## 開始之前

把第一課的程式清掉，在程式碼那一側貼上這段：

```cpp
int main() {
    cout << "分數是 " << endl;
    return 0;
}
```

⚠️ **每次改完程式碼，都要先按「程式碼→積木」再按「執行」。**
只按執行的話，跑的是**你改之前的東西**——而畫面上不會有任何提示。
（第一課教過這個鈕，這一課每一步都會用到。）

按「程式碼→積木」，再按「執行」，你會看到 `分數是 `——**後面是空的**。
這一課要做的，就是把那個空位變成一個**記得住的數字**。

---

## 第一步：給一個數字取名字

在 `cout` 那一行的**上面**加一行：

```cpp
int score = 90;
```

這一行做了三件事，而它們常常被當成一件：

```
int      這個名字裝的是【整數】
score    名字叫 score
= 90     一開始裝 90
```

⚠️ **`int` 那個字不能省。** 它是在跟系統說「**我要開一個新的名字**」——
這個動作叫**宣告**。等一下你會看到少了它會怎樣。

---

## 第二步：把它印出來

把 `cout` 那一行改成：

```cpp
cout << "分數是 " << score << endl;
```

👀 **注意 `score` 沒有引號。**

```
"分數是 "    有引號  →  就印這幾個字
score        沒引號  →  去看那個名字裡裝了什麼，印【那個】
```

按「程式碼→積木」，再按「執行」 → `分數是 90`

> 🔴 **這就是「變數」的意思**：程式裡寫的是名字，跑起來出現的是值。

---

## 🔴 第三步：故意打錯，看系統說什麼

**這一步不要跳過。** 把 `score` 改成大寫開頭的 `Score`：

```cpp
cout << "分數是 " << Score << endl;
```

按「程式碼→積木」，再按「執行」。系統會停下來，而下面會出現：

```
變數 'Score' 尚未宣告
```

**讀一次那句話。** 它說的正是第一步那個沒說完的東西：

```
宣告   ＝ 用 int 開一個新名字這個動作
尚未宣告 ＝ 你用了一個【從來沒開過】的名字
```

⚠️ 而 C++ **分大小寫**——`Score` 和 `score` 是兩個不同的名字。
你以為你在用剛才那個，系統看到的是一個全新的、沒開過的名字。

> **這句錯誤訊息不是在罵你，是在告訴你「名字要先開才能用」。**

改回 `score`，再按一次「程式碼→積木」＋「執行」。

---

## 第四步：讓它變

在 `cout` 那一行的**上面**加一行：

```cpp
score = score + 5;
```

⚠️ **這一行沒有 `int`。** 因為 `score` 已經開過了——
再寫一次 `int` 是「再開一個同名的」，不是你要的。

**這一行怎麼讀**：先算右邊 `score + 5`（90 + 5 = 95），
再把結果放回左邊的 `score`。

```
= 不是「等於」，是「把右邊放進左邊」
```

🔴 **所以 `score = score + 5` 一點都不矛盾**——數學上它無解，
而在這裡它是「拿舊的算出新的，再放回去」。

完整長這樣：

```cpp
int main() {
    int score = 90;
    score = score + 5;
    cout << "分數是 " << score << endl;
    return 0;
}
```

按「程式碼→積木」，再按「執行」 → **`分數是 95`**

---

## 🔴 第五步：再開一個名字，而**故意忘記 `int`**

第四步說「這一行沒有 `int`，因為 `score` 已經開過了」。
**那現在開一個全新的名字看看。** 把程式改成：

```cpp
int main() {
    int score = 90;
    bonus = 5;
    score = score + bonus;
    cout << "分數是 " << score << endl;
    return 0;
}
```

`bonus` 是一個**全新的名字**，而這裡**沒有 `int`**。
按「程式碼→積木」，再按「執行」：

```
變數 'bonus' 尚未宣告
```

👀 **和第三步同一句話。** 那不是巧合——

```
第三步   用了一個【打錯的】名字      → 那個名字沒開過
第五步   用了一個【全新的】名字      → 那個名字也沒開過
```

> **對系統來說，兩件事是同一件：你用了一個沒開過的名字。**

把 `int` 加回去：

```cpp
int bonus = 5;
```

再跑一次 → **`分數是 95`**

⚠️ **而有一件事要說清楚**：這個檢查是在**程式跑到那一行的時候**才發生的
——**不是**你打字的時候。所以如果那一行永遠沒被跑到（例如它在一個
不成立的條件裡），系統**不會**提醒你。真正的 C++ 編譯器在**編譯時**就會擋，
而我們是在**執行時**。

---

## 換你了

**把 `+ 5` 改成別的**，或把 `90` 改成你的數字，再多加一行
`score = score + ...`，看看會變成多少。

⚠️ 想再開名字，**記得前面要加 `int`**——第五步已經讓你看過忘記時會怎樣了。

---

## 這一課之後

```
✅ 你會   給值取名字、改它、印它，而且看得懂「尚未宣告」是什麼意思
❌ 還不會 讓使用者自己輸入數字、重複做很多次
```

那些下一課再說。
