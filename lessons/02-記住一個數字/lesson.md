# 第二課：記住一個數字

> 這一課大約 15 分鐘。走完之後，你的程式會**記住**一個數字，而且會改它。
>
> **前置**：走過[第一課](../01-印出一句話/lesson.md)。

## 你會學到三件事

```
變數      給一個值取一個名字
指定      把新的值放進那個名字裡（包括「用它自己算它自己」）
印出變數  第一課的「印出」，這次印的是一個【會變的東西】
```

⚠️ **只有三件。** `main`、`印出`、`"文字"` 是第一課的，這一課當你已經會了。

---

## 開始之前

把第一課的程式清掉，在程式碼那一側貼上這段：

```cpp
int main() {
    cout << "分數是 " << endl;
    return 0;
}
```

按執行，你會看到 `分數是 `——**後面是空的**。
這一課要做的，就是把那個空位變成一個**記得住的數字**。

---

## 第一步：給一個數字取名字

在 `cout` 那一行的**上面**加一行：

```cpp
int score = 90;
```

這一行做了三件事，而它們常常被當成一件：

```
int      這個名字裝的是【整數】
score    名字叫 score
= 90     一開始裝 90
```

⚠️ **`int` 那個字不能省。** 它是在跟系統說「**我要開一個新的名字**」——
這個動作叫**宣告**。等一下你會看到少了它會怎樣。

---

## 第二步：把它印出來

把 `cout` 那一行改成：

```cpp
cout << "分數是 " << score << endl;
```

👀 **注意 `score` 沒有引號。**

```
"分數是 "    有引號  →  就印這幾個字
score        沒引號  →  去看那個名字裡裝了什麼，印【那個】
```

按執行 → `分數是 90`

> 🔴 **這就是「變數」的意思**：程式裡寫的是名字，跑起來出現的是值。

---

## 🔴 第三步：故意打錯，看系統說什麼

**這一步不要跳過。** 把 `score` 改成大寫開頭的 `Score`：

```cpp
cout << "分數是 " << Score << endl;
```

按執行。系統會停下來，而下面會出現：

```
變數 'Score' 尚未宣告
```

**讀一次那句話。** 它說的正是第一步那個沒說完的東西：

```
宣告   ＝ 用 int 開一個新名字這個動作
尚未宣告 ＝ 你用了一個【從來沒開過】的名字
```

⚠️ 而 C++ **分大小寫**——`Score` 和 `score` 是兩個不同的名字。
你以為你在用剛才那個，系統看到的是一個全新的、沒開過的名字。

> **這句錯誤訊息不是在罵你，是在告訴你「名字要先開才能用」。**

改回 `score`，再按一次執行。

---

## 第四步：讓它變

在 `cout` 那一行的**上面**加一行：

```cpp
score = score + 5;
```

⚠️ **這一行沒有 `int`。** 因為 `score` 已經開過了——
再寫一次 `int` 是「再開一個同名的」，不是你要的。

**這一行怎麼讀**：先算右邊 `score + 5`（90 + 5 = 95），
再把結果放回左邊的 `score`。

```
= 不是「等於」，是「把右邊放進左邊」
```

🔴 **所以 `score = score + 5` 一點都不矛盾**——數學上它無解，
而在這裡它是「拿舊的算出新的，再放回去」。

完整長這樣：

```cpp
int main() {
    int score = 90;
    score = score + 5;
    cout << "分數是 " << score << endl;
    return 0;
}
```

按執行 → **`分數是 95`**

---

## 換你了

**把 `+ 5` 改成別的**，或把 `90` 改成你的數字，再多加一行
`score = score + ...`，看看會變成多少。

⚠️ **一個小提醒**：如果你想再開一個名字（例如 `bonus`），
記得**前面要加 `int`**——不然就會看到第三步那句話。

---

