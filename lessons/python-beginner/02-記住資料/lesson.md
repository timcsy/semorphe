# 記住資料

> 給一個值取個名字，之後就叫得動它。 · ⏱ 約 25 分鐘

## 你會學到三件事

1. 用 `=` 給一個值取名字
2. 四種基本的資料：整數、小數、文字、真假
3. **名字和文字長得像，意思完全不同**

## 開始之前

上一課的話是寫死的。想印別的，只能回去改程式。

這一課要讓程式**記住**東西。

## 一、取一個名字

```python
name = "小明"
age = 16
```

讀法：「**把 `"小明"` 放進一個叫 `name` 的地方**」。

⚠️ **從右邊讀到左邊**：先有右邊那個值，再放進左邊那個名字。

⚠️ **不用先宣告型別。** Python 從你給的值自己看出來——
`16` 是整數、`"小明"` 是文字。

## 二、印出來

```python
print(name)      # 小明
print("name")    # name    ← 🔴 差一對引號，完全不同
```

| 寫法 | 印出什麼 |
|---|---|
| `print(name)` | 那個名字**裡面裝的東西** |
| `print("name")` | `name` 這四個字母 |

**上一課那條規則現在派上用場了。**

## 三、四種基本的資料

```python
name = "小明"          # str    文字
age = 16               # int    整數
height = 1.72          # float  小數
is_student = True      # bool   真假
```

| | 長什麼樣 | 注意 |
|---|---|---|
| `str` | 有引號 | 單雙引號都行 |
| `int` | 整數 | 沒有上限 |
| `float` | 有小數點 | |
| `bool` | `True` / `False` | ⚠️ **大寫開頭** |

⚠️ `true` 是錯的，要寫 `True`。這是從別的語言過來的人最常打錯的一個字。

**想知道某個東西是什麼型別**，可以問它：

```python
print(type(age))       # <class 'int'>
```

## 四、名字可以改

```python
age = 16
age = 17
print(age)             # 17
```

**同一個名字可以換內容，換幾次都行。**

⚠️ 而 Python 允許換成**不同型別**：

```python
age = 16
age = "十六歲"          # 合法，而多半是個壞主意
```

它不會報錯——**所以要靠你自己記得那個名字裝的是什麼。**

### 取名字的規矩

```
✅  age    student_name    total2
🔴  2total（不能數字開頭） my-name（不能有減號） class（保留字）
```

習慣是**小寫加底線**（`student_name`），而不是 `studentName`。

## 完成的樣子

```python
name = "小明"
age = 16
height = 1.72
is_student = True
print(name)
print(age)
print(height)
print(is_student)
```

## 換你了

把上面四個換成你自己的資料，然後多加一行印出「`name` 今年 `age` 歲」。

⚠️ 提示：`print(name, "今年", age, "歲")`——**逗號隔開，Python 會自動加空格**。

## 這一課你做了什麼

- 你用 `=` 給四個值取了名字
- 你認得 `str` / `int` / `float` / `bool`
- 你分得出「名字」和「文字」——差別在有沒有引號

## 如果卡住了

| 你看到 | 多半是因為 |
|---|---|
| 印出來是名字本身 | 加到引號了。變數名**不要**引號 |
| `NameError` | 名字打錯字了——`Age` 和 `age` 是兩個不同的名字 |
| `true` 說沒定義 | Python 是 `True`，大寫開頭 |
| `SyntaxError` 在等號那行 | 名字裡有減號或空格，或是數字開頭 |
