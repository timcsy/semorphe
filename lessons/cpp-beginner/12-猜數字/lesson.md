# 猜數字

> 同一個問題，笨方法要一百次，聰明方法只要七次。 · ⏱ 約 30 分鐘

## 你會學到三件事

1. **同一個問題有很多種解法**，而它們的代價差很多
2. 二分搜：每猜一次，範圍就少一半
3. 「要跑幾次」可以被計算，而**亂數**讓它變成真的遊戲

## 開始之前

這一課沒有新的語法，你已經會的東西剛好夠了：變數、`while`、`if`、比較。

而它是整個課程的轉折：在這之前你在學怎麼講，
從這裡開始你要學**講什麼**。

🟢 **先把編輯器打開，跟著下面一起做：**〈跟著做〉

## 一、笨方法

猜一個 1 到 100 的數字。從 1 開始一個一個試：

```cpp
int guess = 1;
while (guess != target) {
    guess = guess + 1;
}
```

它一定猜得到。而如果答案是 100，你要猜 100 次。

## 二、聰明方法

改成每次都猜範圍的正中間：

```cpp
int lo = 1, hi = 100;
int mid = (lo + hi) / 2;    // 50
```

猜 50，然後：

| 對方說 | 你知道什麼 | 怎麼辦 |
|---|---|---|
| 太大了 | 答案在 1 到 49 | `hi = mid - 1` |
| 太小了 | 答案在 51 到 100 | `lo = mid + 1` |
| 中了 | 結束 | `break` |

**每猜一次，可能的範圍就少一半。**

> 猜中就不必再猜了——那顆積木寫著「**跳出迴圈**」（第 11 課用過）。

```
100 → 50 → 25 → 13 → 7 → 4 → 2 → 1
 ①    ②    ③    ④   ⑤   ⑥   ⑦
```

七次。而笨方法最多一百次。

## 三、七這個數字是算得出來的

範圍每次砍一半，砍幾次會剩下 1？

```
100 ÷ 2 ÷ 2 ÷ 2 ÷ 2 ÷ 2 ÷ 2 ÷ 2 ≈ 0.78
      ①   ②   ③   ④   ⑤   ⑥   ⑦
```

也就是「2 要乘幾次才會超過 100」——答案是 7（`2⁷ = 128`）。

推廣一下：

| 範圍 | 笨方法 | 二分搜 |
|---|---|---|
| 100 | 100 次 | 7 次 |
| 10,000 | 10,000 次 | **14 次** |
| 十億 | 十億次 | **30 次** |

範圍變成一萬倍，二分搜只多了 23 次。

> **這就是「複雜度」在講的事：不是「快多少」，
> 是「資料變大的時候，它變慢的速度」。**

## 四、寫出來
照著打上這一段：

```cpp
int lo = 1, hi = 100, steps = 0;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    steps = steps + 1;
    if (mid == target) break;
    if (mid < target) lo = mid + 1;
    else hi = mid - 1;
}
```

⚠️ **三個很容易寫錯的地方**：

1. `lo <= hi` 不是 `lo < hi`。寫成 `<` 的話，範圍剩一個數字時就不猜了
2. `mid - 1` 和 `mid + 1` 的那個 1 不能省，因為 `mid` 已經猜過了，
   不排掉它會變成無窮迴圈
3. `(lo + hi) / 2` 是整數除法（第 6 課），小數會被丟掉，而這裡正好是我們要的

## 五、讓它變成真的遊戲

到這裡 `target` 是寫死的 `42`——你每次跑，答案都一樣。

真正的猜數字要每次不一樣。C++ 有一顆專門做這件事的：

```cpp
cout << rand() << endl;      // 一個很大的隨機整數
```

> 積木盤上它寫著「**產生隨機數**」。

但 `rand()` 給的數字太大了，要把它壓進 1 到 100：

```cpp
int target = rand() % 100 + 1;
```

```
rand()          一個很大的數
    % 100       取餘數 → 0 到 99
        + 1     → 1 到 100
```

⚠️ 而這樣還不夠：**`rand()` 每次重跑程式會給出同一串數字**。
它不是真的隨機，是照一條固定的規則算出來的，所以叫「偽隨機」。
要讓每次不一樣，得先給它一個種子：

```cpp
srand(time(0));
```

> 積木盤上它寫著「**設定亂數種子 …**」。

`time(0)` 是現在的時間（從 1970 年算起的秒數），每一秒都不一樣，
所以每次跑拿到的那一串就不一樣。

> `time(0)` 這種「名字後面接一對括號」的寫法叫**呼叫函式**，
> 積木盤上那顆就寫著「**呼叫函式 …（…）**」。
> 第 18 課會整整講一課，這裡先照抄就好。

⚠️ **`srand` 只呼叫一次，放在 `main` 的最前面。**
放進迴圈裡的話，同一秒內每一圈的種子都相同，反而每次都拿到一樣的數字。

這兩顆各要一個標頭檔：

```cpp
#include <cstdlib>    // rand, srand
#include <ctime>      // time
```

## 完成的樣子

```cpp
#include <iostream>
using namespace std;
int main() {
    int target = 42;
    int lo = 1, hi = 100, steps = 0;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        steps = steps + 1;
        if (mid == target) break;
        if (mid < target) lo = mid + 1;
        else hi = mid - 1;
    }
    cout << "猜了 " << steps << " 次" << endl;
    return 0;
}
```

## 如果卡住了

| 你看到 | 多半是因為 |
|---|---|
| 停不下來 | `lo = mid` 忘了加 1（或 `hi = mid` 忘了減 1） |
| 有些數字猜不到 | 條件是 `lo < hi`，應該是 `lo <= hi` |
| 次數比 7 多很多 | `mid` 算錯了，或不小心變成一個一個試 |
| 每次重跑答案都一樣 | 少了 `srand(time(0))`，或它被放進迴圈裡了 |
| 說 `rand` 沒宣告 | 少了 `#include <cstdlib>`（`time` 要 `<ctime>`） |
