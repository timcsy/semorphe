# 印出一句話

> 讓電腦說出你要它說的話。 · ⏱ 約 20 分鐘

## 你會學到三件事

1. 程式**從哪裡開始跑**
2. 怎麼叫電腦**印一句話**出來
3. 同一個程式，**積木和程式碼是同一件事**

## 開始之前

打開編輯器，畫面上會有一塊空的程式：

```cpp
int main() {
    return 0;
}
```

這就是一個**能跑**的程式了——只是它什麼都不做。按一下「執行」，
下面的主控台會是空的。**空的不代表壞掉**，代表你還沒叫它做事。

## 一、`main` 是起跑線

`main` 這個字很特別：**電腦只會從 `main` 開始跑**。

你之後會寫很多段程式，而電腦不會亂猜要先跑哪一段——它固定找 `main`。
所以每一支 C++ 程式都要有一個，而且**只有一個**。

`int main()` 下面那對大括號 `{ }` 圈起來的，就是「要做的事」。
你等一下要放進去的東西，就放在那兩行中間。

## 二、叫它說話

在 `return 0;` 的**上面**加一行：

```cpp
int main() {
    cout << "Hello!" << endl;
    return 0;
}
```

拆開來看：

| 這一段 | 意思 |
|---|---|
| `cout` | 「印出去」——**c**onsole **out**put |
| `<<` | 箭頭指著 `cout`，表示「往那邊送」 |
| `"Hello!"` | 要送過去的東西。**有引號 = 一段文字，原封不動印出來** |
| `endl` | **end line**，換行。少了它，下一句會黏在同一行 |
| `;` | 一句話說完了 |

按「執行」，主控台會出現：

```
Hello!
```

### ⚠️ 引號很重要

`"Hello!"` 有引號，所以電腦**原封不動**印出 `Hello!`。
如果你寫成 `cout << Hello! << endl;`（沒引號），電腦會以為 `Hello`
是一個你先前取好的名字，然後找不到它，於是報錯。

**有引號 = 一段文字；沒引號 = 一個名字。** 這條規則整堂課都用得到。

## 三、看一眼積木

切到積木那一邊。你會看到同一個程式，變成幾塊接在一起的積木——
一塊 `main`，裡面接著一塊「印出」，「印出」上面插著 `Hello!`。

試著**把 `Hello!` 那格的字改掉**，改成你的名字。
再切回程式碼——它跟著變了。

> **積木和程式碼不是兩份東西，是同一份東西的兩種畫法。**
> 你改哪一邊都可以。

## 完成的樣子

```cpp
int main() {
    cout << "Hello!" << endl;
    return 0;
}
```

## 換你了

讓它印出**兩行**：

```
Hello!
我是 <你的名字>
```

提示：第一行你已經會了，第二行是一模一樣的事再做一次。

## 這一課你做了什麼

- 你知道了程式從 `main` 開始跑
- 你用 `cout << ... << endl;` 印出了一句話
- 你看到同一個程式的兩種樣子，而且改哪邊都算數

## 如果卡住了

| 你看到 | 多半是因為 |
|---|---|
| 主控台是空的 | 那一行寫在 `return 0;` 的**下面**了——`return` 之後的東西不會跑 |
| 說 `Hello` 找不到 | 引號漏了。文字一定要用 `"` 包起來 |
| 兩句話黏在同一行 | 少了 `endl` |
| 紅紅的錯誤，指著某一行 | 行尾的分號 `;` 漏了 |
