# Round-Trip 報告：cpp 一排位元（`bitset`）（管線 199・階段三）

2026-09-20｜分支 `199-cpp-bitset`｜語料 218 支

> **這一關該找的東西找到了，而它們一個都不在 `bitset` 上——
> 一個在【遷移機制】裡，一個在 `cout <<` 的排版規則裡。**

## 🔴 缺陷一：遷移機制看不見「接點改名」——整整一類的缺口

`cpp_bits_count` 的插槽從 `VALUE` 改名成 `OBJ`，我照慣例寫了：

```ts
SHAPE_CHANGES_V23 = [{ blockType: 'cpp_bits_count', retiredFields: ['VALUE'] }]
```

**而它是一個 no-op。** `staleShapeIn` 只讀 `n.fields` 與 `n.extraState`
——它**遞迴進** `n.inputs` 去找巢狀積木，卻從來不看那些 input 叫什麼名字。

> **一個只看得見欄位的失效判定，看不見「同一顆積木換了接點的名字」。**

⚠️ 而那個檔案 2026-08-26 已經寫過同一句話的第二種（「換了記憶方式」→ `retiredExtraState`）。
**這是第三種。**

⚠️ 症狀不是報錯：舊存檔裡接在 `VALUE` 的那顆積木**安靜地消失**。

🟢 **修法**：`ShapeChange` 多一格 `retiredInputs`，判定多一段（放在「遞迴進 inputs」
**之前**——那一段找的是巢狀積木，這一段問的是這一顆自己的 input 叫什麼名字）。
三支測試釘住：舊形狀要被認出來 · 新形狀不得被誤判 · 別的積木身上有 `VALUE` 不得被掃到。

## 🔴 缺陷二：`cout << (n << 1)` 走一趟積木回來印 51 而不是 10

```
寫的               走一趟積木回來        後果
cout << (n << 1);  cout << n << 1;      那個位移【整個消失】
```

`LOW_PREC_OPS`（哪些東西放進 `cout <<` 要加括號）列了
`& | ^ && || > < >= <= == !=`，**而沒有 `<<` 與 `>>`**。

它們與串流的 `<<` **同一個優先級**而左結合，所以 `cout << n << 1`
讀成 `(cout << n) << 1`。

⚠️ **而程式碼那一路一直是對的**：括號由 `layoutHints` 帶，而**積木上沒有 metadata**。

> **一個靠排版提示帶的括號，在經過一次投影之後就不再存在
> ——而它保護的那個結合律仍然需要它。**

🔴 **這是同一個病的第四次**（第 197 刀的 `pointer_deref`／`address_of`／`bitwise_not`
是第一到三次）。修完語料仍然 **218/218、走樣 0**——因為一個位移只有在使用者
真的寫了括號時才會成為 `cout <<` 的一個值。

## 🔴 缺陷三：`bits_count` 的 `form` 屬性從來沒被填過

與階段二 `bits_fill` 的 `mode` **是同一個病的第二次**，而我在同一天犯了兩次：

```
方法那一路   declaresMethodProp(id) → properties.method = 使用者寫的方法名
呼叫那一路   registerCallComponent 的 funcProp → 同一格
```

取名 `form`（值 `builtin`／`method`）的那一格**沒有任何路由會填它**
⟹ `bs.count()` 產回去變成 `__builtin_popcount(bs)`——**那連編都編不過**。

> **一顆元件宣告的屬性名，就是它能不能被共用路由填到的條件。**

🟢 改成 `method`，值就是使用者寫的那個名字（`count`／`__builtin_popcount`），
兩條路由都填它。

## 🟠 量出來而不修的兩件（都寫了理由）

| | 為什麼不是現在 |
|---|---|
| `cout << (n & 1)` 產出**雙層括號** | `needsParensInCout` 與 `layoutHints` 各加一對。三種寫法都合法、同義、都是不動點（判準第三層）。要修得動共用產生器，而**語料今天走樣 0，動它的風險大於這個排版疣**。何時該修：下一次有人碰 `cout <<` 的排版 |
| `d[i].reset()` 認不出來 | 依型別分派那張表**用接收者的原文查名字**，而 `d[i]` 不是名字。🔴 第一版用「登錄到名字表」繞過去，**而既有護欄抓到那是錯的**（會搶走任何 `x.reset()`）。何時該修：宣告表記得住陣列的元素型別的那一天 |
