**21 本**都真的有它們（`grep` 掃 `tests/baselines/` ＋ `tests/assets/`）。

### ② `retiredInputs` 會不會誤傷既有的 `V12..V22`

🟢 **不會，而它是結構上保證的**：那一格是 optional，既有各筆都沒有它，
判定寫的是 `(change.retiredInputs ?? []).some(...)` ⟹ 空集合。
三支測試釘住：舊形狀要被認出來 · 新形狀不得被誤判 · 別的積木身上有 `VALUE` 不得被掃到。

### ④ 撤掉 `using_alias` 的 `skipPaths` 有沒有蓋掉一個真的洞

⚠️ 它不在任何「跳過宣告」的清冊裡，撤掉之後全套仍然全綠。

### ⑦ 🔴 `_why` 抓到三件，而其中一件比「過期」更糟

| | |
|---|---|
| 🟠 `bits_fill._properties_why` 寫著「引數個數（**0**）」 | **同一天稍後**那個可選的位置接點就加進來了 |
| 🔴 同一段還留著「**帶引數的形式刻意不收**」 | **階段四正是把它收了**——一句與程式碼**說相反話**的理由 |

`bs[i]` 與 `bs.test(i)` 完全等價，多一顆積木做同一件事是認知負載。

### ⑧ i18n

🟢 tooltip 含 markdown `**` 的：**0 句**（第 123 條在擋）。
🟢 「位元」是既有措辭（`位元 AND（&）`／`位元反轉 %1 (~)`）。

並排：

```
array_declare  建立 %1 陣列 %2 %3            |  create %1 array %2 %3        ← 🟠 英文小寫開頭
bits_declare   建立 %1 個位元的一排 %2 複製自 %3  |  Create a row of %1 bits …
```

而 i18n 規範要求動詞大寫開頭。新的四顆都符合。
