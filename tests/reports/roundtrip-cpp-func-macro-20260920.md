## 🔴 這一關抓到的那一個：**「讓開」不是安全的預設**

第二關的設計寫著「證不出來就回 `null`，讓開，走今天的行為」。
第三關逐一量「讓開之後長什麼樣」，結果是：

```
學生寫的                    讓開之後產回去          
go(i,n) s += i;             go(i, n) += i;        🔴 s 不見了
rep(i) s += i;              rep(i) += i;          🔴 s 不見了
```

**「今天的行為」就是那個病**——這一刀存在的理由正是它。
「讓開」把一個**已知的**巨集呼叫交還給一棵解錯的樹，而那棵樹會靜默少一個名字。

> **「讓開」與「誠實降級」的差別，不在我做了多少，
> 在使用者的程式碼有沒有被改掉。**

🟢 **修法**：開頭是一個**已知的**函式形巨集呼叫而證不出展開時，
把那幾句整段降級成 `cpp:raw_code`（原文照抄）。

```
誠實降級之後   go(i,n) s += i;    🟢 一字不差，而執行時會說「這段我不認得」
```

⚠️ **判準是「這個名字是不是一個已知的巨集」**——一個不認得的名字本來就是
一個函式呼叫，把它降級會弄壞一整族正常的程式（★ 錨點釘住了這一條）。

⚠️ 而**運算式位置的巨集（`SQ(3)`）不受影響**：那一句的開頭不是巨集呼叫，
這條規則根本看不到它。

### ② 三種用法的樹形狀**各不相同**——而它們都要走得通

```
rep(i,m) s += i;      →  一個 expression_statement（assignment，左邊是那個呼叫）
rep(i,m) cin >> a[i]; →  兩個並列的 expression_statement
rep(k,4){ … }         →  一個 expression_statement ＋ 一個 compound_statement
rep(i,m) rep(j,n) …   →  三個並列
```

🔴 **所以判別走【文字】不走那棵樹**——不是偷懶，是因為那棵樹是錯的，
而預處理器本來就在文字那一層工作。

> **一棵解錯的樹，它的每一個子節點都會被正確地辨識成錯誤的東西
> ——而照那些子節點去認形狀，等於把解析器的錯當成規格。**

### ③ 巢狀的第二趟：修法驗過了，而且往下再驗兩趟

第二關修掉的那個（重解出來的樹沒有 `#define` 行 → 內層查不到巨集 →
被當成一個函式定義 `void rep(j, n) { … }`）。
這一關量了**四趟**、**三層**，全部是不動點。

### ④ `layoutHints` 走一趟積木回來會不見——**而那是安全性質**

```
沒碰積木   rep(i,n) s += i;                 🟢 一字不差
碰過積木   for (int i = 0; i < n; i++) …    🟢 誠實
```

🔴 而正反兩支都有**正向錨點**：碰過積木那一支除了斷言「拼法不見」，
還斷言 **`for (int` 出現**、**迴圈身分還在**、**主體還在**
——只驗「不見了」的話，一個把整顆迴圈弄丟的缺陷也會讓它變綠。

⚠️ 比對時要**先濾掉 `#define` 那一行**：它當然還印著巨集的名字。
（第一版沒濾，六支全紅——**一個把自己的輸入算進判準的檢查，量的是它自己**。）

## ⑤ 舊存檔：`CURRENT_VERSION` 不必動，而那個判斷被釘住了

這一刀把 `layoutHints` 的值從 `boolean` 放寬成 `boolean | string`，
而 `layoutHints` 住在 `metadata`、**語義樹是存進存檔的**——所以它動到存檔的形狀。

🟢 **既有的每一個消費者都用 `=== true`**（`precedence.ts:55`、`code-generator.ts:403/406`），
所以一個字串值對它們而言就是「沒有那一格」——**放寬是相加的，不是相改的**。

📌 兩支常駐測試釘住它：舊存檔的布林排版註記仍然生效 · 字串與布林同住一格。

## 讓開的那幾種（每一種都有常駐測試）

| 情境 | 行為 | 原文 |
|---|---|---|
| 名字沒定義過（`rep(2,3)` 是真的函式） | 函式呼叫，**不碰** | 一字不差 |
| 引數個數對不上 | **誠實降級** `raw_code` | 一字不差 |
| 巨集呼叫後面沒有語句 | **誠實降級** `raw_code` | 一字不差 |
| 巨集體裡又呼叫另一個巨集 | **誠實降級** `raw_code` | 一字不差 |
| 運算式位置（`SQ(3)`） | 函式呼叫，**不碰**（墓碑那一側） | 一字不差 |

🔴 **刻意沒有中途站**：一個「認得出巨集而還原不回去」的中間態，
產出的是**看起來對而少東西**的樹。
