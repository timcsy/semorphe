| | 症狀 | 處置 |
|---|---|---|
| R1 | 回傳指標／參照的函式原型 `Node* pushFront(Node*, int);` → `Node* ptr;`（名字與參數全丟，安靜） | ✅ 修好：拆開指標／參照，符號併進回傳型別（`liftPointerPrototype`；`const` 開頭那種在常數變數那條路之前攔） |

| R3 | 類別裡的建構子／解構子原型 `BST();`、`~Folder();` → `int BST();`、`int f();` | 🟡 誠實降級（原文保留） |
| R4 | 類別外的解構子定義 → `void Folder::~Folder()` | 🟡 誠實降級 |
| R5 | 類別外的 const 方法定義少了尾端 const | 🟡 誠實降級 |
| R6 | 回傳指標的覆寫方法 `const char* name() const override` 丟了 const 與 override（子類別成了抽象類別）；純虛擬的同款被打亂 | ✅ 覆寫／虛擬方法修好（剝開指標再判斷）；純虛擬的指標回傳／尾端 const 🟡 誠實降級（那顆記不住） |
| R7 | 類別裡的方法原型 `void link(B* b);` 被建成名字叫 `link(B* b)` 的變數 | 🟡 誠實降級 |
| R8 | `friend class Bank;` | 照舊降級成原文（本來就誠實） |
| R9 | 沒標存取的成員被搬到 `private:` 區段（宣告順序改變） | 既有設計（類別定義把成員依存取分組）；記為已知限制 |

R3～R7 是同一族：**類別裡只宣告、定義寫在類別外的成員函式**。要做對得有一顆「宣告方法」的元件，並讓 formalize 把類別外的定義接回類別成員——工作量與這一刀相當，排進路線圖〈類別外定義成員函式〉。
課文與 StudyCpp（306 支）裡這一族 **0 處**（2026-11-06 用 lift 量過），所以誠實降級不動任何現有的課。
