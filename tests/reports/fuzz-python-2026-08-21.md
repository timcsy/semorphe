## 發現的 Bug

### 🔴 Bug 1：`"ab" * 3` 靜靜印出 `0.0`

| | |
|---|---|
| 輸入 | `print("ab" * 3)` |
| 預期 | `ababab` |
| 實際 | `0.0` |

**根因**：`python:arithmetic` 的執行器只處理了字串的 `+`，
`*` 掉進下面的數值運算 → `toNumber("ab")` 是 `NaN` → `NaN * 3` → 印成 `0.0`。

> **一個靜默的錯答案，比一個拋出來的錯誤貴得多——因為使用者會拿它去算下一步。**

🟢 **已修**：字串的 `+`（串接）與 `*`（重複）各自處理，**其餘的字串運算丟錯**
（Python 說 TypeError，我們也要出聲）。

⚠️ 而它值得記的是**發現的難度**：12 題裡**只有一題**碰到它，
而那一題碰到它是因為題目在教「`+` 與 `*` 是兩種完全不同的運算」——
**一個實作感知的出題者不會寫那一題。**

### 🔴 Bug 2：`break` / `continue` 不存在，而執行到它時整支程式中止

| | |
|---|---|
| 輸入 | `for i in range(5):` … `if i == 2: break` |
| 實際 | `RUNTIME_ERR_UNKNOWN_COMPONENT: raw_code` |

**根因**：這兩顆元件沒做。降級**是誠實的**（灰色積木，原文留著），
而執行到那顆積木時它丟錯——整支程式停在那裡。

> **一個誠實的降級，在【執行】那一路上仍然是一個中止。**

🟢 **已修**：兩顆元件補齊（丟 `BreakSignal` / `ContinueSignal`），
進 L1 課程，各四支自證測（含「在 for 迴圈裡也接得住」）。
