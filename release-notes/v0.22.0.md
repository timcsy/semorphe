# Semorphe v0.22.0

> 上一版 v0.21.0（2026-11-05）到這一版，兩週、一百五十次合併。這一版的重點：**Arduino 課堂用的積木重新整理過**、**錯誤訊息全部說得出「為什麼、試試看」**、**C++、Python、C 之間可以互相換寫法**（換了會改變意思的地方照實保留，不悄悄改）。

## ✨ 亮點

### Arduino
- **值分成三種積木**：電位（高 HIGH／低 LOW）、模式（輸出 OUTPUT／輸入 INPUT／輸入上拉 INPUT_PULLUP）、腳位名稱，各是自己的一顆，和數字分開。選了板子之後，腳位的下拉選單不再混著 HIGH、OUTPUT。
- **七顆 Arduino 積木的中文重寫**，例如「設定腳位 … 的模式為 …」、「讓腳位 … 輸出 …」、「讓腳位 … 發出 … 赫茲的聲音 持續 … 毫秒」。
- **字元積木**放到「資料」分類的前面。
- **蜂鳴器**：`tone`／`noTone` 在 ESP32-C3 上可以模擬，持續時間留空會一直響到 `noTone`。
- `String` 的 `trim`、`indexOf`、`substring`、`toInt`，以及 `Serial.readStringUntil`、`Serial.parseInt` 都有自己的積木。
- **中斷**：`volatile` 宣告（含陣列）、`IRAM_ATTR` 的函式有自己的積木；`IRAM_ATTR` 只在 ESP 系列的工具箱出現。
- 硬體分頁停下來時會說出原因（模擬到上限、步數用完、出錯），並點出還開著的輸出腳位。
- ESP32 系列在支援 ESP32Servo 之前，不提供伺服馬達積木（避免給出跑不起來的程式）。

### 錯誤訊息
- 每一種錯誤都有「**為什麼**」與「**試試看**」兩段中文說明，並**指到出錯的那一行、那一塊積木**。
- 編譯錯誤細分成具體的種類（不是左值、型別不能相加、引數不合……），各有自己的中文說明——上一版說的「下一版會改成好懂的中文」做到了。
- 漏了分號時會提示「這一行的結尾可能少了一個 `;`」。
- 條號（C++17 的章節）收進詳細資訊：第一眼只看到說明，VSCode 的 Problems 面板與編輯器的提示裡看得到條號。

### 換語言、換寫法
- **C++ → Python**：學生練習程式裡常見的寫法（vector、二維陣列、pair、map／set、deque、stack、`getline`、`while (cin >> x)`、位元運算、整數除法……）都換得過去，換過去的程式跑出來的結果和原本相同。
- **Python → C++**：`elif`、字典、串列生成式、`enumerate`、連續比較等換得過去。
- **C → C++**：`printf`／`scanf` 換成 `cout`／`cin`、`malloc`／`free` 換成 `new[]`／`delete[]`、拿掉 `struct` 標籤。
- **換了會改變意思的地方照實保留原文**並說明原因，不會產生一支「看起來對、跑起來不一樣」的程式。

### C／C++
- 新增或補齊：類別外定義成員函式、`friend`、運算子多載、`this`、`union`、`typedef struct`／`typedef enum`、類別的前置宣告、函式樣板、靜態成員、`explicit` 建構子、宣告的建構子寫法 `T x(…)`。
- 多個 `catch`、lambda 的 `mutable`、`noexcept`、尾置回傳型別等還沒有積木的寫法，**照原文保留**，不再被悄悄丟掉。

### Python
- 裝飾器、`nonlocal`／`del`、參數的 `*args`／`**kwargs`、迴圈的 `else`、f-string 的 `{x=}` 與轉換、連鎖指定、空類別 `class P: pass` 都有積木。

### 編輯與課程
- 改程式碼之後，**手動排好的積木留在原位**，沒動到的積木保住身分。
- 只在程式碼那側編輯也會自動存檔；重新整理後 Python 不再被套上 C++ 的 `main` 骨架。
- 排序題重新整理不再看到答案；換目標語言時不會在 15 秒後蓋掉學生剛打的程式。
- 課的網址與課名一致，舊網址會自動轉過去。

## 給 VSCode 使用者
- 程式碼也會跟著積木收合（和網頁版同一套判準）。
- 錯誤的條號顯示在 Problems 面板的 code 欄。

## 🔧 已知的限制
- **Arduino 中斷**：`attachInterrupt` 的中斷函式在判斷引擎還沒有模型之前，執行時會照實說「判斷不出來」，不會假裝程式沒問題。
- **換語言**：少數寫法（例如某些 `cout` 格式控制、指標運算）還換不過去，那幾行會保留原文並說明原因。
