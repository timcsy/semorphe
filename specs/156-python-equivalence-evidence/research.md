# Phase 0 研究：一顆 Python 元件會撞到什麼

**日期**：2026-08-20

## R0｜第一次量錯了，而錯的是我的探針

第一版探針只寫 `conceptId` ＋ `traits`，跑全套 **25+ 檔紅**。
我一度把它記成「25 條護欄假設了元件是 cpp」——**而根因只有一個**：

```
膠囊 python/print：缺少 paths。五路要全部列出，沒有的寫 null ＋ 理由
```

`allComponentDefs()` **拋錯**，於是每一支碰元件清單的測試都倒。

> **一個在載入階段就拋錯的探針，量到的是它自己不合格，不是被測系統的性質。**

🟢 補齊契約（五路 ＋ 理由）之後：**8 檔**。
再把「宣告了卻沒有形態的接點」拿掉之後：**5 檔／6 條**。

⚠️ **那兩次縮減都不是「修好了什麼」，是【探針本身變合格了】。**

## R1｜五條檢查，五個不同的「只有一個語言」假設

| 檢查 | 它說什麼 | 假設的面向 | 分類 |
|---|---|---|---|
| `audit-identity-namespace` | `python:print：scope 不在白名單（cpp）` | **白名單**寫死了 scope | 🔴 ① 該支援多語言 |
| `component-move-parity` | `搬家多出了身分（複製沒刪乾淨？）` | **凍結清單**——它的前提是「搬家前後相同」 | ② 判準要收窄：**新增不是搬家** |
| `audit-completeness` | `新缺 python:print → render/extract/execute` | **基線**不認得「這個語言此刻沒有那一路」 | ② 基線要記，而**理由要寫** |
| `audit-curriculum-coverage` | `這些元件不在任何課程裡，學生看不到它們` | **課程清單**是 cpp 的 | ② 明確策展：**Python 還沒有課** |
| `audit-declared-slots` | `有未判定的「無法確定」——它的原因要人說` | **未判定桶**要求人給理由 | ② 給理由（它沒有 lift 產出的接點） |

🔴 **只有第一條是「機制不支援多語言」；其餘四條都是【要求人說明】**
——而那正是那些護欄設計時的意圖：**不准靜默**。

> **一條好的護欄遇到新情況時，會要求你【說明】，而不是直接錯。
> 五條裡有四條做到了。**

## R2｜等價的機制不必發明

`toolbox-builder.ts:118` 逐字：

> 「第四版問的是那條**等價邊**本身：`cpp:print` 與 `cpp:print_formatted`
> 宣告了同一個 `ioRole`（＝同一個等價類）與不同的 `ioStyle`（＝哪個成員）。」

**決定**：觀察集先取 `{ioRole}` 一維，等價類直接由 `traits.ioRole` 分群。
**理由**：它已經是**生產路徑在用**的等價關係（工具箱排序），不是為這一刀發明的。
**否決的替代**：自訂一組「跨語言對映表」——那是 R1 第一條的同一個病（寫死的清單）。

## R3｜第一個分歧點在哪，要量不要猜

⚠️ 規格要求「第一個不落在同一類的地方**是一個位置**」。
量法：把 cpp 與 python 的概念**各自**依觀察集分群，然後看
**哪些類只有單邊成員**——那些就是分歧點的候選，而**第一個**由清單順序決定。

🔴 而 `draft/通解與特解` 已經預測了一個候選：
「`cout << a << b` → `printf` 要**合併**格式字串，那不是逐項投影再相加」
——⚠️ **而那是 cpp 內部的分歧，不是跨語言的**。這一刀要找的是跨語言那個。
