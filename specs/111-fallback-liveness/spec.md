# Feature Specification: 護欄 #33 的自我更正——回退分兩種，只有一種會發生

**Created**: 2026-08-10 ｜ **Status**: Draft
**Input**: `specs/110` 蓋的第三十三條護欄把兩種形狀混成一個數字，而其中一種是死分支。

## 為什麼有這個 spec

`specs/110` 的第三十三條護欄第一次跑抓到 9 筆，我**全部判為「靜默回退」**。
收尾時實測它們的**活性**（415 段語料）：

```
型別不符   if (arr.type !== 'array')      vector_size  → 每次 s.size() 都走到  ✅ 活的
缺子節點   if (!v) / (nodes.length === 0)  其餘 8 筆    → **0 次**
```

對照有效：那 8 筆對應的概念裡有 5 個真的出現過（共 14 次），而**回退一次都沒被走到**。

> **兩種條件的發生時機根本不同**：
> **型別不符**發生於**上游辨識判錯身分**——那是真的會發生的事（`s.size()` 就是）。
> **缺子節點**發生於**語義樹本身壞掉**——防禦性的，而它沒有發生。

**所以基線的 8 是死分支。** 一條數字永遠不動的棘輪，與一條沒有人跑的護欄
是同一件事。

## User Scenarios & Testing

### User Story 1 - 護欄的數字說得出它在盯什麼（Priority: P1）

維護者看到「靜默回退 8 筆」時，無法分辨哪些是**會發生的**、哪些是**防禦性的**。
兩者的意義完全不同：前者是缺陷的藏身處，後者只是還沒被觸發的保險。

**Independent Test**：報表分兩欄，棘輪只盯會發生的那一欄。

**Acceptance Scenarios**：

1. **Given** 掃描完成，**Then** 命中依條件形狀分成「型別不符」與「缺子節點」兩欄
2. **Given** 只做重新分類，**Then** 兩欄**總和不變**
3. **Given** 基線，**Then** `_meta` 記下缺子節點那一欄的**實測活性**（415 段語料 0 次）
4. **Given** 有人新增一個型別不符的回退，**Then** 會被報進第一欄

### Edge Cases

- **分類靠條件的語法形狀**，而形狀會有新的寫法（`typeof x !== …`、`instanceof`）
  → 判不出來的歸「未分類」並**計入要看**，不得靜靜歸進防禦欄
- **活性是對語料量的**，語料變了活性也會變 → 活性記在 `_meta` 而不是當斷言

## Requirements

- **FR-001**：命中 MUST 依條件形狀分成「型別不符」與「缺子節點」兩類。
- **FR-002**：分不出來的 MUST 歸「未分類」並計入要看，MUST NOT 歸進任一類。
- **FR-003**：棘輪 MUST 只盯「型別不符」那一欄。
- **FR-004**：兩欄總和 MUST 在只做重新分類時不變。
- **FR-005**：基線 `_meta` MUST 記錄缺子節點那一欄的實測活性與語料規模。
- **FR-006**：`_meta` MUST 註明本次數字變動屬於「因為判準改了」，不是「因為修好了」。

## Success Criteria

- **SC-001**：報表讀得出兩欄。
- **SC-002**：兩欄總和 = 8（分類前後不變）。
- **SC-003**：型別不符欄 = 0（`vector_size` 已於 `specs/110` 修掉）。
- **SC-004**：`_meta` 有活性紀錄與「因為判準改了」的註明。
- **SC-005**：全部測試通過。

## Out of Scope

- **移除那些死的防禦分支**——不會發生 ≠ 不該存在（它防的是未來的壞樹）
- 擴到產生器（實測 26 處觸發 0 次）

## 給實作者的警告

### ⚠️ 這一輪的數字下降**不是改善**

型別不符欄從「8（其中 1 已修）」變成 0，看起來像大幅改善。
**實際上 8 筆裡有 7 筆只是換了一欄。** `_meta` 必須寫清楚，否則
下一輪會把它讀成「靜默回退幾乎清光了」。

### ⚠️ 我在 `specs/110` 犯的錯，判準已經寫在 skill 裡而我沒套用

`build-guardrail` 6.5 剛補的那條：
> 「宣稱『這 N 筆是同一個根因』之前，在其中至少兩筆上分別驗過。」

我把 9 筆判成同一種病，而**它們有兩種形狀**——那條判準是我兩天前寫的。
→ 本輪要在 skill 補一條更前面的：**新護欄的命中要問「這個條件實際上會不會發生」**。
