# Spec 187：流程面板把一塊收成一個有埠的框

**路線圖**：vision〈分子：組合階層與粒度切換〉「流程面板的投影——收成一個有埠的框」
**設計來源**：`knowledge/draft/2026-09-03-分子與粒度切換.md`（「三個視圖的投影結構上不同」「B 的狀態那一半落地了」）
**已在的機制**：`src/core/molecule.ts`（`boundaryOf`／`crossingEdges`）、`src/core/granularity.ts`（鑰匙 ↔ `nodeId`）——兩者今天都沒有消費者。

## 使用者故事

**US1（P1）** 學生的流程面板太滿。他在一顆有身體的節點（`for`、`if`、函式）上按右鍵 →「收合這一塊」，
那顆節點連同它的整個子樹變成**一個框**：標題照舊、框上寫「收著 N 塊」、對外的接點還在（上一句接進來、下一句接出去、或它的值輸出），
裡面的節點與線都不畫。右鍵 →「展開這一塊」回到原樣。

**US2（P1）** 收起來之後，他在程式碼面板打一個字（改一個不相干的值）——**框還是收著的**。
（`nodeId` 每次重新解析都換掉；用 `nodeId` 記收合的症狀就是「打一個字、全部展開」，`granularity.ts` 檔頭點名過。）

**US3（P2）** 收著的框可以照常拖、照常被選取；被收進去的節點若被執行走到，框亮起來（說得出「在這一塊裡面」）。

## 功能需求

- **FR-001** 收合狀態是**共享的**、屬於真實那一側：狀態以鑰匙（`CollapsedEntry`）保存，走匯流排廣播；
  視圖各自用 `resolveCollapsed` 對回自己手上那棵樹。面板之間不互相呼叫（P9，`principles.md:177`）。
- **FR-002** 收合／展開是**請求**：視圖發 `granularity:request { nodeId, collapsed }`，狀態持有者更新後廣播 `granularity:collapsed { entries }`。
- **FR-003** 每次語義更新後，持有者把鑰匙對到新樹再重產（配不到的安靜地掉——那一段被刪了）。
- **FR-004** 流程面板只畫**最外層**的收合（`outermostCollapsed`）；裡層的收合狀態保留（展開外層後裡層仍收著）。
- **FR-005** 框的對外接點＝那一顆原本的對外接點；**框的埠數必須等於 `crossingEdges`（選區＝那顆與整個子樹）＋ 兄弟串接**
  ——驗收那條等式兩邊各自算一次（`molecule.ts` 檔頭的要求）。
- **FR-006** 只有**有子節點**的節點能收（收一顆葉子沒有意義，選單不出現）。
- **FR-007** 收合不改語義：收合 → 展開，語義樹雜湊不變、程式碼一字不差（收合是檢視狀態，不進語義樹）。
- **FR-008** 執行走到被藏起來的節點時，亮的是**包住它的那個框**。

## 範圍外

- 積木／程式碼的投影（vision 下一格）——它們訂閱同一個 `granularity:collapsed`，這一刀只留好那條線。
- 多選後收合（要 Blockly 插件，會撞 `middle-drag-pan` 的手勢）。
- 鑽入、麵包屑、裝配樹。
- **存進存檔**：重開後收合狀態不還原（避免這一刀動存檔格式；鑰匙格式已備好，`collapsedToKeys`）。

## 驗收

- 單元：`buildNodeGraph` 帶 `collapsed` 時，被收的子樹不出現、框的埠數＝`crossingEdges` ＋ 串接；不帶時輸出與今天逐字相同。
- 單元：狀態持有者——收合、換掉每一個 id 之後仍配得回去；刪掉那一段之後掉掉。
- e2e：收合 → 框出現、內部節點不見 → 在程式碼打一個字 → 仍收著 → 展開 → 節點數回到原本。
