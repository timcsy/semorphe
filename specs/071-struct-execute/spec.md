# Feature Specification: 結構的執行——物件導向的第一片

**Feature Branch**: `071-struct-execute` ｜ **Created**: 2026-08-06

## 為什麼做這個

完備性護欄的 27 個殼裡，**16 個是物件導向**。它們全部註冊成空操作。

而這不是「補幾個執行器」的題目：直譯器的執行期型別只有
`int｜float｜double｜char｜string｜bool｜void｜array｜pointer`——**沒有物件**。
值模型承載不了一個有欄位的東西。

## 範圍：一片，不是整套

| 做 | 不做 |
|---|---|
| 宣告結構型別 | 類別的存取控制 |
| 用它宣告變數（欄位遞迴取得預設值） | 方法、建構式、解構式 |
| 讀欄位、寫欄位 | 繼承、虛擬函式、運算子多載 |
| 巢狀結構 | 指標取成員 |

**切一片而不是一次做完**，因為值模型的改動會碰到每一條路，那個風險要能單獨
驗證。剩下的殼**留在完備性報表裡繼續被數**——切一片不等於把剩下的宣告掉。

## Requirements

- **FR-001**: 執行期的值 MUST 能承載一個有具名欄位的實例
- **FR-002**: 用結構型別宣告變數 MUST 遞迴建立所有欄位的預設值
- **FR-003**: 兩個實例 MUST 互相獨立——欄位在實例上，不在型別上
- **FR-004**: 讀寫不存在的欄位 MUST 出聲，**MUST NOT 靜默回預設值**
- **FR-005**: 自我參照的結構 MUST 報錯，MUST NOT 無限遞迴
- **FR-006**: 型別登記處 MUST 是每個直譯器實例一份，MUST NOT 全域
- **FR-007**: 成員宣告本身 MUST NOT 被當成敘述執行
- **FR-008**: 執行器 MUST 住在語言套件——核心只提供機制
- **FR-009**: 剩下的 OOP 概念 MUST 留在殼的清單裡，MUST NOT 順手宣告掉

## Success Criteria

- **SC-001**: 完備性的殼 **27 → 25**，實作 **810 → 812**
- **SC-002**: 六個行為各有測試（預設值／獨立性／不存在的欄位／巢狀／型別隔離／成員不執行）
- **SC-003**: 既有測試全數通過

## 設計筆記：為什麼欄位用 Map 而不是普通物件

欄位名可能與 `Object.prototype` 的成員撞名（`toString`、`constructor`…）。
用普通物件的話，**讀一個不存在的欄位會靜默成功**——而那正是本專案有專門
教訓的那種靜默降級。
