**路線圖**：vision〈分子：組合階層與粒度切換〉「積木／程式碼的投影」的**程式碼那一半**（積木那一半是 spec 188）

**設計來源**：`knowledge/draft/2026-09-03-分子與粒度切換.md`——「程式碼 摺成一行 ＋ { … } 🟡 Monaco 的 folding 是【按行】的 ⟹ 要 nodeId → 行區間（`mappings` 有）」

## 使用者故事

**US1（P1）** 在流程或積木收起一塊 → 程式碼裡那一段摺起來；展開 → 攤開。
**US2（P1）** 在程式碼裡自己按摺疊箭頭摺一段 → 流程收成框、積木收起來。
**US3（P1）** 在程式碼改一個不相干的值 → 那一段仍摺著。

## 功能需求

- **FR-001** 節點 → 行：對映（`mappings`）起始行上、跨多行的那個節點（同一行好幾個時取跨最多行的）；
  行 → 摺疊區段：從那一行開始的區段。對不到就不摺（不猜）。
- **FR-002** 狀態 → 摺疊：語義更新、廣播、以及 Monaco 自己重算區段之後（`setCode` 之後區段是非同步重算的）都照狀態套一次；
  展開只展開「上一次照狀態摺的」（別的視圖展開時跟著攤開）。
- **FR-003** 使用者摺／展（摺疊模型的 `collapseStateChanged`，而且不是自己在套的那一次）→ `granularity:request`。

## 範圍外

- VSCode／Theia 宿主的編輯器（程式碼在宿主那側，摺疊要走宿主的 API）——這一刀只做網頁版的 Monaco。
- 鑽入、麵包屑、多選、來回一致的 fuzz。

## 驗收

- e2e `code-folding-shared`：流程收 → 程式碼摺；改值 → 仍摺；流程展開 → 攤開；程式碼自己摺 → 流程框 ＋ 積木收起來。
