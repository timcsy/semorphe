# Feature Specification: 繼承、虛擬、運算子多載——物件導向的第三片

**Feature Branch**: `073-oop-slice3` ｜ **Created**: 2026-08-06

## 範圍

071 建了值模型，072 接上行為，這一片補其餘可做的八個：命名空間、模板函式、
指標取成員、繼承、虛擬方法、覆寫、純虛擬、運算子多載、靜態成員。

## 刻意不做，以及為什麼

| 概念 | 為什麼 |
|---|---|
| 解構式 | 需要**物件生命週期**——直譯器沒有離開作用域時的收尾時機 |
| lambda | 需要**閉包**——捕捉清單要把外層變數綁進一個可呼叫的值 |

兩者都不是「補一個執行器」的量級，**留在殼的清單裡繼續被數**。

## Requirements

- **FR-001**: 覆寫的方法 MUST 蓋掉基底的
- **FR-002**: 沒有覆寫時 MUST 繼承基底的欄位與方法
- **FR-003**: 循環繼承 MUST NOT 造成無限迴圈
- **FR-004**: 純虛擬方法被呼叫時 MUST 出聲——它沒有本體
- **FR-005**: 靜態成員 MUST 由所有實例共用，且實例欄位 MUST 遮蔽它
- **FR-006**: 空指標取成員 MUST 出聲
- **FR-007**: 物件參與算術而沒有對應多載時 MUST 出聲，**MUST NOT 轉成 NaN 印出一個數字**
- **FR-010**: 既有測試全數通過——**特別是跑真實程式的那批**

## Success Criteria

- **SC-001**: 完備性的殼 **22 → 19**
- **SC-002**: 九個行為各有測試
- **SC-003**: 既有測試全數通過

## 一個效能退化，以及抓到它的是什麼

運算子多載的第一版在算術執行器開頭**多求值了一次左運算元**，於是每個算術
節點的工作量翻倍——遞迴的 fibonacci 直接爆步數上限。

**單元測試全綠。抓到它的是跑真實程式的那批測試。**
