# 契約：主控台這個表面

## 宿主要接得住的三件

| | 意思 | 網頁版 | VSCode／Theia |
|---|---|---|---|
| `show()` | 把它叫回來 | 底條 `display` 打開 | `view.show(true)` |
| `hide()` | 使用者關掉它 | 底條收起來 | 使用者按 IDE 的關閉 |
| `isHidden()` | 它現在關著嗎 | 讀我們自己的狀態 | `view.visible` |

🔴 **投影到 `host*` 就背一個接手的義務**（第六十三條護欄的形狀）：
宣告主控台住在宿主的 panel 區，宿主那側就要真的**有那個 view**。

## 「有輸出就自己回來」住在哪

🟢 **住在共用的那一側**（`ConsolePanel` 的寫入路徑），不是各宿主各寫一份。

```
write(chunk) → if (surface.isHidden()) surface.show()
             → 寫進去
```

⚠️ 兩個宿主各寫一次的話，其中一個遲早會漏——而漏掉的症狀是
**使用者看不到程式在說什麼**，那與「程式當掉了」長得一樣。

## 🪦 這份契約取代了什麼

```
🪦 output: 'hostTerminal'   （2026-08-25）唯一的理由是「Output 是唯讀的」
🪦 output: 'panelBottom'    （2026-09-01）方向對而位置錯——它進了編輯區
🟢 output: panel 區的 view  （2026-09-02）
```

> **一個「因為 A 不行所以選 B」的理由，在 C 出現時要重新問一次
> ——而不是把 B 當成結論。**
