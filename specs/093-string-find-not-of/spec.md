# Feature Specification: 兩個新概念，五路齊備

**Feature Branch**: `093-string-find-not-of` ｜ **Created**: 2026-08-06

## 為什麼做這個

前面七批查阻斷者，發現的**多是過期的標記**。這一批不同：標成
`[UNSUPPORTED:字串搜尋函式 find_first_not_of／find_last_not_of 尚無對應概念]`
的那支，**標記是對的**——那兩個概念真的不存在。

所以這是**加功能**，不是清理。

## 五路齊備，不是只補一條

| 路 | 交付 |
|---|---|
| 語義 | `concepts.json` 的概念定義 |
| 投影 | `blocks.json` 的積木 |
| 產生 | 積木的 `codeTemplate` |
| 辨識 | `lifters/io.ts` 的方法分派 |
| 執行 | `std/string/executors.ts` |

**只補執行那一條的話，孤兒實作護欄會報出來**——082 就撞過一次（順手加了五個
字元分類的執行器而沒有其他四路，已收斂）。

## 找不到時回 -1

C++ 回 `npos`（`size_t(-1)`，印出來是 18446744073709551615）。
這個直譯器統一回 -1——理由與 092 相同：**使用者常寫 `!= -1` 來比**，
而 npos 在這裡沒有被表示成一個常數。

## Requirements

- **FR-001**: 兩個概念 MUST 有完整五路
- **FR-002**: 辨識 MUST 給各自的專屬身分，且**一般的 `find` MUST NOT 被混進來**
- **FR-003**: 來回轉換 MUST 保住方法名
- **FR-004**: 找不到時 MUST 回 -1
- **FR-005**: 期望值 MUST 由**真的編譯器**決定

## Success Criteria

- **SC-001**: 元件 178 → 180，**殼與缺維持 0**
- **SC-002**: 辨識／產生／執行三路各自有測試
- **SC-003**: 只有名字的測試 15 → 14
- **SC-004**: 既有測試全數通過
