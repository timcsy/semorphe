# Feature Specification: 三層靜默降級——`while ((p = f()) != 0)` 一次都不跑

**Feature Branch**: `085-assignment-expression` ｜ **Created**: 2026-08-06

## 為什麼做這個

查 `var_assign` 那批 todo 時撞到的。`while ((p = f()) != 0)` 這個寫法
**一次都不跑**，而程式照樣跑完、印出後面的東西。

追下去有**三層**，而三層都是靜默降級：

| 層 | 症狀 |
|---|---|
| 指派不回傳值 | `(y = 5) != 0` 的左邊是 undefined → 比較恆假 |
| 指標轉數字一律 0 | `p != 0` 對**有效的指標**也是假 |
| `strchr` 靜默回 0 | 找得到也回 0 —— **安靜的錯答案** |

**沒有錯誤訊息、沒有例外、輸出看起來像一段跑完的程式。**

## 第三層的處置與前兩層不同

前兩層是**做錯了**，修掉。

第三層是**做不到**：`strchr` 回傳指向陣列中間的指標，而這個直譯器的指標存的是
「被指變數的名字」，表示不了「指向 s 的第 3 個字元」。那需要 (基底, 位移)
的表示法，是一個真的功能。

**但「做不到」不等於「安靜回 0」。** 出聲——使用者可以選擇跳過或中止，
但不會拿到一個安靜的錯答案。

## Requirements

- **FR-001**: 指派 MUST 求值成被指派的值
- **FR-002**: 指派 MUST 仍然真的寫進變數——**只驗回傳值的話，一個「回傳值但
  不寫入」的實作也會過**
- **FR-003**: 有效的指標 MUST 為真
- **FR-004**: 空指標 MUST 為假——**只驗前一項的話，「指標一律為真」也會過**
- **FR-005**: 表示不了的回傳值 MUST 出聲，MUST NOT 靜默回 0

## Success Criteria

- **SC-001**: 只有名字的測試 **50 → 46**
- **SC-002**: 三個修正各有正反測試
- **SC-003**: 既有測試全數通過

## 順帶：`cpp_increment` 那 4 支是過期的

「前置／後置遞增在初始化式裡」實測**來回轉換與執行全部正確**，
期望值由 g++ 驗過（`5 7 7 5 5`）。四支移除。

| 批次 | 過期 | 真的 |

| 陣列初始化列表（17） | 17 | 0 |
