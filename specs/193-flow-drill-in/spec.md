# Spec 193：流程面板的鑽入 ＋ 麵包屑

**路線圖**：vision〈分子：組合階層與粒度切換〉「鑽入 ＋ 麵包屑 ＋ 裝配樹——e2e：三層深進出後回到原位；樹上選 ↔ 圖上亮雙向連動」的**前兩件**
**設計來源**：`knowledge/draft/2026-09-03-分子與粒度切換.md` §四（「一個手勢管一件事：縮放管大小，鑽入管深淺」）
**張力**：history/193——「整份程式 ▾」下拉 2026-08-30 被刪（「一個要等到東西變多才有價值的控制項，在那之前是純粹的成本」）。
本刀的回答：**沒有常駐的控制項**——入口在右鍵選單，麵包屑只在鑽進去時出現。裝配樹（常駐側欄）不在本刀，見 draft 的待決。

## 需求

- **FR-001** 右鍵 →「進入這一塊」：有身體、身體裡有東西的節點（函式、迴圈、if）。圖只畫那一塊的身體。
- **FR-002** 麵包屑：「整份程式 › main › for 迴圈 › …」，點一格回到那一層；Esc（沒有選取時）上一層。沒鑽進去時不顯示。
- **FR-003** 鑽入的位置以鑰匙記（同收合）：在裡層改一個字仍停在那一層；那一塊被刪了 → 退到還在的那一層並說出來。
- **FR-004** 回到原位：每一層的手拖位置（以鑰匙記）與鏡頭推進堆疊，回到那一層時還原。存檔只存最外層的位置。
- **FR-005** 鑽進去時從工具盤放下的節點落在這一層的身體裡；收著的框相對於這一層算最外層。

## 範圍外

- 裝配樹（常駐側欄）與「樹上選 ↔ 圖上亮」——待決（draft）。
- 積木與程式碼跟著鑽（鑽入是這個面板的檢視，同鏡頭）。

## 驗收

e2e `flow-drill-in`：手拖一顆 → 三層進入（麵包屑 2/3/4 格）→ 裡層改值仍在第三層 → 麵包屑跳回、Esc 回最外層 → 麵包屑消失、每一顆回到原位。
