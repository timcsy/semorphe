# Data Model：擴充裡跑的就是網頁版本身

**Feature**: 140-app-in-host　**Date**: 2026-08-18

---

## 🔴 這一輪**沒有新資料**，只有一次「誰認識誰」的重畫

```
今天    App ──依賴──▶ 一個具體的編輯器（30 處）
之後    App ──依賴──▶ 一個【角色】
                        ├─ 網頁版：內建編輯器
                        └─ 這個宿主：IDE 的編輯器（一個把文字交出去的殼）
```

> **一次抽象如果沒有換掉任何資料，它換掉的是【誰有權知道什麼】。**

---

## 一、新增的兩個宣告（**都是資料，不是邏輯**）

### `CodeViewAbsence` —— 這個實作**沒有**哪些可選能力

```
absentReasons   Record<能力名, 理由>
```

⚠️ 它與「沒實作的可選方法」**必須一一對應**——
🔴 多一個是說謊（宣稱缺席而其實有），少一個是遺漏（缺席而沒說）。

### `HostFeatures` —— 這個宿主**建不建**哪些介面元件

```
fileButtons     開檔／存檔／匯入匯出
mobileLayout    行動版的分頁列與選單
codeKeyboard    輔助輸入鍵盤（它需要底層編輯器）
featureReasons  Record<關掉的那一項, 理由>
```

🔴 **關掉 ＝ 不建那些 DOM**，不是建了再隱藏（FR-006）。

---

## 二、既有實體的**身分變化**（一個都不改欄位）

| 實體 | 今天 | 之後 |
|---|---|---|
| 內建編輯器面板 | `App` 的一個具體相依 | **角色的一個實作** |
| 存檔服務 | `App` 內部 `new` 出來的 | **由宿主宣告注入** |
| 文件內容 | 存檔裡的一格 | 🔴 這個宿主：**檔案才是真相**，存檔不記它 |

> 🔴 **`storageService` 在這個宿主裡不是搬家，是【消失】**
> ——第一類資料在這裡有真相了。

---

## 三、狀態轉移——**只有一條新的，而它在開機**

```
開機 → 問宿主的存檔服務有沒有東西可還原
        網頁版      有 → 還原（今天的行為，一個字不改）
        這個宿主    🔴 一律沒有 → 不還原 ⟹ 檔案的內容零字元變更
```

⚠️ 而**那條分岔不在 `App` 裡**——`App` 只是「問了、拿到空的、所以不還原」。
🟢 **分岔住在宿主的宣告裡**，那才是它該住的地方。

---

## 四、⚠️ 一個本輪不建模、但會被撞到的


本輪**不重新設計介面**（目標是「一樣」不是「更好」），
