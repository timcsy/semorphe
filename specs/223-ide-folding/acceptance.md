# 手動驗收：IDE 宿主的程式碼也跟著收合（spec 223）

> 這一半只有人驗得到——`editor.fold` 是宿主的指令，測試環境裡沒有真的編輯器。
> 前置：裝上這一版的 vsix（`npm run build:vscode` 產出 `semorphe-vscode.vsix`），在 VSCode 開一個 `.cpp` 檔與 Semorphe 積木面板。

範例程式（貼進 `.cpp`）：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n = 5;
    while (n > 0) {
        n = n - 1;
    }
    if (n == 0) {
        cout << n << endl;
    }
    return 0;
}
```

| # | 動作 | 應該看到 | 通過 |
|---|---|---|---|
| 1 | 在積木面板上，對 `while` 那顆積木右鍵 →「收合」 | 編輯器裡第 5 行（`while`）摺起來，只剩 `while (n > 0) {⋯}` | ☐ |
| 2 | 對同一顆積木「展開」 | 編輯器裡那一段展開 | ☐ |
| 3 | 收合 `if` 那顆 | 第 8 行（`if`）摺起來；`while` 那段不受影響 | ☐ |
| 4 | 在編輯器的 `int n = 5;` 上面加一行空行，再在積木上展開 `if` | `if` 那段展開（行號挪了也對得上） | ☐ |
| 5 | 開另一個檔案到前景，在積木上收合 `while`，再切回原檔 | 另一個檔案**沒有**被摺；切回後下一次狀態改變時才摺 | ☐ |
| 6 | 在編輯器裡自己按摺疊箭頭摺 `while` | 積木**不會**跟著收合（宿主沒有事件，刻意單向）——不算錯 | ☐ |
