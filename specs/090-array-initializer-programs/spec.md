# Feature Specification: 第二批過期的陣列 todo

**Feature Branch**: `090-array-initializer-programs` ｜ **Created**: 2026-08-06

## 為什麼做這個

剩下的 40 支 todo 裡，**13 支的阻斷者與 082 那批完全相同**——
「陣列初始化列表在辨識時遺失（pre-existing lifter limitation）」。

082 已經證明那個阻斷者不存在了（050 修好，而沒有人回頭看）。這 13 支散在
五個不同的檔，所以上一輪沒有一起清掉。

> 一個過期的阻斷者標記會**散佈在很多檔案裡**，而每一份都看起來像獨立的一筆。

## 這一刀

寫兩支完整的程式（函式鏈與分類、求最大值與總和），**期望輸出由 g++ 實際編譯
執行決定**，然後移除 13 支 todo。

## 為什麼要驗執行結果

初始值全部變成 0 的話，來回轉換仍然產得出 `{0, 0, 0}`——**看起來像一段合法
程式**。只有跑起來比對輸出才分得出來。

外加一支反面：`{7,8,9}` 讀出來必須是 `789`——沒有它，一個「初始值全填 0」的
實作在某些程式上可能碰巧對。

## 順帶：又一個空的 describe

移掉 todo 之後 `known issues: arrays & pointers` 變成空的。
**一個空的 describe 是殼**——它看起來覆蓋了一個情形，實際上零斷言。
填成真的回歸測試，不是刪掉。
