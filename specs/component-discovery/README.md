# 元件探索報告

`/component-discover` 產出、`/component-generate` 讀入的**工作文件**：
一份「這個標頭／函式庫裡有哪些元件值得做」的清單，附建議的層級歸屬與降級路徑。

## 🪦 它原本叫 `specs/concepts/`（2026-09-13 改名）

那是 spec 159 把 `concept` 改成 [`元件`](../../knowledge/concepts/元件.md) **之前**留下的化石。
今天 `src/` 裡 `concept` 剩 4 個，而這個資料夾名一直沒跟上。

⚠️ **不叫 `components`**：`src/components/` 才是元件本身，這裡裝的是**關於元件的報告**。
兩個同名而層級不同，grep 的時候會混。
🟢 而 `component-discovery` 多說了一件真的事：**這是探索階段的產物，不是規格**
（這個目錄裡沒有 `spec.md`，其餘 141 個目錄都有）。

> **一個資料夾如果說不出它與內容的關係，東西多半是放錯地方了。**

## 🔴 它們不是用完的化石——六成是還沒做的待辦

量過（2026-09-13）：31 份報告一共提案 **191 顆元件，而只有 76 顆成為膠囊**。

```
cpp-cstring              14 提案 →  2 膠囊   12 未落地
cpp-advanced-features    16 提案 →  5 膠囊   11 未落地
cpp-types-advanced-ops   17 提案 →  7 膠囊   10 未落地
…
合計                    191 提案 → 76 膠囊  115 未落地
```

⚠️ 所以**留著它們的理由不是紀念，是那 115 顆**。

## ⚠️ 讀它們的時候要知道

**用的是舊詞彙。** 這批多數寫於 2026-03 到 2026-08，裡面的
`cpp_vector_declare`（積木型別名）、「概念」（現在叫元件）、「Topic 層級樹」
都還是當時的說法。

而**它們的結論不是真相**——真相是 `src/components/` 底下真的存在的那些膠囊。
