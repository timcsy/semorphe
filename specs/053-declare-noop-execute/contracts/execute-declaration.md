# 介面契約：執行路徑的宣告

**消費者**：核心執行引擎、完備性護欄、中立性護欄、除錯器

---

## 概念定義（`ConceptDefJSON`）

| 欄位 | 變動 | 說明 |
|---|---|---|
| `skipPaths?: PathName[]` | **定位改變** | 從「純資料，不影響執行期行為」變成**機制**——執行引擎讀它 |
| `skipReasons?: Record<PathName, SkipReason>` | **新增** | 每個被跳過的路徑必須說出理由 |
| `annotations?: Record<string, unknown>` | 沿用 | 新增 `debug_step: true` 這個鍵 |

```ts
export type SkipReason = 'declarative' | 'consumed-by-parent'
```

**只有兩個值，且不得增加。** 第三個值就是在替「還沒做」找體面的名字。

### 不變式

1. 有 `skipPaths` 必有對應的 `skipReasons`——測試強制
2. 宣告 `execute` 被跳過的概念，**不得**同時註冊非空執行器——矛盾，測試強制
3. 未宣告的空實作**仍判為殼**（現況，不得放寬）

---

## 執行引擎

| 情況 | 行為 | 與現況 |
|---|---|---|
| 有執行器 | 執行 | 相同 |
| 宣告了 `skipPaths: ['execute']` | 跳過，不報錯 | **相同**（現況由清單達成） |
| 兩者皆無 | 回報未知概念 | 相同 |
| 兩者皆有 | 矛盾，測試階段就擋下 | 新增 |

**行為不變，來源改變。** 核心層不再持有任何語言專屬的概念名。

---

## 執行器註冊表

```ts
register(concept: string, executor: ConceptExecutor): void
/** 新增：回報同一概念被註冊超過一次的情形（供護欄量測） */
duplicates(): { concept: string; count: number }[]
```

**不在註冊時報錯。** 本功能只讓重複可見；消除排在後面。理由見 `history/017`——加嚴之前要先回答「被拒絕的東西去哪了」，而這裡的答案目前是「不知道」。

---

## 完備性報表

三欄取代兩欄：

| 欄 | 意義 |
|---|---|
| 實作 | 真的會做事 |
| **已宣告不提供** | 附理由，**與「實作」分開計數** |
| 殼／缺 | 棘輪只看這欄 |

**兩種下降混在一起的話，下一個人會用宣告刷數字。**

## 護欄的自我否證（照 `concepts/執行機構.md`）

> ⚠️ 如果分類跑出來「34 個全部可宣告」，代表判準太鬆或最小程式太簡單——**那不是好消息，是工具壞了**。
> ⚠️ 如果 `static_cast<int>(3.9)` 在修改後仍不是 3，代表覆蓋來源不只 research F8 找到的那一處。

**不檢測**：概念在**其他語言**下是否也不執行；`lift`／`render`／`extract`／`generate` 四條路徑的宣告（本功能只碰 `execute`）。
