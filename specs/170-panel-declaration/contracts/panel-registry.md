# 契約：面板登錄表

## 核心可以問它什麼

```
allPanels()                    有哪些投影（照 LAYER_ORDER 排）
panelsOfLayer(layer)           這一層有哪些（可能多份 → 那一格的分頁）
panelsFor(profile)             這個宿主上有哪些（吃 availableIn）
layersOf(profile)              這個宿主上有哪幾層 ← layout-presets 吃它
```

## 🔴 核心【不可以】問它什麼

```
panelById('blocks')            ⚠️ 允許，但**組裝點以外不得用**
                                  ——那正是今天 app-shell 的病
```

> **核心可以知道「有這種投影」，不該知道它叫什麼、也不該假設它有幾個。**
> （`concepts/宣告登記處.md`，這是它的第三次應用）

## 組裝點必須出聲的四種情形

| 情形 | 訊息 |
|---|---|
| 兩份宣告用同一個 `id` | 「面板 id 撞名：…」 |
| `layer` 不在 `LAYER_ORDER` 裡 | 「認不得的層：…」 |
| `nameKey` 查不到翻譯 | 「面板『…』的名字沒有翻譯」 |
| 一份宣告都沒有 | 「一個面板都沒有登記——glob 沒吃到東西」 |

⚠️ 最後一條是**入口條件**：沒有它的話，glob 壞掉時整個應用會安靜地變成空白。
🔴 而 `concepts/執行機構.md` 記著同一個病：「一個沒有人宣告的登記處**就是殼**，
而它綠得跟真的一樣」。
